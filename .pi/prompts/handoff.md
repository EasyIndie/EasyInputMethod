按 Skill `update-handoff` 的规范收尾本次会话：

1. 汇总本次会话：做了什么、关键决策、验证结果（贴关键命令与结果）、遗留问题。$ARGUMENTS
2. 更新 `HANDOFF.md`：
   - §0 元信息（时间 / 更新者 / 阶段 / 分支 / 最近 `make verify` 结果）
   - §2–§5 状态（已完成 / 进行中 / 下一步 / 待决）
   - §9 会话日志**顶部**追加一条（≤5 行）
3. 同步 `ROADMAP.md`：勾选已完成项。
4. 保持简短；细节指向 `docs/`，不要复制设计内容。

完成后，用一句话告诉我"当前状态 + 下一步"。
