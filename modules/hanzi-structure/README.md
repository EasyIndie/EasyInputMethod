# 汉字结构与五笔教学生成模块

状态：目录和依赖边界已按ADR-189确定；当前仅有文档，尚无新结构数据、编译器或运行包。现有教学实现和来源仍在原位置。本目录不是Git submodule，不是已可用的新输入引擎。

## 职责

建设可自主审核的汉字结构事实，结合不同五笔版本规则，生成有来源的取码轨迹与教学资源。支持主项目学习区，并为未来查码、教程图示和练习答案复用。文字说明由事实和规则派生，不按每字每版另写文案。

## 目录边界

以下是后续按需建立的布局；当前不创建空目录或空壳代码：

```text
hanzi-structure/
  README.md
  spec/          # 模型、格式版本、质量等级、构建契约
  corpus/        # 自建部件/字形/笔顺与字符结构对应
  schemes/       # 五笔86/98/新世纪规则及结构化特例
  assets/        # 自有/经准入的字根和笔画图形
  tools/         # 离线校验、分析、编译、审核视图
  tests/         # 规则、几何、差异和迁移验证
  provenance/    # 作者、来源、许可、固定快照及哈希
```

不依赖ime-*、平台框架、用户配置、输入会话或主仓库目录。工具未来从显式源目录/方案/输出目录取得输入，不依赖调用者cwd、主仓库Makefile、git状态或`../../data`。模块内引用相对自身根解析，输出路径由调用者指定。项目既有wubi-encoder的复用/迁移方式另决策，不能因此新增反向依赖。

## 产物边界

- 编辑用事实、分析器、完整审核证据和测试语料是源资产，不直接进入输入法App。
- 运行教学包只含已支持方案、完整根序与选取/省略/识别码依据、共享根/规则字典、必要小型显示资产和版本/来源清单。
- 大型几何、教程或字体资源独立分层，是否随默认安装提供由对应产品需求决定；学习功能已承诺的资源不能只放在可选包里。运行不自动联网下载。
- 主项目保持自己的适配器、FFI和平台加载；只通过版本化产物契约接入。当前协议尚未冻结，不假设换路径即可替代现有include_*。
- 模块的每项数据仍须按主项目流程登记来源/许可及SHA；以后拆分时模块自己的provenance必须保留完整来源链。数据/资产许可单列，不默认沿用代码许可。

## 独立迭代与迁出验收

后续实现须能在只复制本目录的临时位置完成其校验与构建，不访问父仓库、不依赖主项目私有数据；相同输入输出一致。主项目只承担消费适配与集成验证。格式、数据集、方案规则和生成器版本分别记录，产物带哈希和质量覆盖清单。

迁出仓库时移动的是自包含源模块，并将主项目接入改为固定版本资源；是否用Git submodule、源码vendoring或离线发布归档再决定。不得使用浮动分支或构建时自动抓在线最新版本。兼容性和来源验证不因拆分省略。

当前目录只有文档，故尚不宣称“独立构建/运行验证通过”。启动模型/工具试点前先形成相关ADR；实现后再执行迁出测试与独立门禁。
