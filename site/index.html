安装（macOS 13+，universal）

图形安装（推荐）

  1. 打开 Lampyris-0.1.8-universal.dmg，双击「安装萤火虫」。
  2. 点「安装」；安装器会保留配置与个人词库，并自动备份旧版本。
  3. 按 ⌃Space，或在输入法菜单中选择「萤火虫」。

命令行安装（备选）

在终端粘贴执行（安装到当前用户，不需要 sudo）：

curl -fsSL -o /tmp/lampyris.zip https://github.com/EasyIndie/EasyInputMethod/releases/latest/download/Lampyris-0.1.8-universal.zip && rm -rf /tmp/lampyris && ditto -x -k /tmp/lampyris.zip /tmp/lampyris && "$(find /tmp/lampyris -maxdepth 3 -name install.sh | head -1)" --app "$(find /tmp/lampyris -maxdepth 3 -name Lampyris.app -type d | head -1)"
  • 安装器会校验 Developer ID 签名、hardened runtime 与公证；校验失败会拒绝安装。
  • 安装后自动注册输入源；用 ⌃Space 或输入法菜单选中「萤火虫」即可（若菜单里还没出现，重启登录一次）。
  • 同版本重复执行无操作；已有不同版本需先卸载（见下）。
  • 对应源码（GPL-3.0 §6(d)）在同一 Release 页：Lampyris-0.1.8-source.tar.gz。

卸载

目前使用下面的命令卸载：脚本会切回 ABC、禁用并移除输入源（DMG 与命令行安装均适用）：

curl -fsSL -o /tmp/lampyris.zip https://github.com/EasyIndie/EasyInputMethod/releases/latest/download/Lampyris-0.1.8-universal.zip && rm -rf /tmp/lampyris && ditto -x -k /tmp/lampyris.zip /tmp/lampyris && "$(find /tmp/lampyris -maxdepth 3 -name uninstall.sh | head -1)" --input-source-removed
  • 默认卸载会备份旧应用，保留 ~/Library/Application Support/Lampyris/ 下的配置与个人词库。
  • 如果宿主仍在运行，先注销一次再执行；旧输入源条目会在下次登录后消失。
  • 彻底清除用户数据请由你自己删除该目录（安装器不提供静默清库参数）。

  • 输入法本身零网络；更新检查需手动点击菜单「检查更新…」或按 ⌥G（可在设置中改键）。
  • 升级：在输入法菜单点「检查更新…」或按 ⌥G；也可下载新的 DMG 覆盖安装（保留配置与词库）。

特性

  • 默认混输：五笔能打则快，空码自动出拼音候选。
  • 零网络、零遥测、无账号、无广告、无云同步。
  • 配置唯一（config.toml）且改动即时生效；用户词库本地、可导出/导入。
  • 轻量：核心码表约 0.5 MB，安装包 < 15 MB。
