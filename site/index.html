安装（macOS 13+，universal）

  • 从 Release 下载 Lampyris-0.1.0-universal.zip，用 Finder 或 ditto -x -k 解压（保留执行权限）。
  • 见包内 README.md 运行安装脚本；注销/重新登录。
  • 「系统设置 → 键盘 → 文字输入」添加「萤火虫 / Lampyris」。
  • 对应源码（GPL-3.0 §6(d)）在同一 Release 页：Lampyris-0.1.0-source.tar.gz。

特性

  • 默认混输：五笔能打则快，空码自动出拼音候选。
  • 零网络、零遥测、无账号、无广告、无云同步。
  • 配置唯一（config.toml）且改动即时生效；用户词库本地、可导出/导入。
  • 轻量：核心码表约 0.5 MB，安装包 < 15 MB。

故障与恢复

配置写坏、词库残留锁、数据文件缺失等，见仓库文档 故障恢复。
