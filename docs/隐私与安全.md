# 隐私与安全（Privacy & Security）

> 本文件定义本项目的隐私承诺、威胁模型与**可验证性**方法。
> 配套：`技术方案.md` §11。

---

## 1. 隐私承诺（对用户）

1. **不联网**：核心输入引擎没有任何网络代码；输入法在离线状态下功能完全可用。
2. **零遥测**：不收集、不上报任何按键、候选、词频、设备信息、崩溃数据。
3. **不出设备**：输入内容、用户词库、配置**永不离开本机**。
4. **无账号**：不需要注册、登录、绑定手机。
5. **无广告/无推广/无弹窗**。
6. **本地学习**：用户词库与词频只存本地，可导出/导入/删除。

> 输入引擎和IMK宿主不联网。ADR-239的网站版独立更新检查程序仅在用户主动检查、且签名构建元数据完整时建立HTTPS连接；没有输入/词库/配置上传、遥测、持久cookie或更新偏好副本。当前开发接入默认关闭，不随正式包分发。服务器仍可见正常连接信息（例如IP），因此独立更新检查程序不宣称零网络。未来可选数据包下载也必须显式触发并校验。

> **反馈入口（完全本地）**：「版本信息」窗口展示诊断信息，提供「复制信息」；「反馈问题」「反馈漏洞」按钮**仅在用户显式点击**时用系统默认程序打开公开 Issues / 安全公告页（异步、不阻塞），App 自身**不建立连接、不发送任何数据**，也不在链接中预填环境信息（ADR-071/074/079/080）。复制显示操作结果；默认浏览器打开失败时保留可复制地址（ADR-102）。因此关闭代理、GitHub 不可达时，反馈信息仍可复制到本地，也不会卡死。

## 2. 威胁模型

输入法是**高权限组件**：它挂进前台进程、读取全部按键、常驻内存。因此：

| 资产 | 威胁 | 缓解 |
|---|---|---|
| 用户按键（含密码、聊天） | 引擎被植入键盘记录/后门 | 全开源可审计；核心 `forbid(unsafe_code)`；无网络代码 |
| 用户词库 / 配置 | 被读取或外传 | 只读自己数据目录；无网络 |
| 词典 / 配置文件（**唯一不可信输入**） | 恶意构造文件触发解析漏洞 | 解析器 fuzz；长度/深度上限；`catch_unwind` 边界 |
| 二进制供应链 | 被篡改/投毒 | 可复现构建 + 签名 + SBOM + 依赖审计 |
| 名字/品牌 | 被劣币冒充 | GPL-3 防闭源抄袭；名称/Logo 保留权利 |

**明确不在威胁模型内**：已 root/管理员被攻陷的系统、硬件键盘记录器、操作系统级别的监视。

## 3. 工程约束

| 项 | 约束 |
|---|---|
| 网络 | `ime-core`/`ime-table`/`ime-pinyin`/`ime-dict` 不依赖任何网络 crate；CI 检查产物符号表无 socket/DNS/getaddrinfo |
| 内存安全 | 核心 crate `#![forbid(unsafe_code)]`；`unsafe` 只在 `ime-ffi` 且集中审查 |
| FFI | `catch_unwind` 兜底；不 panic 穿越；字符串 UTF-8；显式释放 |
| 解析 | 词典/配置解析器用 `cargo-fuzz` 持续 fuzz；限制输入规模 |
| 依赖 | `cargo-deny` 白名单（禁不符许可）+ `cargo-audit`/`osv-scanner`；尽量少依赖 |
| 构建 | 固定工具链（`rust-toolchain.toml` + Docker/Nix）；LTO；可复现 |
| 发布 | 签名（macOS 公证 / Windows Authenticode / Linux 包签名）+ SBOM |

## 4. 可验证性（把承诺变成事实）

不希望用户"相信"我们，而是能**自己验证**：

1. **抓包验证**
   - 提供 `scripts/verify-no-network.sh`：在 macOS 用 `nettop`/`lsof`，Linux 用 `ss`，Windows 用 `netstat`，检查输入法进程**无外部连接**；有则返回非零。
   - 文档说明如何用 Wireshark/Little Snitch 自行验证。
2. **符号检查**
   - CI 对产物运行 `nm`/`objdump`，断言不含网络相关符号。
3. **依赖清单**
   - 每个 release 附 SBOM（CycloneDX）与 `cargo tree`。
4. **可复现构建**
   - 提供 `scripts/reproduce.sh`，第三方在同环境构建应得到一致产物（或可验证的差异说明）。
5. **源码审计**
   - 核心逻辑开源、`forbid(unsafe_code)`，便于人工审计。

## 5. 数据处理细节

| 数据 | 位置 | 生命周期 | 是否加密 |
|---|---|---|---|
| 用户词库 / 词频 | 本机数据目录 | 用户可删 | 可选（后续） |
| 配置 | 本机 `config.toml` | 用户可改可删 | 否（本就用户可见） |
| 组合缓冲 / 预编辑 | 内存 | 上屏或取消即释放 | — |
| 语音录音（P6，若实现） | **仅内存** | 识别完立即丢弃，**不落盘** | — |
| 崩溃日志 | 无（不采集） | — | — |

## 6. 漏洞响应

1. **安全渠道**：`SECURITY.md` 提供私下报告方式（邮箱/私密 issue）。
2. **响应时限**：确认后尽快修复并在 release notes 说明（开源项目尽力而为）。
3. **不追溯用户**：修复不依赖、不采集任何用户数据。

## 7. 给审阅者的核对清单

- [ ] `Cargo.toml` 中核心 crate 无网络依赖
- [ ] 核心 crate 有 `#![forbid(unsafe_code)]`
- [ ] 全仓库无遥测/统计代码
- [ ] 全仓库无配置写入 `UserDefaults`/注册表（见 `配置架构.md` R1）
- [ ] `scripts/verify-no-network.sh` 通过
- [ ] 解析器有 fuzz 目标
- [ ] release 附 SBOM 与可复现说明

## macOS 发布附件（ADR-032）

`packaging/macos/prepare.sh` 仅离线本地打包（cargo metadata/vendor --locked --offline）；CycloneDX 1.5 清单覆盖 ime-ffi 的锁定依赖闭包，附原始依赖许可、完整提交源码及 vendor、默认数据登记及许可、cargo tree、SDK/架构/工具链记录和 SHA-256。没有用户词库或配置。Apple 公证上传只在独立 `sign.sh --submit` 命令执行，构建和准备不触发。

第三方可使用**源码包**中 vendor 离线构建；相同 Swift/SDK/架构比较未签名载荷，暂不声称不同 SDK 或带签名 ZIP 字节一致。最终正式 IMK 宿主仍须执行进程连接检查与多应用长时验收，源码符号检查不能替代动态外联验证。

生产macOS宿主不记录按键字符、键码或修饰组合；临时Ctrl诊断日志已由ADR-114移除。资源/ABI初始化失败可保留非输入内容诊断。零网络符号扫描不能替代最终包的独立零外联验证。

### ADR-159：本地排序权重，不是打字统计

现有用户词库TSV的词频列可用作学习权重：五笔主动选择后项给予更强信号。该值不代表实际输入次数，不采集整句、文档、应用身份、剪贴板或时间历史，也不用于统计/上报。格式仍v1，无新数据库、配置副本或网络依赖；只在用户主动输入选择路径更新本地词库，删除精确词条沿既有接口。
