# 五笔输入法：从零开始理解它怎么工作

> 面向**第一次接触五笔**的读者，也面向想看懂本项目数据（码表、根序表、勘误表）的人。
> 本文只讲五笔86；查数据字段、判定规则请看 [`standards/wubi86/spec-1.0.md`](standards/wubi86/spec-1.0.md)，
> 项目里的具体数字看 [`../HANDOFF.md`](../HANDOFF.md)。

---

## 1. 一句话说清五笔是什么

**拼音输入法**是"我怎么读"，**五笔**是"**我怎么写**"。

五笔把每个汉字当成**积木**：先记住 25 个键各自代表哪些"积木块"（叫**字根**），
打字时按**书写顺序**把字拆成几块，敲出这几块所在的键，字就出来了。

所以五笔的优点是：

| 好处 | 原因 |
|---|---|
| 不认识的音也能打 | 只看字形，不看读音 |
| 重码少、几乎不用选字 | 一个四码通常只对应一个字 |
| 打词组更快 | 词组有固定取码规则，四键一个词 |

代价是：**要背字根、要练拆字**。本文就是把这两件事讲清楚。

## 2. 五个笔画，五个区

所有汉字笔画归成 5 类，编号 1–5：

| 代号 | 笔画 | 名称 | 例 |
|---|---|---|---|
| 1 | 一 | 横 | 一、二、三 的横 |
| 2 | 丨 | 竖 | 十、干 的竖 |
| 3 | 丿 | 撇 | 人、禾 的撇 |
| 4 | 丶 | 捺（含点） | 火、文 的点 |
| 5 | 乙 | 折（所有带拐弯的） | 了、也、马 的折 |

键盘上 25 个字母键被分成 5 个**区**，每区 5 个**位**：

```
区1（横）  G(11) F(12) D(13) S(14) A(15)
区2（竖）  H(21) J(22) K(23) L(24) M(25)
区3（撇）  T(31) R(32) E(33) W(34) Q(35)
区4（捺）  Y(41) U(42) I(43) O(44) P(45)
区5（折）  N(51) B(52) V(53) C(54) X(55)
```

**区号 = 该区字根首笔的笔画**。这就是"五笔"名字的来源：五种笔画，五个区。

## 3. 字根：键上的"积木"

每个键上放着一组形状相近的部件，叫**字根**。背下来这 25 句口诀就够了（五笔86 标准助记词）：

```
11 G  王旁青头戋（兼）五一
12 F  土士二干十寸雨
13 D  大犬三羊古石厂
14 S  木丁西
15 A  工戈草头右框七

21 H  目具上止卜虎皮
22 J  日早两竖与虫依
23 K  口与川，字根稀
24 L  田甲方框四车力
25 M  山由贝，下框几

31 T  禾竹一撇双人立，反文条头共三一
32 R  白手看头三二斤
33 E  月彡（衫）乃用家衣底
34 W  人和八，三四里
35 Q  金勺缺点无尾鱼，犬旁留叉儿一点夕，氏无七

41 Y  言文方广在四一，高头一捺谁人去
42 U  立辛两点六门疒
43 I  水旁兴头小倒立
44 O  火业头，四点米
45 P  之宝盖，摘礻（示）衤（衣）

51 N  已半巳满不出己，左框折尸心和羽
52 B  子耳了也框向上
53 V  女刀九臼山朝西
54 C  又巴马，经有上，勇字头
55 X  慈母无心弓和匕，幼无力
```

三种特殊角色，一定要分清：

| 概念 | 是什么 | 例子 | 怎么打 |
|---|---|---|---|
| **键名字** | 每个键的"代表字"，口诀第一个字 | 王、土、大、木、工、人、火 | **把该键连按 4 次**：王 `gggg`、人 `wwww` |
| **成字字根** | 本身就是字、又是字根的字 | 马、竹、方、九、广 | **报户口 + 首笔 + 次笔 + 末笔**：方 `yygn` |
| **普通合体字** | 其余所有字 | 汉、是、照 | 见 §5 |

> **报户口**：先按该字所在的键（方 在 Y，所以第一码是 Y），再按它的第一、二、末笔画所在的键。

## 4. 拆字：把一个字拆成几块

四条规则，按优先级用：

1. **书写顺序**：按你写字的顺序从左到右、从上到下、从外到内取；
2. **取大优先**：能凑成大字根就别拆小（"章"取「立早」，不取「丶一丿…」）；
3. **兼顾直观**：拆完还要"像"，别拆得看不出原字；
4. **能连不交、能散不连**：笔画相连的优先于交叉的，能分开的优先于连着的。

拆完得到的**块序列**，就是这个字的**根序**。

> 注意：**根序不是"字形结构"，而是"取码顺序"**。比如「是」取「日 一 龰」，
> 并不是把"是"真的切成三块，而是按取码规则取这三段。

## 5. 取码：四种情形

五笔单字**最多 4 码**。按根数分情况：

| 情形 | 规则 | 例子 |
|---|---|---|
| 4 个根或更多 | 取 **第 1、2、3、末** 个根 | 照 `jvko` = 日+刀+口+灬；键 `qvfp` = 钅+彐+聿+廴 |
| 正好 3 个根 | 3 根 + **识别码** | 是 `jghu` = 日+一+龰+U |
| 正好 2 个根 | 2 根 + **识别码** | 汉 `icy` = 氵+又+Y |
| 1 个根（成字字根） | 报户口 + 首/次/末笔 | 方 `yygn`、马 `cnng` |
| 键名字 | 同键按 4 次 | 王 `gggg` |

**关键点**：不足 4 码时**不是随便补一个字母**，补的是下面这套**识别码**。

---

## 6. 识别码：为什么需要它，怎么算

### 为什么需要

「氵+又」只有两码 `ic`，但同码字很多（汉、汪、汁…），单靠两码分不清。
五笔的解法是：再加一位"**末笔 + 结构**"的编码，把重码拉开。

### 怎么算

**识别码 = 末笔画的区号 × 结构的位号**：

| 末笔 \ 结构 | 左右型(1) | 上下型(2) | 杂合型(3) |
|---|---|---|---|
| 横(1) | **G** (11) | **F** (12) | **D** (13) |
| 竖(2) | **H** (21) | **J** (22) | **K** (23) |
| 撇(3) | **T** (31) | **R** (32) | **E** (33) |
| 捺(4) | **Y** (41) | **U** (42) | **I** (43) |
| 折(5) | **N** (51) | **B** (52) | **V** (53) |

三种结构怎么分：

- **左右型**：江、和、汉（能左右切开）
- **上下型**：字、是、花（能上下切开）
- **杂合型**：本、国、这（包围、穿插、独体）

### 三个完整例子

| 字 | 拆 | 末笔 | 结构 | 识别码 | 全码 |
|---|---|---|---|---|---|
| 汉 | 氵 + 又 | 丶(捺4) | 左右1 | **Y** | `icy` |
| 本 | 木 + 一 | 一(横1) | 杂合3 | **D** | `sgd` |
| 字 | 宀 + 子 | 一(横1) | 上下2 | **F** | `pbf` |
| 是 | 日 + 一 + 龰 | 丶(捺4) | 上下2 | **U** | `jghu` |

**两个必须记住的特例**（新手最容易错）：

1. **带「力、刀、九、七、万」等，末笔一律算"折"**：如「万」取「丆+乚+识别码 V」`dnv`；
2. **包围结构的末笔取被包围部分的末笔**：如「远」的末笔不是"辶"的，而是"元"的末笔。

## 7. 简码：少打几个键

全码 4 码，但高频字可以少打：

| 级别 | 键数 | 例子 |
|---|---|---|
| **一级简码** | 1 键 + 空格 | 一 `g`、地 `f`、是 `j` |
| **二级简码** | 2 键 + 空格 | 学 `ip`、时 `jf` |
| **三级简码** | 3 键 + 空格 | 是 `jgh`、了 `bnh`（部分字） |

简码不是"缩写"，而是**官方指定的高频取码**：25 个一级简码、约 600 个二级、三千多个三级。
**全码永远可用**，简码只是快捷方式。

---

## 8. 词组：四键一个词

| 词长 | 取码规则 | 例子 |
|---|---|---|
| 2 字 | 每字取**前两码** | 数学 `oip` → 「数」前两码 OI + 「学」前两码 IP |
| 3 字 | 前两字**首码** + 第三字**前两码** | 计算机 `ytsm` |
| 4 字 | 每字**首码** | 中文输入 `kyfl`（示例） |
| 5 字以上 | 前 3 字**首码** + **末字首码** | 中华人民共和国 `kwwl` |

## 9. 完整走一遍：打「键」字

```
第 1 步  拆：钅 + 彐 + 聿 + 廴       （按书写顺序，取大优先）
第 2 步  找键：钅→Q   彐→V   聿→F   廴→P
第 3 步  4 个根 ⇒ 取一二三末 ⇒ 恰好 4 码
第 4 步  敲 qvfp  ⇒  「键」
```

再走一个「学」：

```
拆：丷 + 冖 + 子            （3 个根）
找键：丷→I   冖→P   子→B
不足 4 码 ⇒ 补识别码：末笔「一」(横1)，结构「上下」(2) ⇒ F
全码：ipbf        简码：ip（二级）
```

## 10. 本项目的「学 · 练 · 用」怎么对上这套原理

| 阶段 | 产品里的东西 | 对应本文哪一节 |
|---|---|---|
| **学** | 每个字给出「字根序列 + 键位 + 识别码理由」 | §4–§6 |
| **练** | 按根序/识别码/简码出题，答错给理由 | §5–§7 |
| **用** | 真打字，候选按码表排序 | §7–§8 |

学习区显示的一行长这样（本项目实际数据）：

```
是  jghu   full   日:j 一:g 龰:h   U|捺|上下   简码 一 J · 三 JGH
```

读法：全码 `jghu`；三个字根「日(j) 一(g) 龰(h)」；识别码 U 的理由是"末笔捺 + 上下结构"；简码有一级 `j` 和三级 `jgh`。

## 11. 核心概念表（看懂项目文档必备）

### 11.1 五笔本身

| 概念 | 含义 |
|---|---|
| **字根** | 键上的积木块（见 §3 口诀） |
| **键位** | 字根 → 哪个键（如 钅 在 Q） |
| **键名字** | 每键代表字，连按 4 次（王 `gggg`） |
| **成字字根** | 本身是字的字根，报户口+首/次/末笔（方 `yygn`） |
| **根序 / 拆字** | 取码的字根序列（不是字形切分） |
| **全码** | 完整 4 码（不足则补识别码） |
| **识别码** | 末笔×结构的第 4 码（§6 网格） |
| **简码** | 一/二/三级高频取码（§7） |
| **末笔约定** | 力刀九七万算折；包围取内部末笔（§6 特例） |

### 11.2 本项目的数据层（重要：别混淆）

| 表 | 位置 | 内容 | 谁用 |
|---|---|---|---|
| **码表** | `data/generated/wubi86-core.tsv` | `码 → 字 → 词频` | **引擎**（真正决定打什么出什么） |
| 单字全码表 | `data/generated/wubi86-single.tsv` | `码 → 字` | 生成用 |
| 简码表 | `data/sources/wubi86-level{1,2,3}-codes.tsv` | `简码 → 字` | 简码/练习池 |
| **根序表** | `data/learning/wubi86-root-order.tsv`（D25） | `字 → 字根序列 + 键位 + 依据` | 教学解释、走查 |
| **学习运行时** | `data/generated/B0-runtime.tsv` | 码表 + 根序 + 识别码 + 简码，一行一字 | App 学习区 |
| **勘误表** | `data/learning/wubi86-code-errata.tsv`（D26） | `字 → 原码 → 正确码 + 同族证据` | 码表纠错（见 §12） |

一句话记：**码表是"字典"，根序表是"为什么这么拆"，勘误表是"字典哪条错了、凭什么"**。

### 11.3 项目的硬约束

| 名字 | 含义 |
|---|---|
| **学 = 用** | 学习区教的全码，引擎必须真能打出来（`test-learning-consistency.py` 强制） |
| **标准 v1 / LWS-86** | 判一个字的拆法够不够格算 `full` 的规则：字根合法、键位一致、根数对、识别码可推 |
| `full` / `partial` / `unknown` | 拆法已证 / 未证但有用 / 完全未知；**只教 `full`，`partial` 标注"待核验"** |
| **PUA 占位** | 数据源里认不出的字形用私有区码位占位，**绝不进产物** |
| **不猜** | 拼不出来就留 `partial` 并写清缺什么，不编一个像样的拆法 |

## 12. 为什么"覆盖率"这件事值得做

早期数据只有 **91.5%** 的常用字能给出发音/拆法齐全的解释，剩下的是"码表说有，但拆法对不上"。
对一个教学型输入法来说，这等于**10 个字里有 1 个不能教**。

我们做的事是：给每个字**逐位验证**「第几位是哪个字根、在哪个键、为什么」，
能自证的转 `full`，不能的写下卡点。现在一级常用字是 **99.9%**，
剩下几个字卡在"码表本身可能印错"或"字形无法确认"上——那种情况我们宁可标注，也不编。

**码表勘误**就是这种情况的产物：比如「酶」的码表写作 `sgtu`，但同族 5 个字
（每 `txgu`、海 `itxu`、梅 `stxu`、悔 `ntxu`、霉 `ftxu`）证明应该是 `sgtx`，
于是登记一条勘误，并**同时**改引擎码表与教学数据（否则"学"和"用"会不一致）。

## 13. 新手最常踩的 6 个坑

| 坑 | 正确做法 |
|---|---|
| 按"结构"拆，不按取码顺序 | 取码顺序优先（§4），"是"取「日一龰」不是切成三块 |
| 不足 4 码时乱补字母 | 补**识别码**（§6 网格），或确认它是简码 |
| 忘记"力刀九七万末笔算折" | 「万」是 `dnv` 不是 `dne` |
| 把简码当"缩写" | 简码是固定高频码，全码永远可用 |
| 以为字根要背 200 多个 | 先记 25 个键名字 + 口诀，其余靠拆字练习上手 |
| 拆不出来就硬猜 | 本项目里对应"不猜"原则：标注待核验，而不是教错 |

## 14. 下一步怎么练

1. 背 25 句口诀（§3），先做到"看到字根知道键"；
2. 练 §5 的四种取码情形 + §6 的识别码网格（这部分最容易错）；
3. 用本项目的「学 → 练」循环：学一个字看根序理由，练时答错会告诉你是"字根错"还是"识别码错"；
4. 打词组（§8）比打单字快得多，熟练后再上简码。
