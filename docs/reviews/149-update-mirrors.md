# 149 更新源多镜像回退（ADR-270）

## 交付

- 配置：`update.feed_mirrors`（新类型 `UrlList`：逗号/换行分隔、≤8、https、无凭据/fragment、去重保序）；
  设置「更新」分区自动出现第二个输入框（Schema 驱动，无手写 UI）。
- 更新程序：`FeedSource.effectiveFeeds` 生成「主源 → 镜像」有序列表（去重、只留 https），
  `--check` 逐个尝试；任一源成功（有更新/已最新）即停止；全失败才非零退出。
  输出里标明命中的来源主机（便于诊断镜像）。
- 安装器：`upgrade.py` 新增 `--feed-urls`，同样按顺序回退；重定向策略调整为
  **同主机直链放行**（自建镜像托管 ZIP）+ GitHub 资产主机白名单，其他跨主机跳转仍拒绝。
- 文档：`docs/更新源与镜像.md`（区域镜像搭建、镜像要求、验证命令、边界）。

## 验证

| 范围 | 结果 |
|---|---|
| Rust 配置 | 18 项（新增镜像列表：空值、多值归一化、http/凭据/fragment 拒绝、>8 拒绝） |
| ime-ffi | Schema 21 项布局通过 |
| 更新程序 | 14 项（新增：镜像有序去重、非法项忽略、经 ime-config 读取镜像） |
| 安装器 | 24 项（新增：同主机镜像下载放行、多源跳过不可用项） |
| 设置/预览 | 21 项设置、5 分区通过 |

## 边界

- 不做自动测速/择优；镜像滞后可能延迟看到新版本；不支持带认证的私有源。
- 多公钥/密钥 ID 轮换、渠道/架构筛选仍按 ADR-267 待做。
- 未在真实大陆网络环境验证镜像可达性；未发新 Release、未改已装 v0.1.0 生产包。
