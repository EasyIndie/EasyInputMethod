# 068 — 单行循环菜单与设置/关于快捷键实机验证

2026-10-18 凌晨，按 ADR-206（取消模式子菜单、单行循环、标题显示模式）与 ADR-207（设置/关于快捷键）实现并在 B 上实机验证。A 未操作。

## 本机样式限制（已定论）

IMK 输入菜单只保留 **纯标题 + 真实快捷键**：自定义 `NSView`、`NSMenuItem.badge`、塞进 key equivalent 列的任意文本都会被剥离（本轮用三个构建分别截图核对）。因此"左侧标题 + 右侧状态"只能通过标题本身表达——菜单行标题改为 `混输模式` / `五笔模式` / `拼音模式`，右侧为快捷键列。

## 结果

菜单（实机截图与 AX 树一致）：

```
混输模式        ⌃⇧M
中文输入        ⇧
半角输入        ⇧空格键
简体输入        ⌃⇧F
中文标点        ⌃.
设置            ⌃,
关于            ⌃⇧A
```

- 点击模式行：`混输→五笔→拼音→混输` 三次循环全部生效，标题与 `config.toml` 的 `mode` 同步；测后 `mode=mixed`、配置字节回到 `65643c64…`。
- `⌃,` 打开设置窗口（标题“输入 — 萤火虫”）。
- `⌃⇧A` 打开“关于”窗口。
- 菜单项数：源列表 + 名称头 + 8 个产品项 + 系统项；无子菜单、无箭头、无自绘 view。
