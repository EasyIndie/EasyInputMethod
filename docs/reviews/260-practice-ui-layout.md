# 260 — 练习窗口 UI 修正：不再压字、不越界、两类题型共用一套版式

- 日期：2026-11-06　｜　来源：用户截图反馈「练习的 UI 界面需要优化调整」
- 现象（截图）：题干汉字**压在题型切换控件上**；中部大片空白；底部「已练 N 字」被窗口边缘裁掉。

## 1. 根因

旧版用手写 frame 且**从窗口底部往上算**（非翻转坐标），高度估算不准就会：
题干与顶部控件重叠、进度行落到窗口之外。题型 C 的两行按钮还额外占用纵向空间，更容易冲突。

## 2. 改法

- 内容容器改为**翻转坐标**（`isFlipped = true`），一律**从顶部往下**排：
  题型切换 → 题干 → 提示 → 作答区 → 反馈 → 按钮 → 进度；
- 固定窗口尺寸 **460 × 336**，各行显式坐标（A 与 C 共用同一套纵向基准）：
  20 / 56 / 120 / 144–210 / 218 / 264 / 300；
- 题干 40pt **居中**；提示与反馈居中；输入框整宽；
- 题型 C 增加「末笔」「结构」两个小标题，选中后标题就地更新为「末笔 撇」；
- 底部按钮等距（120×28，间距 10），进度行固定在最下方、不再越界；
- 新增**版式自检**（`layoutProblemsForTesting`）：A/C 两种题型下，所有可见控件必须落在内容区内，
  且不得与顶部题型控件重叠——离线回归里断言为空。
