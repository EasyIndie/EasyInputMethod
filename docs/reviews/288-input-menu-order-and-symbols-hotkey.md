# 288 — 输入法菜单固定顺序 + 符号面板快捷键调整（ADR-360）

> 2026-11-15。人工验收反馈：菜单缺「练习」入口、顺序无策略、`⌥S` 易冲突。

## 1. 问题

1. **入口缺失**：正式宿主的输入法菜单只有「检查更新… / 设置 / 关于 / 使用指南…」，
   没有「练习…」「符号与表情…」；预览菜单连「使用指南…」也没有，人工验收看到的是不完整菜单。
2. **顺序无策略**：入口按添加历史排列，新增一个就要重新记一次位置。
3. **快捷键冲突**：`hotkey.open_symbols = "alt+s"` 与用户已有快捷键冲突。

## 2. 固定顺序

```text
状态区（IMK 契约，永远在最前）
  模式 · 中英 · 全/半角 · 简/繁 · 标点
────
学习与工具
  显示学习区（勾选）· 练习… · 符号与表情… · 使用指南…
────
应用
  检查更新… · 设置… · 关于
────
异常状态（仅出错时出现，恒在最后）
```

规则：

- 顺序只写在 `InputMenuAction.sections`（`platforms/macos/Sources/InputMenu.swift`），正式宿主与预览共用；
- 新增入口**只能追加到所属组末尾**，并同步更新三处探针；
- 每组之间一条分隔线；错误状态不进固定顺序。

## 3. 新增入口

| 菜单项 | 快捷键来源 | 行为 |
|---|---|---|
| 显示学习区 | `hotkey.toggle_wubi_learning`（默认 ⌥L） | 与 ⌥L 同源，切换显示偏好并打勾，不提交当前组合 |
| 练习… | `hotkey.open_practice`（默认 ⌥K） | 打开离线练习窗口 |
| 符号与表情… | `hotkey.open_symbols`（默认 **⌃⌥E**） | 先提交当前组合，再把选中符号插入原插入点；预览里插入预览输入区 |
| 使用指南… | 无 | 打开完整使用指南 |

## 4. 快捷键

`hotkey.open_symbols` 默认 `alt+s` → **`ctrl+alt+e`**：

- E = emoji，保留语义首字母；
- `⌥S` 与应用快捷键冲突（用户反馈）；`⌥E` 在 ADR-209 已确认是死键，不能单独使用；
- 双修饰键同时避开「仅 ⌥ + 字母」的应用快捷键面；
- **已有显式配置不静默覆盖**：老用户文件里写了 `alt+s` 就继续用，设置页显示实际值。

- `input-menu.swift`：断言分组与标题顺序、只有「使用指南」无快捷键；
- `controller-menu.swift`：正式宿主冷菜单 **14 项**、两条分隔线、位置与快捷键全部核对；
- `preview-menu.swift`：预览菜单同序，7 个动作各触发一次回调；
- `settings-presentation.swift`：设置页显示 `⌃⌥E`；
- UI 快照：设置快捷键页已重新渲染；快照缓存键加入 `libime_ffi.a`，Schema 默认值变化不再复用旧二进制；
- `make macos-offline-tests` 68 文件 / 337 例 PASS；`make verify` PASS。
