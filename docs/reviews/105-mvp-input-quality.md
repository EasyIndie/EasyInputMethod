## 排序：已复现与已修复

| 机制 | 最新源码证据与结果 |
|---|---|
| 加码后集合变化 | 合成回归 a→ab→退格a中，ab精确集合变化属于正常查询，退格恢复原顺序 |
| 学习改变单字次序 | 新测试在旧实现失败：最高学习值使低频单字前移；现单字学习增量0，保持基础频次顺序 |
| 词组调频 | 基础分加min(本地学习权重,32)，不会无限跨越词频差距；同分基础频次/文字稳定排序；不实行所有单字优先 |
| 精确/补全路径不一致 | 新测试在旧实现失败：核心重算未比较is_prefix；现与个性化都维持精确在补全前 |
| 精确/模糊拼音 | 保留既有边界，极大学习不能越过；回归通过 |
| 混输插入 | ADR-161首页最多两个非模糊拼音仍保留；其数量变化仍可移动页尾五笔，这是已知政策限制，**未宣称解决全部位置变化** |
| 显示与选择 | 核心/FFI和真实词表回归通过，含数字、后页、退格、重复输入与Store销毁重载；不是原生IMK实测 |

学习记录不删除、不重置，无格式迁移。首选普通上屏加1，主动后项仍按ADR-159记录更强偏好，但显示排序受新上限约束；没有独立显式置顶功能，主动选择不等同置顶。学习在下一组合生效。词组在基础分接近单字时仍可影响单字的绝对位置，保证的是单字基础排序，不是每个单字永远固定在某个数字键。

FFI隔离回归覆盖生僻单字反复选择、退格重输、翻页数字提交、五笔/混输与Store重载；既有三模式切换、四码唯一及跨引擎歧义、空格/回车/标点/Esc等测试保留。未拿到用户的真实输入码与已装词库最小例子，不能把上述机制认定为用户全部跳序根因。

## 常用词与拼音

先比较20k/30k/50k，不直接全量打包337,231词组。探索测量的进程RSS分别约27/33/43MiB，30k与50k均高于30MB量级，因此冻结20k基础词+训练词；每表预算800,000 B，ADR明确替代旧体积策略。保留源权重、精确匹配边界和每引擎256条上限，低频补全不会绕过精确码。基础词按频次，领域词取训练集中已有来源条目，个人词走既有本地词库，未收录长尾仍需个人词或拆字输入。

七个指定词均已可达：输入法、五笔、拼音、词库、候选、开发者、人工智能。真实表回归覆盖纯模式和混输、连续全拼/显式音节分隔以及显示候选的数字提交。新增词而不改查询时，`rengongzhineng`仍不可达；合成测试确认最长切分偏离词读音。ADR-228以排序紧凑拼写索引作有条件整词回查，规范读音码用于学习，不改隔音符和xian单音节，不重写解码器。

个人词库复用现有功能。新增FFI隔离工作流验证：添加错词→精确删除→添加纠正词→导出→删除→导入→数字上屏→Store重载，错误词消失、纠正词持久化。既有原子写失败、坏文件导入与跨Store回归继续通过。此为逻辑/FFI证据，原生成功反馈仍沿IT-18待验。

## 覆盖率与选词成本

D15共433项：292训练、69探索验证、72冻结后保留。最初自动划分误把用户已指定的“候选”归为保留项，回归纠正为训练项；最初69项探索数据参与了规模比较，因此**不包装为独立保留结果**。20k规模冻结后另编72项，未据结果追加词条或改变上限。它们都属于项目自编工程集，不等同独立用户盲测。

对照两组均运行同一最终引擎，仅替换核心词表，隔离数据覆盖效应。每页9、无个人词、关闭自动提交、开启基础模糊音；五笔使用完整词组码，拼音比较全拼和显式分隔，选成本较低的可达写法。逐键输入、枚举分页并用数字实际提交；可达定义为引擎256候选范围内命中，首页为前9。**不包含用户能否记住编码、简码成本、自由聊天效率或自然句子输入。**
