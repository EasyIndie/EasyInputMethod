## D2 仍未完全解决

`caretLookupIndex` 只在部分情况取到可用矩形。实测：

- 首行有文字时 HUD 出现在该行上方 `(130,54)`（可接受）；
- 加入换行/空行后，`attributes` 返回空或异常矩形，HUD 退化到鼠标 `(369,257)` 或屏幕下方 `(161,774)`；
- 截图 `05-hud-caret.png`、`05-hud-caret-line4.png` 可见 HUD 与光标不一致。

结论：IMK 的 `attributes(forCharacterIndex:)` 在空行/末尾并不可靠，靠索引微调无法稳定贴住光标。
下一步候选方案：
1. 记住「最近一次有效光标矩形」，仅在从未取到时退回鼠标；
2. 通过 AX 读取聚焦文本元素的插入点/选区矩形（需要辅助功能权限，且部分应用不暴露）；
3. 接受为已知限制：HUD 走「最近有效位置/鼠标」，不阻塞功能。
