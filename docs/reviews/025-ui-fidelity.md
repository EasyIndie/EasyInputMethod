# 025：UI改版还原度偏差分析

2026-10-15。用户反馈实际改版与设计稿还原度低。本轮仅调查、生成对照和记录后续任务，不改产品代码、不重新安装或发布。

结论：反馈成立。功能/原生控件改造完成不等于统一稿视觉还原完成；本轮核实存在规格分叉、旧通用布局复用及视觉对照门禁缺失。教学能力后移是已明确的范围选择，但不能解释设置、关于等既有能力的全部视觉偏差。

## 依据与证据边界

设计基准是docs/design/review-20261014/统一设计方案.md及其50图，不以早期v1草稿比较。实际实现采用后来docs/design/mvp-ui.md子集（ADR-165…168），两份规格没有完整逐屏映射/偏差清单。基础UI实施范围变小，但没有同步出一套由用户审阅的最终子集视觉基准。

本轮重新执行生产组件的candidate/settings/tools三个原生离屏测试，各1项均通过；另用同候选文字/页码渲染当前CandidateWindow，避免用2项/4项不同样例解释全部宽度差异。原生组件运行时代码与已安装50fdac3一致，私有配置，不激活窗口或读取真实词库。参考稿是既有设计资料，实际组件图片全部本轮生成。

原生CUA绑定已安装Lampyris返回timeoutReached -10005，未得到活跃宿主截图。因此这是源码/生产组件视觉还原对照，不声称完成实机全流程UX审计。Product Design audit skill要求“Do not claim an audit if the actual flow could not be accessed and captured.”，本轮遵守此边界。此前11条实机功能通过不是本轮视觉证据。

[同尺度图文对照](025-ui-fidelity/index.html)，图片及SHA清单在同目录evidence.json。所有图2像素=1pt；不把小图拉大、不同控件状态或裁切范围当成字体/按钮缺失。

## 根因

1. **交付基准分裂**：统一稿与MVP子集各有一套信息结构。工程改造完成被表述为UI整体完成，未明确区分“行为/访问性工程通过”和“视觉还原待验”。
2. **用通用组件代替设计呈现**：Schema顺序直出设置、通用诊断窗兼作关于、保留旧提示，省下了定制呈现适配，但没有还原产品信息层级。这不是AppKit限制，也不能全部归因于MVP减功能。
3. **原生图有了，比较门禁没有**：测试验证字号/焦点/翻页/有界布局和配色可读，未把同内容、同主题、同尺度的设计/实现配对作为验收项；静态设计可读不等于产品布局相同。本轮不编造还原度百分比。
4. **稿件本身有固定样例**：400pt候选和650pt设置是原型选择，不能不顾实际候选长度/屏幕约束机械复制；需要把视觉意图转成自适应规则，而不是另做一套布局。

## 建议修正路线（未实施）

1. P0：将统一稿中“不新增能力”的部分锁为MVP视觉基准，逐屏列出保留/延期/平台差异；拆字新功能继续延期。更新MVP子集及任务状态，不再用旧子集自证还原。
2. P0：先候选信息精简及设置分组/对齐/帮助层级。取消常驻D13提示的默认展示属于对外行为调整，先ADR并说明现有提示入口安排，不无声删除。设置Schema/校验/热更新不变，呈现独立适配。
3. P1：候选密度/边界/翻页、关于身份、快捷键摘要/编辑及完整表单sheet；每次一项，有界布局、焦点/选择恢复及错误契约不退化。
4. 每步先出当前生产组件的修正对照稿，经用户审阅再改产品实现；同样例/同状态/同主题/同pt尺度配对，清楚标注窗口内容或完整chrome。既有设计稿不再逐步漂移。
5. 视觉检查独立于工程门禁：必要界面元素、分组/控件顺序、样式/间距/字体令牌、缩放/长文案/亮暗逐项验收。原生控件允许系统差异，不用整图像素阈值逼迫伪造系统外观。
6. CUA可用或取得用户提供的实机图后，补最终已装包候选/四设置pane/关于/词库sheet活跃截图，继续UI04/05产品门禁。后续修复仍按make verify/独立提交/PR全门禁及同包公证；不会静默替换当前安装。

Apple依据2026-10-15核验：官方[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)强调层级、对齐、关联分组与渐进披露；[Settings](https://developer.apple.com/design/human-interface-guidelines/settings)作为原生偏好结构依据，官网JS页使用官方DocC JSON读取。具体pt尺寸/分组/功能范围是项目决策，不宣称Apple强制。使用apple-native-product-design skill，不引入第三方皮肤或框架。
