## 2. 这一版包含的、上一发布版没有的行为

- 更新链路：装包自带更新程序、更新器自更新与「重新打开更新程序」、窗口内卸载（ADR-294/295/296）、`--purge-data` 数据根修复、更新程序定位修复（报告213）。
- 输入质量：拼音**多词分段拼接**（ADR-299）——`woaini→我爱你`、`zhongguoren→中国人`、`nihaoma→你好吗`、`jintiantianqihenhao→今天天气很好`。
- 光标跟随：`CaretPlacement` 统一几何（ADR-301）——行框归一化、候选窗**先下后上**、右边缘**镜像**、三条不变量。
- 可访问性：组合开始播报输入编码（ADR-300）。
- 卸载语义：`keepData` 只保留 `config.toml` 与个人词库（ADR-297）。

判定口径（ADR-033，报告 208 §4 已实证）：

- **身份链**：`.sha256` 校验通过、`SOURCE-COMMIT` = `11abece3…`、`Cargo.toml` 1.0.0 / `build-number` 29 与 `BUILD-INFO.txt` 一致 → 必须一致。
- **数据表**：`wubi86-core.tsv` / `pinyin-chars.tsv` / `pinyin-core.tsv` / `variant-s2t.tsv` → 必须 **4/4 逐字节一致**。
- **可执行文件**：本机 SDK 27.0 / Swift 6.4 vs 构建机 SDK 26.5 / Swift 6.3.3 → `cmp` **预期不同**，记录 `otool -l` 的 `sdk`/链接器差异即可，不据此判失败。
- **静态零外联**：`./scripts/verify-no-network.sh`（或 `make verify-no-network`）通过。
- **运行时零外联**：一边打字一边 `lsof -i -a -p "$(pgrep -x Lampyris)"`，预期**无输出**。
