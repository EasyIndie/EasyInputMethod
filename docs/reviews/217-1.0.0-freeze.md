## 2. 这一版包含的、上一发布版没有的行为

- 更新链路：装包自带更新程序、更新器自更新与「重新打开更新程序」、窗口内卸载（ADR-294/295/296）、`--purge-data` 数据根修复、更新程序定位修复（报告213）。
- 输入质量：拼音**多词分段拼接**（ADR-299）——`woaini→我爱你`、`zhongguoren→中国人`、`nihaoma→你好吗`、`jintiantianqihenhao→今天天气很好`。
- 光标跟随：`CaretPlacement` 统一几何（ADR-301）——行框归一化、候选窗**先下后上**、右边缘**镜像**、三条不变量。
- 可访问性：组合开始播报输入编码（ADR-300）。
- 卸载语义：`keepData` 只保留 `config.toml` 与个人词库（ADR-297）。
