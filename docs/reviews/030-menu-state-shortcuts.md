# 030 状态菜单与快捷键反馈修正

2026-10-16，基线main1621a6d；独立工作树menu-state-shortcuts，ADR-181先于实现提交。用户提供两张实机截图，要求修正状态文案/模式双入口/快捷键按钮和默认键。本轮不操作桌面、不安装、不覆盖主目录既有代码或真实配置。

## 改动

- 中文/英文输入、全角/半角输入、简体/繁体输入及中文/英文标点，按真实会话/配置显示当前状态；点击切换后重新读取并刷新，无布尔勾选。繁体资源异常提示保留。
- 模式一级项有循环动作（混输→五笔→拼音）和当前模式；使用原生attributedTitle的右对齐制表位显示模式，完整文本同步保留在title。二级三项直接选择，共用持久化/会话路径，只有当前模式勾选。写入失败不伪更新显示。
- IMK官方SDK的doCommandBySelector约定sender为命令字典，原chooseMode强制NSMenuItem不可靠；改用三个明确selector，避免依赖跨进程representedObject及sender类型。
- 设置快捷键按钮只显示符号/未设置，不加省略号；不改“设置…”、“新增词条…”等打开工具的入口文案。
- Schema学习区默认Ctrl+Shift+L，全/半角默认Ctrl+Shift+Space；Shift+Space在全新默认配置下不再触发全/半角。学习快捷键保留组合和页码。没有新依赖/新配置项。
- 已有显式配置（包括旧Shift+Space及none）原样保留，不静默覆盖；要应用到旧用户文件须在现有设置中修改。设备B当前仍装1621a6d，真实配置未改。
