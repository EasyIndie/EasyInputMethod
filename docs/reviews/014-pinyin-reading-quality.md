# 014：常用多音读音质量与保守构建权重

2026-10-14，IT-27第二步/ADR-163；仅本地，无安装/推送/UI改造。

## 结果

37个固定纯拼音样例（常用多音读音及基础语法）首项命中22→27，首屏命中36→37。重点：xian先3→1、见1→3、省2→4；xing行2→1、省1→4；bo薄10→5。保留常用次读音：hang行1→1、xiang降8→8、jiao觉4→6、de地2→3。明确记录少量排名下降，不宣称所有词或人群都改善。

同37例混输隔离FFI未出现提前提交；xian先及xing行均第1。既有ni/wo/yu首屏兜底、wang歧义、xi'an隔音符、简拼/v代ü及私有学习重载仍通过。混输继续仅保留两个精确拼音兜底，不保证所有纯拼音第九项都进入混输首页。

## 为什么这样做

旧生成器把全字频次复制到每个读音，缺乏读音证据。仅按词组比例分配会使地de、降xiang等常用次读音跌出首屏，拒绝该方案。最终采用保守分数：D5首读沿原W；次读=max(1,min(W,W/3向下取整+E))。E来自D4权威词音与D10词频交集的合法逐字对齐，每词一次。保留原频次三分之一底线以缓和语料对独立用字/助词的偏差；分数不是读音真实频次/概率。规则固定，无用户参数。

只复用已登记MIT来源D4/D5/D10，源摘要已核对，机器登记pinyin-chars-v2。全部53,087条读音及首读反查顺序不变；单读/首读、词表及五笔权重不变。无运行时语料装载、网络、模型、依赖或格式迁移。

## 验证范围

- 旧同权重函数明确失败后修复；生成器两项回归进入cargo workspace测试，37例默认词表保护集纳入make verify。
- make verify最终144通过、1个既有计时忽略，零诊断；137产物零网络扫描。
- 三来源重复生成，字表逐字节一致；核心词表及其报告逐字节保持不变。CI既有可复现步骤额外检查字表差异。
- Swift/C ABI私有配置及学习回归通过；strict universal通过，仅生成开发包不安装。
- 固定37例本机FFI调用采样，单键最大0.247ms以内；仅工程采样，不等同真实IMK端到端性能或不同设备结果。
