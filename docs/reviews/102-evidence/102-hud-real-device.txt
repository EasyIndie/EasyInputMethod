# 报告 102：真机候选窗与状态 HUD 实测（2026-10-20，A 机）

## 方法

1. 隔离身份包（开发者 ID 公证）选中，TextEdit 独有 fixture 文档取焦点（守卫：前台 + 窗口 ID + 聚焦控件角色）；
2. 按键 `wq` 出现候选窗 → 读宿主窗口（CGWindowList）：候选 531×70、`layer 101`、`onScreen=true`、所在屏=TextEdit 窗口所在屏、前台仍是 TextEdit；窗口截图有真实内容（27 014 字节）。
3. 取消组合后按 `⇧⌃M`（模式切换）触发状态 HUD → 读窗口：400×32、`layer 101`、位置在光标上方 8pt、`alpha=1`、但 **`onScreen=false`**；窗口自身截图有内容（30 种颜色）。
4. 对 HUD 所在屏整屏 2× 截屏三张（切换前 / HUD 期间 / 1.8s 后），按 HUD 矩形裁切后逐像素比对。

## 结果

| 宿主 | HUD 矩形（CG 坐标） | 屏 | HUD 区域像素差异 |
|---|---|---|---|
| 隔离身份包 | (224, −1013, 400×32) | LG 4K（display 2） | `hud vs after = 0/51200`，`hud vs before = 0/51200` |
| 生产包 07bbb2f（对照） | (0, 768, 400×32) | 内建（display 1） | `hud vs after = 0/51200`，`hud vs before = 0/51200` |

结论：状态 HUD 的窗口被创建、定位正确、离屏缓冲里有内容，但**屏幕合成后没有任何像素变化**——用户看不到 HUD。
两个宿主（隔离包与生产包）表现一致；未写入真实学习词库（`user-dictionary.tsv` `2ee1a469…` 前后一致）。
