## 2. 复验中修掉的缺陷

### 2.1 私有数据根没有真正生效（build 41/42）

`quality-samples.sh` 用相对路径的 `OUT`（如 `platforms/macos/build/...`）拼 `LAMPYRIS_SUPPORT_DIR`。
ADR-215 的宿主只接受**绝对路径**，相对值被忽略 → 宿主仍用真实数据根，样本写进用户词库/词库计数，
而脚本的自检只比较了字符串，误以为隔离生效。

修复：
- `OUT` 在脚本开头统一转绝对路径；`PRIVATE_SUPPORT` 非绝对直接 BLOCKED；
- 每个样本前逐个 Lampyris 进程校验 `ps eww` 里的私有根；
- 停宿主改为 `pkill -x Lampyris`（不再只停第一个）。

修复后最终一轮：真实 `config.toml` / `user-dictionary.tsv` / `practice.tsv` 的 SHA 在样本前后**逐字节相同**；
私有根里出现自己的 `config.toml` 与 `user-dictionary.tsv`。

### 2.2 练习/薄弱字路径不跟随私有根（build 41/42）

`PracticeProgress.defaultURL` 与 `WeakChars.defaultURL` 直接从 `Application Support` 拼路径，忽略
`LAMPYRIS_SUPPORT_DIR`。已改为走 `ImePaths.supportDirectory`，并加两条可注入的路径断言。

### 2.3 切模式后没有重建引擎选项（build 42）

`double_pinyin` 依赖 pinyin-only 模式，但宿主切模式后没有重建 `EngineOptions`；双拼要等下一次配置变更才生效，
模式恢复也可能滞后导致 `collect_weak_chars` 跳过。`ImeSession.setMode` 现在切换后调用 `prepare()`。

### 2.4 探针自身的时序/环境问题

- 双拼样本在配置写入后加 2.5s（宿主重建引擎的一拍）；
- TextEdit 首个窗口未就绪时 `axtext` 返回 `NO_WINDOW`：`type_read` 会重试建文档；
- `ime-state.sh` / `multi-display.sh` 里紧挨中文标点的变量改为 `${VAR}`，避免 shell 解析歧义。
