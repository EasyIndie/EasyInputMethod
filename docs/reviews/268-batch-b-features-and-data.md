## 2. 高频字拆解：负面结论（未交付）

目标是把 B0 的 876 条 `partial` 补成 `full`。结论是**现有许可来源做不到**：

- 3,000 字里 876 条 partial，其中 **738 条**是 D2 的补充区私有码位（`U+F00xx`）字根字形未解码，
  不是缺笔画或识别码；
- 现有 PUA 映射只覆盖 BMP 私有区（251 个 PUA 中 184 个可确认、67 个含糊），补充区没有可读字形来源；
- 试过把含糊 PUA 的主导读法按码位键回填：JSON 里可多判 106 条 `full`，但运行时渲染按
  `positionMismatch` 降级回 `partial`，**用户可见效果为零**；强推会让错误字根进入教学，故放弃并还原工具改动；
- N1 字根字形库仍受 ADR-310 的许可阻塞（两款候选字体无许可），需要新的许可来源或人工核验。

结论：U3-4 保持受阻，等 P1-2 的联网调研/授权，不用猜测填数。
