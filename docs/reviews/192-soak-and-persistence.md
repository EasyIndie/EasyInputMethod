# 192 久用与持久化验收（自动化）

## 1. 一条命令

```sh
make macos-soak                 # 默认 5 分钟
MINUTES=2 make macos-soak       # 冒烟
SOAK_MINUTES=3 make macos-auto-acceptance   # 与热键/客户端/延迟一起跑
```

`tools/macos-probe/soak-session.sh` 做三件事：连续键入（6 组不同码轮换）→ 每秒采样宿主网络与 RSS → 重启宿主核对词库。

## 2. 结果（0.1.13/build21，执行 `a3faf05c…`）

| 项 | 结果 |
|---|---|
| 轮次 / 键数 | 111 轮（5 分钟，约 1.7k 键） |
| 网络 | 全程 **0 条 TCP/UDP** |
| 词库 | 568 行 → 568 行；**重启前后一致**（未丢学习结果） |
| RSS 稳态（后 25% 均值） | **20.0 MiB**（阈值 30 MiB） |
| RSS 峰值 / 增长 | 56.3 MiB 瞬时峰值；尾部均值比热身段低 17.2 MiB（**无单调增长**） |

## 3. 关于内存读数的说明（重要，避免误判）

- 宿主 RSS 在 **2.9 – 58 MiB** 间波动：页面被回收时数字下降，候选窗/字体/词库首次触碰时上升。
  因此验收只对**稳态（尾部均值）**设阈值，峰值只记录、不设门禁；判定"是否泄漏"看尾部是否低于热身段。
- 重启宿主后 6 秒读到的 33.7 MiB 属"刚启动还没回落"，静置 30 秒可降到 3 MiB 量级。写报告时必须标出采样时刻，否则同一台机器能得出相反结论。

## 4. 仍未自动化

## 5. 追加：卸载脚本离线回归（同批）

`packaging/macos/tests/test-uninstall-script.py`（随 `make macos-offline-tests` 自动执行，6 项）：

| 用例 | 断言 |
|---|---|
| `--dry-run --purge-data` | 只打印计划，bundle 与 `config.toml` 均在原地 |
| 默认卸载 | bundle 移入 `uninstalled/bundle.*/Lampyris.app`，配置与词库保留 |
| `--purge-data` | `config.toml` 与 `user-dictionary.tsv` 移入 `uninstalled/data.*`，活动目录不再有 |
| 标识不符 | 退出非零、提示「标识不符」、bundle 未被移动 |
| 符号链接 bundle | 退出非零、提示拒绝符号链接 |
| 未安装 | 退出 0、提示「没有萤火虫」 |

- 用假 `HOME` 与假 `pgrep`（返回未运行）隔离，**不接触真实安装与真实宿主**，本机开着生产宿主也能跑。
- 真实卸载流程（移除输入源 → 注销 → 重装）仍需人工；脚本逻辑本身现在有回归保护。
