# 报告 298：练习的确认键改为空格（ADR-371）

日期：2026-11-18 / pi（air）· 分支：`dev`

## 1. 用户反馈

输入法的键位语义是**空格=确认上屏（选候选）**、**回车=上屏原始码**。练习里却用回车进下一题，
练久了会养成与输入法相反的肌肉记忆，正式打字时容易按错。要求：练习的确认键也换成空格。

## 2. 改动

| 位置 | 改动 |
|---|---|
| `PracticeAnswerView` | 新增 `0x20`（空格）分支：已作答时进位；**回车（`0x0D`/`0x03`）不再进位**，改为忽略 |
| `PracticeWindow.handleNavigation` | 窗口级兑底键从 `36/76`（回车/小键盘回车）改为 `49`（空格），识别码题型同样用空格进位 |
| 提示文案 | 按钮/悬停/无障碍："下一题（已作答后空格或 →）"、"输入字母，打满位数自动判分；空格进入下一题；Esc 或 ⌘⌫ 清空" |
| 测试 | 未作答空格不动作 / 已作答空格进位 / 回车不进位 / 重试态空格与回车都不跳题 |

## 4. 练习键盘语义（累计）

| 键 | 行为 |
|---|---|
| 字母 | 写入作答框；**打满本题位数立即判分**（ADR-370） |
| 空格 | 已作答 → 进下一题（与输入法"空格上屏"一致，ADR-371）；未作答 → 无动作 |
| 回车 | **无动作**（输入法里它上屏原始码，练习无对应动作） |
| `→` | 下一题 / 跳过（答错时放弃重试） |
| `←` | 回上一题回看（不重复计分） |
| `⌘↩` | 看答案（未作答时） |
| `Esc` / `⌘⌫` | 清空 |

判对后 0.7 秒仍会自动进位（ADR-369），期间打字母会取消定时并把该字母算作下一题首键。

## 5. 待真机复验

- 打完最后一码立即判分、判对后自动进位。
- 已作答后按空格进下一题；按回车不再进位。
- 判错抖动清空后，重打满位数会再判。
