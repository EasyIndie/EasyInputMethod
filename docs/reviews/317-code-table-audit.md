# 317 · 码表口径审计（C 路线）：6 个末位冲突 + 剩余 7 条

> 日期：2026-11-19 ｜ 关联：ADR-382、报告 306、`docs/tasks/T-ROOT86.md`
> 目的：把"码表说 A、字根表说 B"的冲突逐条定性，而不是硬塞一个根。
> 结论：**4 条判定为"我们的拆法错了"并已修正（旁/藏/骄/戚），2 条判定为码表异常（酶/薛），
> 剩余 7 条按成因分类归档**。一级覆盖率 99.7% → **99.8%**。

## 1. 判定修正的 4 条（错在我们，不在码表）

| 字 | 码 | 原判 | 审计后的解释 | 依据 |
|---|---|---|---|---|
| **旁** | upyb | 4 位全不符 | **六(u) + 冖(p) + 方(y) + 识别码 B** | 方 自身码 `yygn` 的末位是 **N=折**，所以 旁 的末笔是折不是撇 ⇒ 折·上下 = b ✓ |
| **藏** | adnt | 第 3 位 PUA | **艹 + 厂 + 乚 + 丿**（丆 拆一+丿，五根取一三末） | 臧 `dndt` = 厂+乚+丆 + 识别码 t，同一套部件 |
| **骄** | ctdj | 末位 J 与左右冲突 | **马 + 丿 + 大 + 识别码 J** | 码位只在「上下」成立；以码位定结构（与 卤`hlqi` 同处理） |
| **戚** | dhit | 3、4 位不符 | **厂 + 卜 + 小 + 丿**（四根取尽，无识别码） | 戊(厂+丿)+尗(卜+小) 的 1,2,3,末 |

这 4 条说明：**"末位冲突"里有一半是我们把某个部件的末笔/结构想错了**，不是码表错。
最典型是 旁 —— 方 的末笔在 `yygn` 里写作折，直接决定了 旁 的识别码是 B。

## 2. 判定为码表异常的 2 条（我们的表自洽，码表不自洽）

| 字 | 码表 | 我们的严格推导 | 差异原因 |
|---|---|---|---|
| **酶** | sgtu | 酉(西+一) + 每(𠂉+母) ⇒ **sgtx** | 第 4 位要落 U，但 母 在 X 键；除非把 每 的 母 记成「一+丷」，而这与 姆 `vxgu`/拇 `rxgu` 的"母 是单根"矛盾 |
| **薛** | awnu | 艹 + 辟(尸+口+辛) ⇒ **ankf**（或 a w n u 需 亻/コ） | 码表把 辟 的 尸/口 记成了 亻(w)/コ(n) 的键位，与字形不符 |

两条都是"要么改码表、要么改字根键位"的取舍，**不适合在判定表里单方面决定** → 记 `blocked`，附预测码。
若将来审码表确认 `sgtx`/`ankf`，这两个字会自动变 full。

## 3. 剩余 7 条的成因分类（99.8% 之后）

| 字 | 码 | 成因 | 需要什么 |
|---|---|---|---|
| 率 | yxif | 第 3 位（I 键）对应 IDS 的「⿱丿丶」，I 键上无对应字根 | PUA/字形证据 |
| 鼎 | hndn | 第 2 位 PUA 在其它 full 字里没有同位样本 | 同上 |
| 迎 | qbpk | 首根「卬」不在 241 条标准字根清单 | ADR：是否扩清单 |
| 印 | qgbh | 首根「𠀉」不在清单（D2 记作 爪，而 爪 在 R 键） | ADR：同上 |
| 卯 | qtbh | 首根是 卯 自身（成字字根模式），但第 3 位 卩 不是笔画键 | 判定口径：成字字根是否允许非笔画尾 |
| 酶 | sgtu | 见 §2 | 码表审计 |
| 薛 | awnu | 见 §2 | 码表审计 |

**结论**：99.8% 之后，每一条都指向**标准本身的两处未定义**：
① 成字字根模式的尾巴必须是笔画吗（卯）；② 标准字根清单能不能收 卬/𠀉 这类"只在合体里出现"的部件（迎/印）。
这两条要写进 LWS-86 的下一版（1.1 草案），不是数据问题。
