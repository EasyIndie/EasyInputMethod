## 验收后更正（用户 2026-10-19 反馈）

用户实测澄清了三条预期，本报告据此改判：

1. **空文档有焦点光标 → 应显示 HUD**（本轮实测就是显示，属**通过**；原任务清单「空文档不显示」措辞错误，ADR-213 的表述已由 ADR-214 修订）。
2. **新开终端有焦点光标 → 应显示 HUD，但实际不显示** → 新增 **D12**（真实缺陷）。
3. **Finder 前台无文本焦点 → 不应显示 HUD，但实际显示** → **D7 成立**（用户确认）。

### D12 的根因（日志实证）

Terminal.app 里切换状态时，宿主日志显示 `hudCaretRect()` 连续 64 次 `Get attributes for character`（回退循环用尽）后仍无有效矩形
→ 返回 nil → 不弹 HUD；同一时刻候选窗仍能显示（`caretRect()` 有鼠标兜底）。即：**Terminal 不通过
`attributes(forCharacterIndex:)` 暴露插入点矩形**，而 HUD 只用这一条 API。修复见 ADR-214（`firstRect` 优先）。
