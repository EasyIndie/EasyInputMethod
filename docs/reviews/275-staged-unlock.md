# 275 — 练习分阶段解锁（U2-5，ADR-350）

> 2026-11-14，air（arm64 / macOS 27.2）。代码完成，**未换包**；真机目视待授权。

## 1. 口径

- 题型顺序沿用：字根 → 一级简码 → 二级简码 → 完整码 → 词组 → 识别码。
- **掌握** = 该题型练过的不同字数 ≥ `min(30, 题库数)` 且总正确率 ≥90%。
  - 一级简码题库只有 25 字，因此要求练满 25 字；其余题型为 30 字。
- **不回锁**：任意题型只要已有练习记录（attempts > 0）就保持可用。新进度只有「字根」可点。
- 新增 `practice.staged_unlock`（默认 `true`）；关闭后恢复全部可选。

## 2. 实现

- `Practice` 新增 `KindStats`、`requiredPractice(bankSize:)`、`isMastered`、`unlockedKinds`；
  `nextHint` 新增可选 `bankSize`，题库不足 30 时也能正确提示。
- 练习窗口：未解锁分段禁用 + 悬停提示前置题型进度；进度行显示下一阶段字数/正确率门槛；
  重置进度后回到「字根」。
- 配置 Schema 33 → 34；设置页「五笔学习」分组新增开关。
- 进度文件格式不变（`practice.tsv` 五列），不新增数据文件、不联网、不参与候选排序。
