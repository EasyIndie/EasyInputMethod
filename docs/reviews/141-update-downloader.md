# 141 更新负载下载器（ADR-261）

## 交付

`packaging/macos/upgrade.py` 新增 `--payload-url`：

- **只允许 https**；`--allow-file-url` 明确标注为「仅本地离线测试」，正式发布不得使用；
- 流式下载到 `mkdtemp` 0700 私有目录，文件 0600，**上限 256MB**；
- 重定向后再次检查协议，禁止降级到 http；
- 空负载、超限、协议不符立即失败；
- 无论成功/失败都删除下载临时目录；
- 顺序不变：**下载 → 验签 → 解包 → 候选校验 → 停精确宿主 → 备份 → 原子替换 → 落地复验/回滚**，
  验签通过前下载内容不进入安装流程。

## 离线回归（7 项，全 PASS）

`packaging/macos/tests/test-upgrade.py` 新增：

1. 拒绝 `http://` / `ftp://`；
2. 未显式 `--allow-file-url` 时拒绝 `file://`；
3. `file://` 负载复制到 0700/0600 私有位置且字节一致；
4. 超过大小上限失败；
5. 重定向到非允许协议失败；
6. 空负载失败；
7. CLI 在未给 `--allow-file-url` 时对 `file://` 返回 3。

合计升级相关离线回归 **15 项**；`make macos-offline-tests` 全绿。
