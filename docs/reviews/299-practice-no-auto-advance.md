# 报告 299：取消判对后自动进位（ADR-372）

日期：2026-11-18 / pi（air）· 分支：`dev`

## 1. 用户反馈

判对后 0.7 秒自动进下一题不需要：讲解还没看完就跳走，而且"自动走"和"空格确认"两套推进方式混在一起。
要求：判对后由用户自己确认是否进位。

## 2. 改动

| 位置 | 改动 |
|---|---|
| `PracticeWindow` | 删除 `autoAdvanceDelay` / `autoAdvanceItem` / `scheduleAutoAdvance` / `cancelAutoAdvance` / `letterTyped` 与三处取消调用；`onLetter` 回到"只点亮键位图" |
| 测试 | 删掉自动进位断言；改为「判对后停在原题 / 未确认时打字母不进位 / 空格与 `→` 才进位」 |
| 文档 | ADR-369 第 1 条标记为被 ADR-372 取代；ADR-369 的字根标注与解锁庆祝保留 |

## 3. 现在的练习节奏

1. 打满最后一码 → **立即判分**（ADR-370）。
2. 判对 → ✓ + 讲解 + 统计留在屏上，**等你确认**：空格（ADR-371）或 `→` 进位，`←` 回看。
3. 判错 → 不揭晓答案、抖动、清空，停在原题；重打满位数会再判。
4. 回车在练习里不动作（输入法里它是"上屏原始码"）。

## 5. 待真机复验

- 判对后停在原题，讲解可以看完；按空格或 `→` 才进下一题。
- 判错抖动清空后重打满位数再判。
