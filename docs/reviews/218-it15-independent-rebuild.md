## 3. 过程中发现并修掉的工具缺陷

用户首次运行 `platforms/macos/tests/run-repro.sh` 时日志止于：

```
.../expected .../rebuilt differ: char 22, line 1
```

原因：脚本在 `set -euo pipefail` 下**先** `cmp` 可执行文件，跨 SDK 必然失败 → 直接中断，
**后面 3 张数据表的比对从未执行**（报告 208 的预演也踩过同一处，只是当时没意识到）。

修法（同一批提交）：

1. 默认数据先比，且补齐为 **4 张表**（原来只比 3 张，漏了 `variant-s2t.tsv`）；不一致直接失败。
2. 可执行文件后比，不一致时打印双方 SDK 并说明 ADR-033 边界，默认**不判失败**；需要严格时用 `STRICT_BYTES=1`。
3. 两个产物摘要都打印，便于写进报告。
