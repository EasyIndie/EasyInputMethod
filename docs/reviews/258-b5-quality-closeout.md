## 1. A4 冷首键：有数据，但不是学习区的锅

| 版本 / 配置 | 冷首键 | 稳态 p95 |
|---|---|---|
| 1.1.0（历史，报告 229） | p50 15.88 / p95 25.77 | 6.71 |
| 1.2.0 学习区**开** | p50 27–30 / p95 33–40 | 6.12–8.32 |
| **1.2.0 学习区关（本次，10 轮）** | **p50 28.55 / p95 42.85 / max 42.85** | **7.09** |

- 学习区关闭时冷首键仍是 ~28 ms → **与学习区无关**（此前怀疑排除）；
- 稳态 p95 全部远低于 16 ms 门禁；
- 用户实测"**没有第一下顿的感觉**"；
- 结论：**不优化**，按 ADR-307 继续"单独披露、不进 PASS/FAIL"。
  **触发条件**：用户可感知的首次输入延迟，或冷首键 p95 > 50 ms。

## 2. A1–A5 的明确关闭

| 项 | 结论 | 触发条件（重开条件） |
|---|---|---|
| **A1** 排序观察期 P2（误选不学习 / 时间衰减 / MRU） | **关闭**。1.2.0 评测 ALL 首选 86.4%（1.1.0 为 83.8%），无"学了更乱"证据；ADR-304 原本就要求"有证据才做" | 用户报告"学过的词不生效"或"误选被学进去"，且有样本集对比 |
| **A2** 位置记忆 /「固定顺序」开关 | **关闭**。属新增配置项，无证据 | 出现"老手被学习打乱顺序"的重复反馈 |
| **A3** 三级简码入表 | **关闭**（报告 239：按键仅 −0.22、582 处撞码、+53 KB） | 拿到官方三级简码表，且用户反馈"识别码难记" |
| **A4** 冷首键优化 | **关闭**（见 §1） | 冷首键 p95 > 50 ms 或用户可感知 |
| **A5** 拼音后端质量评估 → 是否自研 FSA | **关闭**，移出 1.2.0 范围 | 1.3.0 起独立评估（需质量数据 + ADR） |
