# 197 离屏 UI 快照与对比度自动化（IT-22 的机器可判部分）

## 1. 产物

```sh
make macos-ui-snapshots                      # 26 张：候选/设置/关于/诊断/状态提示，亮+暗
python3 tools/macos-probe/contrast-report.py  # 逐张算对比度并判定
```

- 快照目录：`platforms/macos/build/ui-snapshots/`（不入库）。
- 报告工具：`tools/macos-probe/contrast-report.py`，只用 `sips` 解码，无第三方依赖。

## 2. 本版结果（0.1.13 / `c3b533e4…`）

| 项 | 结果 |
|---|---|
| 快照数量 | 26 张（13 个场景 × 亮/暗） |
| 对比度（背景 vs 最深笔画邻域） | **15.58 – 19.77 : 1**，全部 ≥ 4.5:1，**失败 0 张** |
| 需人工判读的次色调 | 设置类快照各 1 个（多为分隔线/次要文字），不判失败但要求评审看一眼 |

## 3. 这个指标能证明什么、不能证明什么

- **能**：主体文字与背景的对比度足够；主题/文案改动导致"文字几乎看不见"会被自动抓到。
- **不能**：不区分正文与次要文字（MVP 标准要求二者分别 ≥4.5:1）、不检查布局重叠/截断、不检查 Retina 与非 Retina 差异、不判断视觉一致性。
- 因此 IT-22 仍需人工走查；本工具的作用是把"对比度"这一项从人工变成可重复的机器检查，并指出该看哪里。
