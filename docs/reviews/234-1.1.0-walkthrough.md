## 3. 本次走查暴露的验收设计问题（已修）

用户指出：**验收不能假定用户装了非系统自带应用**（VS Code、微信都不是 macOS 默认安装）。
本轮据此整改：

| 位置 | 改动 |
|---|---|
| `client-matrix.sh` | 必需 = TextEdit + Safari（系统自带）；Chrome / Xcode 标记 `"required":false`，未安装输出 `SKIP`；Xcode 不再写死 `/Applications/Xcode-27.0.0.app`，改 `open -a Xcode` |
| `client-matrix-verdict.py`（新） | 判定只看必需项：必需全通过 = PASS；必需样本 <2 = BLOCKED；可选只统计不判失败 |
| `acceptance-auto.sh` | 客户端项改用上面的判定脚本，不再要求「≥4 个客户端全部命中」 |
| `platforms/macos/tests/test-acceptance-portability.py`（新） | 机器门禁：`open -a <App>` 的非系统自带应用必须先 `has_app` 判断；禁止写死版本化 `.app` 路径；清单里出现 VS Code/微信必须标可选或移除 |
| 清单 | `T-ITER-22.md` §3、`T-ITER-22-coverage.md` §2 同步：A 档 12 → **10 项** |
