# 175 GitHub Pages 产品页改版

## 目标

- 只保留 DMG 图形安装这一种安装引导，删除命令行安装/卸载内容；
- 用清晰的结构展示输入法特点；
- 保持极简，采用专业、清新的深绿/薄荷配色，兼顾亮暗模式。

## 页面结构

1. Hero：图标、产品名、五笔+拼音定位、DMG 下载、签名/许可/无账号信任信息；
2. 特性：6 张卡片（混输、离线零遥测、开源、本地数据、轻量、macOS 原生）；
3. 安装：三步 DMG 安装 + “DMG 里有什么”侧栏；
4. 卸载：保留配置/词库、彻底清理两种方式；
5. 平台与架构、开源收尾、隐私/许可页脚。

## 实现

- 单文件 HTML + 内联 CSS，无脚本、无第三方资源；
- 新增本地 `site/assets/lampyris-icon.png`（由官方图标生成 512px）；
- 亮/暗模式均使用同一套语义色变量；
- 已用 headless Chrome 在 1280px 桌面和窄屏下检查布局。

## 验证

- 页面无 `curl`/终端安装命令；
- 所有链接指向 latest DMG、Release、源码或故障恢复文档；
- 移动端单列布局，桌面端两栏/三栏栅格。
