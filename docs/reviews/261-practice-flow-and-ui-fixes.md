# 261 — 练习流程修复 + 识别码界面修正 + 流程自动化测试

- 日期：2026-11-06　｜　来源：用户实测「回车后正确率不变」「识别码判断界面需要优化」「流程要自动化验证」

## 1. 回车不判分（根因）

练习窗口的输入框是 `NSTextField`，而它所在的宿主就是输入法本身：键入会先被输入法接管，
**回车被输入法当作候选提交**，字段的 action 根本没触发 → 只有识别码点选会记进度，正确率停在 0%。

**修法**：换成自绘的 `PracticeAnswerView`（`NSView` + `keyDown`），自己收键、**不经过输入法**：
只接受 A–Y 字母（大小写都收，统一转小写）、退格、回车；回车触发提交。

## 2. 识别码界面（截图问题）

| 问题 | 修法 |
|---|---|
| 「末笔」「结构」标题被按钮压住、文字被截断 | 标题宽度 32→46、按钮起点 36→52，「末笔」选中后就地显示「末笔 撇」 |
| 判错的说明把**用户的**选择当成答案 | 说明改用**正确**的末笔·结构（`PracticeSession` 里取 `question.recognition`） |

## 3. 自动化：练习流程跑通

新增 `PracticeSession`（无 AppKit 的纯逻辑），把"出题 → 作答 → 判分 → 记进度"收进一处；
离线回归（`platforms/macos/tests/wubi-learning.swift`）现在断言：

1. 正确码判对、**进度摘要随之变化**、`practice.tsv` 记 1 次作答与 1 次正确；
2. 错误码也计数（次数 +1、正确不变）；
3. 识别码：正确末笔/结构判对，说明里包含**正确**的字母与末笔；
4. `PracticeAnswerView`：只收 a–y（含大写归一）、退格删除、`z` 忽略、回车回调拿到已输入内容。

## 6. 字根显示改为与学习区一致（2026-11-08 反馈）

**反馈**：练习页把字根和键位交替写成 `土F 丿T 匕X`，阅读不直观。

**改法**：新增 `PracticeRootRowView`，与学习区同一套呈现——**字形在上、大写键位在下**，格子等宽居中；
- 识别码题型：字根行常驻，作为判断末笔/结构的依据；
- 看字打码题型：答题后再显示字根行（不提前泄题），反馈文案不再重复拼接字根；
- 窗口高度 336→356，纵向重排：题型 / 题干 / 提示 / 字根行 / 作答 / 反馈 / 按钮 / 进度。

**测试**：新增字根行断言（键位大写、顺序一致）；版式自检仍要求所有控件在内容区内。
