# 报告 296：练习体验第二轮（ADR-369）

日期：2026-11-18 / pi（air）· 分支：`dev`

## 1. 用户反馈（真机练习一轮后）

1. 判对后还要再按一次回车才进下一题，多余击键会影响"连续输入"的习惯养成。
2. 字根题的题干是一个字形（例：「口」），和一个空心方框难以区分，容易以为数据缺失（截图 08.49.06 / 08.49.21）。
3. 进度到 100%、正确率 ≥90% 解锁下一阶段时，没有任何鼓励性反馈。

## 2. 改动

| 项 | 实现 |
|---|---|
| 答对自动进位 | `PracticeWindow.scheduleAutoAdvance()`：判对后 0.7s 进下一题；期间按字母 → `letterTyped` 取消定时并**把这颗字母算作下一题的第一个输入**；回车/`→` 仍立即进位；答错不排期 |
| 字根字形标注 | 新增 `PracticeGlyphView`（自绘、垂直居中）+ 字形上方「字根」小字；字根题用宋体 44pt，题干行高 48→64（宋体行距约 62pt，`NSTextField` 会裁顶） |
| 解锁庆祝 | `finish(unlockedBefore:)` 比对提交前后的解锁集合，新增时显示「🎉 已解锁「一级简码」」并 VoiceOver 播报；该行固定占位，窗口高度不跳 |
