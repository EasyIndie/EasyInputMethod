# macOS 核心性能测量（2026-10-08）

环境：macOS 27 arm64、Rust 1.98.1；release staticlib，经 C ABI 调用，使用隔离配置和空用户词库。脚本 `platforms/macos/tests/run-perf.sh`，2200 次按键，包括 wq、nihao、zhongguo、zz 通配、a、kwwl；每次包含配置消费和候选转换。

| 场景 | 持续输入物理 footprint | 峰值 RSS | P95 延迟 |
|---|---:|---:|---:|
| 优化前、仅五笔 | 194.45 MiB | 202.02 MiB | 10.28 ms |
| 有界 top-k、仅五笔 | 6.69 MiB | 10.59 MiB | 0.445 ms |
| 有界 top-k、核心拼音 256KiB | 16.78 MiB | 20.67 MiB | 0.471 ms |

第三项样本最大延迟 1.322 ms；100 轮后内存稳定。默认核心拼音词表 12403 条、262131 字节，规则及校验和见 `data/generated/pinyin-core-report.json`。原全量词表 340k 条，不默认装载。

这些结果只覆盖引擎 ABI，不包含 Swift/AppKit/IMK 的事件分发、候选 UI、客户端、最大用户词库或长时间 GUI 会话；完整宿主常驻内存与端到端延迟仍需在发布候选包验收，不能据此勾选完整 Phase 1 性能 DoD。

## 多会话补测（ADR-035）

5 个会话同时装载默认资源：共享前稳态 65.89MiB / 峰值 RSS 69.73MiB；共享只读词表后稳态 16.64MiB / 峰值 RSS 20.53MiB，2200 键 P95 0.481ms、最大 0.607ms。用 `run-perf.sh 5` 可复现；轮转会话处理按键，配置/组合/引擎选项仍分别持有。缓存为 Weak，不保活没有会话的数据，最多 4 组资源键。

此补测仍是引擎 ABI，不包含 GUI、最大用户词库和正式客户端，完整 DoD 继续待验收。

## 最大用户词库（ADR-038，尚未满足内存预算）

合成 10000 条、1978919 字节，五会话；所有词条以 a 前缀、60个汉字加编号，接近2MiB上限。优化前稳态40.30MiB、P95 0.834ms、最大19.434ms；有界用户候选与每候选一次频次后稳态36.67MiB、P95 0.738ms、最大10.857ms。包含首次懒加载；词库快照仍重复持有，完整内存目标尚未满足。测试词条不含任何真实用户数据。

## 用户词库快照共享（ADR-039）

`platforms/macos/tests/run-perf.sh 5 --max-user-dictionary` 生成隔离的满容量合成词库，测试普通按键及显式选字学习。共享不可变快照后，五会话稳态22.09MiB、峰值 RSS25.95MiB，2200键 P95 0.775ms、最大9.075ms。五次学习包含原子落盘，最大13.196ms；失焦释放旧快照后物理 footprint27.73MiB。正式宿主激活时预加载快照，失焦时释放，组合状态仍各自独立。

这些数据仍仅覆盖引擎 ABI，不能替代 AppKit 渲染及正式客户端验收。合成数据不含真实用户内容，测试结束自动删除。

## 实际候选窗口预检（2026-10-09）

`bash platforms/macos/tests/run-render-perf.sh --max-user-dictionary`：5 个 Swift 会话、满容量合成词库、2200键，真实 NSPanel 处理 FFI/候选转换/布局/显示调用。首键95.897ms（包含首次窗口与系统字体初始化），后续 P95 4.513ms、最大6.696ms，进程物理 footprint38.47MiB。

该探针没有 IMK 客户端和合成器完成计时，也没有扣除 mmap；38.47MiB 不能作为“排除 mmap 后≤30MB”通过证据。冷启动超16ms与宿主内存仍需分析，正式性能 DoD 不勾选。测试仅使用临时配置/词库，不安装输入法。

复用候选标签后，满词库同场景 footprint32.55MiB（原38.61），稳态 P95 4.084ms。ADR-040 将隐藏窗口/字体初始化移到激活阶段后，窗口预热24.949ms，首键5.968ms，后续P95 4.356ms、最大5.682ms，footprint32.61MiB。vmmap 显示主要为堆分配及碎片，不能据此扣除所有系统框架开销；内存预算及正式 IMK 仍待验收。可追加 `--inspect-memory` 对探针自身执行 vmmap，检查期间额外内存开销不纳入前述 footprint。

默认空用户词库补测：同样五会话，窗口激活74.890ms、首键8.305ms、稳态P95 3.335ms / 最大3.973ms、footprint27.05MiB。环境字体缓存会影响激活耗时，初始化成本保留报告；该结果仍是候选窗口预检，不含正式 IMK/客户端及长时间运行。

构建完成后收缩五笔与拼音候选数组的空闲容量，满容量同场景 footprint30.94MiB（原32.61），首键12.622ms、P95 3.678ms、最大5.539ms。只改变分配容量，不改变数据/查询/排序。30.94MiB 仍高于30MB（十进制约28.61MiB），不据此勾选性能 DoD。

## 拼音索引共享文本（ADR-041）

大量单字反查共享少量音节，全拼/简拼/词反查共享不可变词文本，公开输出仍为独立 String。满容量五会话真实候选窗口预检 footprint28.24MiB（约29.61MB），首键6.465ms，P95 4.273ms、最大6.272ms；窗口激活预热27.394ms 单独记录。99项单测及真实 AppKit 冒烟通过。

此前借用排序实验为31.02MiB，未形成可确认收益，未纳入产品代码；实验源码/补丁保存在 `/private/tmp/yinghuo-pinyin-borrow-experiment.*`。当前预检达十进制30MB以内，仍需正式宿主及长时间输入验收，不据此勾选完整性能 DoD。
