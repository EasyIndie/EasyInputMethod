# macOS 首版实现对照与待办（2026-10-09）

## 范围与结论

用户本轮要求先全面梳理、记录待办及交接，之后再实施。本文把“MVP”理解为现有 macOS 首版交付，不另行缩减承诺；权威技术方案§12将 Phase 1 定义为完整五笔输入法，其八项DoD仍是发布门槛。P2整句、其他平台、语音及非目标不纳入首版。

当前引擎、宿主、交互与签名公证链路已实现；输入及多数交互已有用户实测。尚不能称Phase 1验收完成：除后续实机验证外，候选来源显示、配置即时刷新、配置错误反馈已分别由 ADR-057/058/059 补齐，数据结构约定已由 ADR-060 闭环（含 T-M1-10 实现），解析器 fuzz 已由 ADR-061 补齐，组合长度边界已由 ADR-062 钉住。检查范围为本地源码、既有测试/CI证据与文档；未新增实机操作，未复核远端套餐/凭据，也未进行逐行全面安全审计。
