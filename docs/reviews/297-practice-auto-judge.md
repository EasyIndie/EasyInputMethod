# 报告 297：练习打满位数即判分（ADR-370）

日期：2026-11-18 / pi（air）· 分支：`dev`

## 1. 用户反馈

打满最后一码后还要按回车才判对错，等于每题多一次击键；要求"打满即判"，
回车只决定是否进下一题：判对直接进位、判错抖动并清空，以支持快速连续练习。

## 2. 改动

| 位置 | 改动 |
|---|---|
| `PracticeAnswerView` | 新增 `onComplete`：填满 `capacity` 位立刻判分；回车只在 `isAnswered` 时进位（`onAdvance`），未作答时既不提交也不进位；无障碍说明改为"打满位数自动判分；回车进入下一题" |
| `PracticeWindow` | `onReturn` → `onComplete`；离屏渲染前置清空作答框（共用控件，避免上轮残留） |
| 测试 | 视图级：打满自动提交 / 未打满不提交 / 未作答回车不动作 / 已作答回车进位；窗口级：`typeForTesting` 敲满正确码 → 自动判分 + 排期进位，敲满错误码 → 重试态 + 清空 + 回车不跳题 |

## 4. 与 ADR-369 的组合行为

1. 打满最后一码 → 立刻判分（本轮）。
2. 判对 → 反馈 + 讲解可见，0.7 秒后自动进位；期间按字母会取消定时并把该字母算作下一题首键（ADR-369）。
3. 判错 → 不揭晓答案、抖动、清空，停在原题重试；回车此时不跳题，重打满位数会再次判分。
4. 任何时候 `→` 跳过、`←` 回看、`⌘↩` 看答案不变。

## 5. 待真机复验

- 打完 4 码（或 1/2/3 码题型）立即出对错，不再需要回车。
- 判对后自动进位；判错后抖动清空，直接重打。
- 与 ADR-369 的三项一起在下一个公证候选上验。
