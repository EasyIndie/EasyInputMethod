## 3. 自绘工作流（建议）

1. 审阅者按清单逐条给出可读字根（Unicode 部件），填入 `label`，状态改 `verified`；
2. 对没有标准 Unicode 部件的字根，按公开五笔86字根表绘制 SVG（CC-BY-SA-4.0），
   以 PUA 码位 + label + SVG 路径登记；
3. 用 `build_b0` 读取新映射，重跑 B0；每条映射必须有样本字与来源；
4. 回归：3,000 字 `partial` 中由字根身份导致的条目下降；无「？」误填；体积/渲染实测。

## 4. 结论

- 自绘范围从「251 个」收敛为 **110 个待确认 PUA**（156 个已有可读映射）。

  或由熟悉五笔字根的人按样本字逐条人工确认。
