# MVP UI01：候选主体与分页工程验收

2026-10-14；功能基线66ab513，独立分支codex/mvp-ui-refinement；ADR-165、T-MVP-UI。仅本地，不替换安装包。

## 实施

输入编码、候选及必要页码构成主体；移除逐项来源和模式徽标，来源仍保留于AX/帮助。首项17pt加粗，无常驻选中背景；原生上一页/下一页按钮仅翻页，首末页禁用，保持输入缓冲与数字选择。浮窗不能成为key/main。繁体资源失败保持可见简体回退及完整错误帮助；旧键位提示保留低权重附行，不冒称拆字学习区。

长内容按屏幕换行并在有界视口滚动，提交文本不截断。隐藏清除旧候选可执行动作。没有修改Rust引擎、排序、快捷键或配置Schema。

## 证据与限制

- make verify全绿零诊断，137产物零网络检查；144 Rust通过、1既有计时测试忽略。
- make macos-offline-tests：19文件77测试通过；新增测试使用真实AppKit组件和私有FFI会话，覆盖分页不提交、AX选择、焦点资格、长词、亮暗、失败及隐藏后旧动作。
- 原生预览仅构建通过；strict universal构建通过。未启动旧可能展示设置窗口的预览冒烟。
- 实际AppKit离屏图：platforms/macos/build/mvp-ui01-review下light/dark/warning-dark/long-dark.png；人工检查字体层级、无选中背景、错误与长词边界。

离屏组件与AX动作不能替代真实客户端焦点、VoiceOver、多屏/系统辅助外观及最终包性能验收。UI02设置/菜单、UI03工具/反馈/关于、UI04/05仍待；66ab513原功能审核包不含本轮UI，最终完整包必须重新锁定。
