# 292 — 练习答错重试（抖动）与达标即时解锁

日期：2026-11-16　设备：air（arm64 / macOS 27.2）
结论：离线断言全绿、隔离预览实机确认重试态；**已装包复验待下一次公证候选**。

## 1. 起因（用户反馈）

1. 某题型达标时，下一题型的练习 tab 不会自动亮起（要切题型或重开窗口）。
2. 答错后按回车直接进入下一题，用户还没感知到错误就被跳过；希望像验证码输入那样抖动再重试。

## 2. 改动（ADR-366）

| 文件 | 内容 |
|---|---|
| `Practice.swift` | 新增 `retry()`：答错后清"当前题已作答"指针，历史与进度保留；答对后再调用无效 |
| `PracticeWindow.swift` | 判分后 `applyStagedUnlock()` 即时刷新 tab；答错进入重试态（不揭晓答案、清空作答框、播报）；窗口级 `→` 始终下一题、回车只在已通过时跳题；`←` 回看 |
| `PracticeAnswerView.swift` | 回车映射改为"未通过=提交 / 通过=下一题"；`→` 始终下一题；新增 `Shake`（layer transform，不抢布局） |
| 测试 | `wubi-learning.swift`：会话重试语义、窗口重试态与键盘导航、tab 达标即时解锁、作答框回车映射；临时目录每轮清空（避免跨运行污染） |

## 3. 验证

| 门禁 | 结果 |
|---|---|
| `make verify` | PASS（542 产物零网络符号） |
| 离线回归 | **68 文件 / 337 例 PASS**（新增断言见上） |
| `build.sh --strict` | PASS |
| 隔离预览实机 | 答错 → `✗ 再试一次 · 你答 A`、作答框清空、题面不变、讲解区显示"答错了：再试一次…"；`PASS interactive cleanup … real files unchanged`，输入源还原 |

覆盖到的断言（摘）：

- 答错 → `retry()` 为真 → 同题重答 → 答对 → `retry()` 为假；两次作答都留在 `history`。
- 重试态：`navigateForTesting(36)` 返回 false 且题面不变；`124`（→）换题；`123`（←）回到该错题。
- 29 字时一级简码 tab 锁定；逐题答对到 30 字后 tab 立即亮起（不用切换题型/重开窗口）。
- 作答框：`isAnswered == false` 时回车只提交、`true` 时才进入下一题。

## 4. 差异与遗留

- **未在已装包验证**：本机只能构建 ad-hoc 包；待下一次 `dev → main` 的公证候选换包后确认
  （答错抖动、回车不跳题、tab 即时亮起）。
- 抖动为视觉反馈，`screencapture` 在本机无屏幕录制授权，报告里以"重试态"（反馈文案、作答框清空、
  题面不变）作为可判定证据；动画本身是 0.34s 的 layer transform，不影响布局与命中区域。
- 识别码题型：答错清空末笔/结构并抖动整张卡片，重新选择即可；不额外记录"重试"事件。
- 真实 `practice.tsv`（148 行，用户本人练习）本轮未改动。
