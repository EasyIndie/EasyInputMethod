# 报告 303：B0 字表来源与覆盖率复核（含 N1-d 13 个 PUA 的现状）

日期：2026-11-19 / pi（air）· 基线提交 `b529096`（dev）· 本轮改动见提交（ADR-375）

## 1. 触发

`docs/待办与积压.md` 与 `HANDOFF.md` 里还挂着两条"可选小项"与一条"覆盖率卡在许可数据上限"：

1. N1-d「剩余 13 个语境歧义 PUA 仍以 `？:键` 占位」；
2. 练习窗口「副屏居中位置」；
3. corpus 3,000 字覆盖率 87.1%，要提升需要许可干净的 canonical 五笔根序数据。

本轮把三条都按证据复核了一遍。**结论：① 已不成立；② 已由 ADR-365 关闭；③ 覆盖率被选字口径压低，
真实口径是 91.3%，剩余差距依旧卡在 canonical 根序数据。**

## 2. N1-d 的 13 个 PUA 现状（①）

| 检查 | 事实 |
|---|---|
| `corpus/pua-supplementary.tsv` | 127 行全部 `verified`，无 `unresolved` 行 |
| `corpus/pua-context.tsv` | 34 条逐字语境（ADR-355 接入） |
| `corpus/pua-inventory.tsv` | 79 个补充区 PUA：`verified 64 / partial 2 / unresolved 13` |
| `data/generated/B0-runtime.tsv` | **`？` 占位 0 条**，产物无 PUA（`test-b0-runtime.py` 亦钉死） |

即：那 13 个 PUA 的身份仍未被独立证明（证据链缺一环，故清单里保持 `unresolved`、label 留空，不猜），
但**它们已经不再以 `？:键` 出现在任何用户可见文本里**：受影响字的条目降级为 `partial`
（如 `良 丶:y 彐:v`、`补 衤:p`、`杨 木:s`），学习区按 `partial` 说「拆解待核验」。
复核方式：把 13 个 PUA 的 sample 字（37 个）逐个回读运行时资源，`partial` 37 / `full` 25、无 `？`。

> 因此文档里"剩余 13 个仍以 `？:键` 占位"是**陈旧表述**，本轮改为"13 个 PUA 未独立核验，
> 受影响字降级为 `partial`"（`docs/待办与积压.md` P1-3/U3-4、`HANDOFF.md`、`ROADMAP.md`）。

## 4. 覆盖率复核（③）

### 4.1 现行口径与它的问题

现行 3,000 字 = `data/generated/pinyin-chars.tsv` 的 `weight` 降序前 3,000（`--limit 3000`）。
该 `weight` 来自 D10 jieba 单字词频。抽查发现有 **154 个字带着明显被污染的频次**排进前 3,000：

```
rank 503  銆 6982     rank 594  鐨 5901     rank 820  鏄 4025
rank 1006 竴 3048     rank 1023 鍙 2979     rank 1138 佸 2603
```

它们夹在「底 7005」「院 6957」这类常用字之间，频次与其真实稀有程度完全矛盾（上游 `jieba-dict.txt`
的 `zg` 段是语料编码噪声的残留）。后果有两个方向：

- **压低覆盖率**：这 154 个字在 D2 里没有拆字 → `unknown`（占 154/3,000 = 5.1 个百分点的分母）；
  把它们剔除后按同一词频顺序取 3,000 字，`full` 2,724 = **90.8%**，`unknown` 降到 31。
- **挤掉常用字**：与「GB2312 一级按词频取前 3,000」相比，交集只有 2,604 字，**396 个常用字没有条目**。
  新增应覆盖（396 字，按词频顺序）：

### 4.2 改用标准字表后的实测

`--char-list data/generated/gb2312-level1.txt`（GB2312-1980 一级汉字区 3,755 字，按词频排序）：

| 集合 | 规模 | full | partial | unknown | full 占比 |
|---|---|---|---|---|---|
| 旧口径（jieba top-3,000） | 3,000 | 2,614 | 232 | 154 | 87.1% |
| 旧口径剔除 154 个脏频字 | 3,000 | 2,724 | 245 | 31 | 90.8% |
| **GB2312 一级（新口径，ADR-375）** | **3,755** | **3,429** | **326** | **0** | **91.3%** |
| GB2312 一级按词频取前 3,000 | 3,000 | 2,750 | 250 | 0 | 91.7% |

运行时资源 155,500 B（41.4 B/字，预算 512 KiB）；`key-roots-wubi86.tsv` 内容不变，仅 audit 的语料统计行刷新；
`pua-inventory` 仍 79 个 PUA（64/2/13），occurrences 随字表变化。

### 4.3 剩余 326 条 `partial` 的成因

全部是**拆法口径**差异，不是缺字形/缺数据文件：

| 成因 | 条数 | 说明 |
|---|---|---|
| `positionMismatch`（根序不符） | 283 | D2 记视觉拆法，标准 v1 要求逐组件通过 241 条标准字根/键位校验，如 `不` 记 `丆卜`（86 取 `一丿卜`）、`交` 记 `亠八乂`（86 取 `六乂`） |
| 组件数与码长不符 | 43 | D2 用复合字根/漏件，如 `字根数 3 与码长 4 对不上，无法判定识别码` |
| **合计** | **326** | 与 `unknown 0` 一起说明：缺的不是字形，是 canonical 根序 |
要把它们变 `full` 只能拿到**canonical 五笔根序**：
- 王码官方数据：许可与 GPL-3 不兼容，未采用；
- Academia Sinica「漢字構形資料庫」（CDP）：站点仍 Access Restricted / 证书过期（2026-11-14 起多次尝试），
  且给的是构形/部件，不给五笔根序；
- cjk-decomp（Apache-2.0）：已接（D24，283 条覆盖），只覆盖 D2 漏拆，不校正根序。

**结论：91.3% 是在"不猜、不降标准、不用不合规数据"前提下的现值，98% 需要外部数据到位后才谈。**
