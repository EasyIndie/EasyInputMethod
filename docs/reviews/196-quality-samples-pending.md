# 196 固定输入质量样本集（脚本就绪，执行仍待图形会话）

## 1. 为什么要有这份东西

MVP 标准要求「固定典型输入与质量样本集逐项通过」。此前验收是零散断言（报告190-192），换包后无法逐条复跑。现在把样本固化成 `tools/macos-probe/quality-samples.sh` 的一张表，一条命令跑完并逐项 PASS/FAIL。

## 2. 样本集（14 项）

| 分组 | 用例 | 按键 | 判定 |
|---|---|---|---|
| 核心输入 | 五笔四码自动上屏 | `wqiy` | 含「你」 |
| | 五笔一级简码 | `r ` | 出中文（简码命中） |
| | 混输拼音兜底（两字） | `nihao ` | 以「你好」结尾 |
| | 全拼双字词 | `zhongguo ` | 等于「中国」 |
| | 拼音长词 | `zhonghuarenmingongheguo ` | 等于「中华人民共和国」 |
| 标点与形态 | 中文句号 | `nihao .` | 以「。」结尾 |
| | 中文逗号 | `nihao ,` | 以「，」结尾 |
| | 成对引号 | `"` | 出中文引号 |
| | 全角往返 | `opt+f;1;opt+f;1` | 等于「１1」 |
| | 简繁往返 | `opt+t;xuexi ;opt+t;xuexi ` | 含「學習」 |
| 中英与健壮性 | 单 Shift 英文直通 | `shiftc;abc` | 等于 `abc` |
| | 翻页键不破坏输入 | `nihao ,,,` | 仍是中文文本 |
| | 撤销回空态 | `wqiy;cmd+z` | 文本为空 |

脚本自带前置检查（`acceptance-preflight.sh`）与中文态归位（`ensure_cn`），环境不具备时以 **78** 退出并打印 `SKIP`，不会被误判为失败。
