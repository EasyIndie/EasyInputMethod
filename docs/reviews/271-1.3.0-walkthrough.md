开始前在同一终端记录（复制结果到证据文件）：

```sh
E=platforms/macos/build/acceptance-air-1.3.0-b41/walkthrough
mkdir -p "$E"
{ echo "== walkthrough pre $(date -u +%FT%TZ)"
  echo "installed=$(shasum -a 256 "$HOME/Library/Input Methods/Lampyris.app/Contents/MacOS/Lampyris" | awk '{print $1}')"
  echo "config=$(shasum -a 256 "$HOME/Library/Application Support/Lampyris/config.toml" | awk '{print $1}')"
  echo "dict=$(shasum -a 256 "$HOME/Library/Application Support/Lampyris/user-dictionary.tsv" | awk '{print $1}')"
  echo "practice=$(shasum -a 256 "$HOME/Library/Application Support/Lampyris/practice.tsv" | awk '{print $1}')"
  grep -m1 '^mode' "$HOME/Library/Application Support/Lampyris/config.toml"
  tools/macos-probe/bin/tissrc list 2>/dev/null | grep -E '^current'
} | tee "$E/00-pre.txt"
```

> 注意：A 档会正常使用输入法，用户词库会因真实键入而增长，这是预期行为；走查结束只核对 `config.toml` 的取值没有被意外改动。

## 2. 1.3.0 新增行为的人工确认（建议同轮完成）

这些不在 IT-22 原表里，但本版新增，机器测试覆盖不到「观感/首次」：

| # | 项 | 怎么操作 | 判定 | 结果 |
|---|---|---|---|---|
| N1 | 首次启用上手提示 | 正常安装后第一次激活会出现一次；本机若已看过，标记在 `~/Library/Application Support/Lampyris/onboarding-done`。**不要手动删用户数据**，除非你同意重看 | 只弹一次，四个快捷键文案正确（⌥M/⌥,/⌥K/⌥L），关闭后不再出现 | 待填 |
| N2 | 设置页新开关 | ⌥, →「五笔与拼音」应有「连续单字自动造词」（默认关）；「候选显示」有分号选词/以词定字/拼音上屏提示五笔码；「练习」有记录薄弱字 | 分组与文案正确，开关可切换并即时写回 `config.toml` | 待填 |
| N3 | 五笔自动造词 | 设置里临时打开「连续单字自动造词」，切到**纯五笔**；连打同一个 2 字组合 3 次（如 `wqiy`→你、`vbg`→好，间隔 <2 秒），再打该词码看候选；完成后关闭开关 | 第 3 次后用户词库出现该词，重启宿主仍在；关闭后不再新增 | 待填 |
| N4 | 文章跟打 | ⌥K → 工具栏「文章跟打」→ 照目标句输入 → 回车 | 正确/错误提示与首个错字位置正确；「下一句」换句；关闭后无历史文件 | 待填 |
| N5 | 日期/时间/三级简码观感 | 混输或拼音模式打 `riqi`、`shijian`、`xingqi`；打 `aah` + 空格 | 首候选是当天日期/当前时间/星期/「芽」，来源标签不刺眼 | 待填 |

> N3 会真实写入用户词库；若不想保留，可在设置 → 词库管理里删除该词条。
