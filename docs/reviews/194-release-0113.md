## 4. 交给两台设备的人工验收清单（pro / air）

1. 从 `https://github.com/EasyIndie/EasyInputMethod/releases/latest` 下载 DMG，核对 `.sha256`，安装后确认版本 0.1.13、构建号 21。
2. 添加输入源（系统设置 → 键盘 → 文字输入），用五笔打一词、想不起码时用拼音兜底，确认上屏。
3. 逐项人工验证自动化覆盖不到的部分：辅助功能（VoiceOver 朗读候选）、多屏与缩放、睡眠唤醒后继续输入、真实卸载→重装。
4. 若该机原为 0.1.12：应用内「检查更新」应发现 0.1.13；安装后确认执行文件变化、配置与词库仍在。
5. 记录：设备型号/系统版本、安装前后执行 SHA、`config.toml` SHA、词库行数、输入源，以及每项结论（PASS/FAIL/BLOCKED）。
