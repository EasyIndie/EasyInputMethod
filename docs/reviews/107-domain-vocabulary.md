# 107 — 小批量常用组合词补充

2026-10-21，B arm64/macOS 27.0.1；ADR-237，复用 T-M1-09/T-M2-02。基线744bae2，候选为本报告同提交的D16数据和生成器。PR #60已合入main 3fe36b0，#59关闭；历史验收SHA不改写。本轮不是正式RC或原生IMK验收。

## 改动与来源

独立自编132项日常、工作和开发组合词，先冻结清单再对照旧保留集，重叠0项。D16采用CC-BY-SA-4.0，来源/许可/SHA先登记后生成。拼音逐字读音由既有D5数据校验，五笔沿用已有单字码和编码器。保留原有词条、频次和基础20k选择；新增词使用1作为排序占位权重，不宣称语料词频。基础词、显式领域补充、个人词和完整长尾仍分别管理，不把全部长尾放入核心表。

五笔48,012行（27,823字、20,189词），666,315字节，比基线多125行/2,516字节；拼音20,192行，436,115字节，多125行/3,865字节。两表仍各小于ADR-237的800,000字节预算。原始433项验收文件未修改，新增132项单列domain，不能作为盲测。
