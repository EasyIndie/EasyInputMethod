# 026 首版完整 UI 与拆字学习实现核验

日期：2026-10-15。源码基于 main 50fdac3；独立分支 codex/mvp-complete-learning-ui。ADR-170…180；任务 T-MVP-FULL-UI。用户已授权纳入首版；本报告替代原“教学后移”的当前工程安排，不改写历史审计025。

## 已实现

- 候选默认400pt、16pt边距、17pt主字、11pt序号，首项加粗而无背景；翻页首末禁用、单页隐藏。扩展学习保持同候选主体几何，优先分配主体视口。
- 学习由唯一Schema开关及可自定义快捷键控制，默认关闭/未绑定，与模式无关。完整码和规则同行，字根上/键码下；识别码单列解释，提示及AX说明提供完整规则。
- 两/三/多字词按五笔组词规则显示摘要；中华人民共和国覆盖七字，逐字独立披露、明细137pt有界滚动，同词重排保留披露身份/滚动位置，换词清理。学习动作不调用候选提交，不夺键盘焦点。
- 四pane设置按稿分组、右对齐原生控件、Mac符号快捷键摘要和编辑sheet；新增/删除词条附着父窗口，错误保留输入，关闭后不重现；删除默认取消。
- 输入模式原生单选子菜单和真实布尔勾选；移除额外学习菜单入口/旧键名常驻提示。关于恢复官方图标、身份、独立诊断复制及两类反馈，使用系统亮暗语义色。

## 教学覆盖与许可边界

全码索引27,823字/222,584字节；3,592条教学记录中，104条完整规则解释（compound29/key_name25/stroke5/chengzi45），1,348条可核验码位字形、2,140条部分说明，均有类型与界面缺失说明。剩余24,231字仅有全码，不冒充完整拆分。覆盖率是内容边界，不能将“学习UI及查询实现完成”写成“全量字库完整拆字完成”。

数据来自既有主码表事实、独立D14键位/人工核验事实和固定SHA的D2可读字形；MIT全文/署名随包，未引入外部字体或PUA，不推断末码就是识别码。15类识别码、成字字根、单笔画及七字长词均有核验例。生成器确定性重建字节一致，全部主码表单字逐行核对、分类及规则重建回归通过。来源见数据来源与许可、sources.toml及机器覆盖报告。
