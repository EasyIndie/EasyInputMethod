# MVP产品验收标准（ADR-084）

## 目标与范围

MVP是首个准备正式分发的macOS产品版本：核心输入功能齐全、日常使用稳定、交互完善、视觉体验良好，达成“小、干净、默认离线、五笔优先且拼音兜底”的目标。当前历史工程收敛已完成，产品MVP仍在推进。目标版本暂沿用0.1.0；实际版本与渠道在锁候选时确认。

“上架就绪”指具备正式交付条件；当前渠道为Release＋Pages，不代表已完成App Store准入。若指定商店，需要独立渠道决策及验证，不以修改版本号代替。

## 缺陷与完成判定

- P0数据损失/安全问题及P1核心功能、状态、兼容、可访问性、明显视觉/交互缺陷必须关闭；不能只因历史脚本绿色而关闭。
- 明显布局/可读性和常用任务操作缺陷不得降为“发布后美化”。轻微不影响任务的瑕疵需登记、说明影响，并在最终产品评审中明确接受；用户目标不等于要求无任何技术债。
- UX-1浏览器地址栏残留维持此前接受决定，发布说明清楚披露并提供Esc取消组合的操作建议；若出现新的丢字/错误提交情形重新评估，不能用旧豁免覆盖新问题。
- IT-22产品评审、IT-23日常试用、IT-14最终候选和IT-15第三方核验全部完成后，才标“产品MVP完成/正式分发就绪”。发布或商店审核通过是后续独立状态。
- 每个行为/架构/协议变更先ADR；新增数据先许可登记；不引入云、账号、遥测、AI扩展、剪贴板历史等非目标。
