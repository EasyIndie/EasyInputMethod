## 2. 相对 0.1.12 的改动（面向用户）

- **更新更可靠**：下载临时目录的所有权清理、首次安装失败时的回滚、预检失败不留 staging（ADR-286/287/289）。
- **安装目标目录缺失时给出明确错误**，不再出现模糊的移动失败（ADR-289）。
- **包体更干净**：`-dead_strip` + 逐架构网络符号门禁，宿主二进制不再带入未使用的网络符号（ADR-285）。
- 其余为内部测试/验收能力（隔离更新演练、探针、自动化验收），不改变用户可见行为。
