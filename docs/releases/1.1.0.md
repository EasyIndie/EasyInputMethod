## 2. 内容（相对 1.0.2）

**这是 1.1.0 唯一的产品行为变更：候选排序（ADR-304 / 报告 228）。**

- **一级简码 25 条入表**（数据 `D17`，项目自编清单，CC-BY-SA-4.0）：
  `g 一 f 地 d 在 s 要 a 工 h 上 j 是 k 中 l 国 m 同 t 和 r 的 e 有 w 人 q 我
   y 主 u 产 i 不 o 为 p 这 n 民 b 了 v 发 c 以 x 经`，单键即首选。
  **自动上屏规则未变**：仍要求输入长度 = 4，简码需空格或数字确认（符合五笔习惯）。
- **个人化改为"有界位次上移"**：学过的候选按固定步数上移（≥1 次 1 位、≥4 次 2 位），
  **首选位受保护**（最多升到第 2 位），且**不跨"精确 / 补全 / 模糊"分块**。

## 4. 升级与回滚

- 升级：菜单「检查更新…」或 ⌥G → 下载 → 验签 → 安装；升级前自动备份到 `updates/`。
- 回滚：`~/Library/Application Support/Lampyris/uninstalled/` 里的旧 bundle 可原位还原；
  配置与个人词库在升级中不做迁移改动（1.0.1 起 `full_width` 已是枚举，旧布尔值只读兼容）。
- 卸载：更新窗口「卸载萤火虫…」；保留数据 = `config.toml` + `user-dictionary.tsv`（ADR-297）。

## 5. 已知限制

- **候选顺序变化是真变化**：一级简码从"要打全码或翻页"变成"一键首选"。老用户若习惯打全码，结果不变（全码仍是精确命中），
  但 1–2 码的候选顺序会与 1.0.x 不同，回滚只能整包回滚。
- **二级简码（625 条）不在本版**：需要单独登记数据来源与 SHA（D17-bis），未就绪就不上。
- 浏览器地址栏组合中失焦可能残留原始编码，Esc 取消（UX-1，macOS IMK 限制）。
- ⌥M 切到没有候选的模式时，候选窗隐藏、编码以预编辑文本留在输入框（ADR-302 的取舍）。
- **冷首键延迟 15–26 ms**（新输入上下文首次建立，一次性）：已按 ADR-307 与稳态分开统计与披露，
  本版未优化、也未把它设为门禁。
