## 3. 本版内容（相对 0.1.16）

- 组合态切换不再丢字（ADR-302/报告 221+222）：Shift 切英文把编码原样上屏；⌥M 切模式保留编码并按新模式重算；⌥F 保留组合。
- 候选窗去掉恒为「中文」的中英芯片，header 5 枚 → 4 枚（ADR-303/报告 223）。
- 候选窗跟随输入焦点而非鼠标（报告 219），几何由 `CaretPlacement` 单一决策点负责（ADR-301）。
- 拼音多词分段拼接（ADR-299）、组合开始播报编码（ADR-300）。

## 4. 已知限制

- 设置页「全角 ASCII」不跟随 ⌥F 更新、且是复选框（ADR-305 于 1.0.1 修）。
- 浏览器地址栏组合中失焦可能残留原始编码，Esc 取消（UX-1，macOS IMK 限制）。
- ⌥M 切到没有候选的模式时，候选窗隐藏、编码以预编辑文本留在输入框（ADR-302 的取舍）。
