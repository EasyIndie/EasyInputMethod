## 2. 这一版做了什么

### 2.1 LWS-86（萤火虫五笔86 拆字标准）1.0 正式

**这不是输入法功能变更**，是把我们已经用了半年的拆字口径正式发布成一份可被第三方引用的标准：

- 规范与一致性判定器（`docs/standards/wubi86/`）：R1–R10 规则、识别码网格、L1–L4 四级一致性；
- 数据包随本 Release 发布（字根表 / 字表拆解 / 简码表），附 `SHA256SUMS`，与 tag 绑定；
- 站点新增「标准」页：规范摘要、判定器用法、数据包下载与校验值；
- **一个独立实现**（只读规范、不引用本项目代码）跑通 L1–L3，结果写进 CHANGELOG。

诚实边界：规范**只声明独立性**——不宣称与王码/中研院官方一致、不暗示任何背书；覆盖范围是
**GB2312 一级 3,755 字（100%）**，一级之外仍有 27 个字拆解待核验（标为 `partial`，不猜）。

### 2.2 可靠性体检（R-1）

1.3.2–1.3.4 三次候选都是"跳过 soak"，长时间与特殊场景没有连续验证。本版补跑四项：

- **30 分钟连续键入**：178 轮 / 2,173 键，p95 **16.2 ms**、最大 30.5 ms、慢轮 **0**；footprint 冷 8.3 → 稳态 43.4
  （窗口内增长 0.5 MiB）；1,685 个采样点 **0 外联**；词库 2,523 行键入前后与宿主重启后完全一致。
- **睡眠唤醒**：真实入睡后唤醒（间隔 235 s），**同一个宿主进程**继续工作，键入正常、词库不变、0 连接、无崩溃记录。
- **多屏落点**：内建 1440×900 + LG HDR 4K 1920×1080，窗口内与全屏各测一次，**4/4 PASS**，无跨屏。
- **扩展词库档**：存活堆 **48.3–48.4 MiB**（门禁 64），与 1.3.0 同档（48.0–48.2）相比 **+0.2 MiB**；关掉复原后配置逐字节一致。

体检本身也修：久用探针原来用 `vmmap` 采样，而 `vmmap` 会挂起宿主，把按键量成 300–600 ms 的假卡顿
（实测 10/10 轮复现）。改用 `proc_pid_rusage` 的 `bin/footprint` 后，同一台机器同一候选的"慢轮"从 24/174 降到 0/178。
详见 ADR-389。

## 4. 发布流程

1. `dev` → PR → CI 全绿 → merge commit。
2. main 上 `macOS Acceptance Package` 产出候选 → 校验 ZIP SHA / 包内执行 SHA / `spctl`。
3. 用户移除再加回「萤火虫」→ `make macos-fast-reinstall APP=… ARGS="--stop-host --keep-data"`。
4. 真机验收（整套 acceptance + 标准数据包/站点回读 + 体检结论）。
5. 打签名 tag → Release（含标准数据包）→ 站点上线 → 回读 `v1.4.0 · 构建 48`。
