## 2. 内容（相对 1.1.0）

### 2.1 判码行为（唯一影响候选顺序的改动）

- **二级简码 598 条入表**（数据 `D17-bis`，报告 238）：二级简码在精确命中里排到前面，
  全码仍精确命中、排序不变；`prefix2` 首选率 93.3%→40% 是预期让位（见 §5）。

### 2.2 学习区（⌥L，ADR-311）

- 结构化的教学运行时资源 `B0-runtime.tsv`（6 列：字 / 全码 / 质量 / 字根(形:键) / 识别码 / 简码，≈121 KB，3,000 字）。
- 学习区版面重做：**完整码 + 简码**、字根格（字形上、键位下）、识别码两行；词组按实际输入码逐位对应到字。
- **候选窗零改动**：学习信息只在 ⌥L，学习区默认关闭；资源缺失时静默关闭（不报错、不降级候选）。

### 2.3 练习（⌥K，ADR-313 / 316–323）

- 四个专项：**一级简码 / 二级简码 / 完整码 / 识别码**，题库按题型从 `B0-runtime.tsv` 过滤（缺对应简码的字不进该题库）。
- 四位输入格（位数随题型：1 / 2 / 3–4 / 无），`Esc` / `⌘⌫` 清空，回车提交；`z` 只点亮键位图、不进答案。
- 判分本地进行；进度写 `~/Library/Application Support/Lampyris/practice.tsv`（数据非配置，3,000 行 / 256 KiB 上限、原子写、删除即重置）。
- 统计：题库字数、已练字数、次数、正确率、练习进度（进度条），按当前题型统计。
- 动作统一在**窗口工具栏**：下一题 / 显示答案 / 键位图 / 重置进度（二次确认）/ 打开进度文件。

### 2.4 键位图与口诀（`modules/keymap`，ADR-315 / 320）

- 25 键字根分布图：左上编码字母、右上主字根、下方其余字根（**按口诀顺序**、3×3 网格），按区着色。
- 答完把答案用到的键位描边，并在**键位下方序号带**标出位次（重复码位合并，如 `①②③④`）。
- 口诀：每键一句传统口诀，按 11→15 区位顺序拼成五行；开关在面板内部，**默认关闭**。
- 数据以**标准字根表**为唯一真源（`CANONICAL`），逐键审计「语料有/标准表无、标准表有/语料未用」写入
  `modules/keymap/data/key-roots-wubi86-audit.md`；展示只含可渲染的 CJK 字根。
- 面板自包含（方案名 + 键位图 + 口诀 + 位次），宿主只给宽度与显隐 → 可整体复用到其它窗口/项目。

### 2.5 工程与质量

- 发布 tag 改为 **SSH 签名**（`packaging/git-allowed-signers`），未签名/签名不符时流水线失败。
- 站点版本号改由 `tools/stamp-site.py` 在 Pages 部署时盖章（不再硬编码）。
- 内存双阈值（ADR-312）：默认 ≤30 MiB、学习区开 ≤34 MiB；实测 28.5–33.3 MiB。
- 延迟门禁沿用 ADR-307 稳态 p95 ≤16 ms；冷首键单独披露、不进门禁。
- 覆盖安装后自动 `lsregister -f`，并警告"仍有旧宿主跑在备份 inode 上"（`docs/故障恢复.md` §4.2/§4.3）。

## 4. 升级与回滚

- 升级：菜单「检查更新…」或 ⌥G → 验签 → 安装；升级前自动备份到 `updates/`。
- 回滚：`~/Library/Application Support/Lampyris/uninstalled/` 或 `updates/` 里的旧 bundle 可原位还原；
  配置与个人词库本版无迁移改动。
- 卸载：更新窗口「卸载萤火虫…」；保留 `config.toml` + `user-dictionary.tsv`（ADR-297）。

## 5. 已知限制

- **二级简码优先后，`prefix2` 首选率 93.3%→40%** 是预期让位：二级简码在精确命中里靠前，全码用户结果不变。
- **三级简码专项未提供**：仓库没有「哪些字真有三级简码」的码表（ADR-314 已关闭三级简码），
  用"前 3 码"冒充会教错；开工条件写在 `docs/待办与积压.md`。
- **冷首键 ~28 ms**（与学习区无关，用户确认不可感知）；稳态 p95 5.8–7.2 ms。
- **学习区开启 +~3 MiB**（ADR-312 双阈值，差额归因为字形缓存）。
- **覆盖安装可能把输入源移出启用列表**（已多次实测）：`scripts/ensure-input-source.sh` 可判断并给出恢复步骤；
  根治方案（安装器交互）仍在待办。
- Terminal 里 ⌥L 与终端自身快捷键冲突（非缺陷），可改 `alt+shift+l`。
- 浏览器地址栏组合中失焦可能残留原始编码，Esc 取消（macOS IMK 限制）。
