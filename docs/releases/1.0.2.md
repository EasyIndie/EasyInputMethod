## 2. 内容（相对 1.0.1）

- **修复更新程序自更新把自己杀掉**（ADR-306 / 报告 226）：`replaceBundle` 替换前会调用 `stopHost`，
  自更新时它会 `lsof` 并 `SIGTERM` 正在执行安装的更新程序自己，事务停在「宿主已换、回执未写」，
  留下 staging 与缺失的 receipt。新增 `stopsRunningInstance`：`.updater` 目标不停进程
  （运行中的 bundle 允许被 rename 替换，下次启动用新版），`.production` 维持原行为。
- 该缺陷在 1.0.0 → 1.0.1 的真机升级中暴露：宿主升到 36，更新程序仍停在 34，`updates/receipts/` 从未创建。
- 顺带修 CI：发布工作流按提交挑选验收产物时，`--status success` 与 `--commit` 组合在某些提交上返回空，
  改为只按提交过滤再在 jq 里判 `completed && success`。
