## 2. 行为变更（用户可感知）

### 2.1 输入与标点

- **删除「拼音上屏后提示五笔码」浮层**（ADR-367）：默认开启的浮层在正常输入中造成干扰，已连同
  `candidate.hint_wubi_code` 一起移除；薄弱字记录（ADR-335，默认关）保留。
- **数字串里的 `.` `:` `,` 一律半角**（ADR-368）：`3.14` / `12:30` / `1,000` 不再出现"半角点 + 中文逗号"混排；
  数字之外的标点仍是中文标点，要英文标点用 ⌥P 手动切换。

### 2.2 窗口

- **自建窗口按鼠标所在屏居中并夹进可见区域**（ADR-365）：练习、使用指南、设置、文章跟打在多屏/副屏布局下
  不再落到看不见的位置。

### 2.3 练习

| 变化 | 说明 |
|---|---|
| 答错重试（ADR-366） | 答错不揭晓答案：卡片抖动、作答框清空、停在原题重打；达标时下一题型 tab 立即亮起 |
| 字根字形标注（ADR-369） | 字根题题干上方写「字根」，字形改用宋体并自绘居中，方形字根不再像占位方框 |
| 同形字根辨识（ADR-374） | 「口」与「囗」等易混字根给出辨识短语与例字，例如 `字根 · 囗（包围外框，如「国」「园」）` |
| 打满即判分（ADR-370） | 打满本题位数立刻判对错，不需要再按确认键 |
| 空格确认（ADR-371） | 已作答后按**空格**进下一题（与输入法"空格上屏"一致）；**回车在练习里不做任何事** |
| 不自动进位（ADR-372） | 判对后停在原题，用户看完讲解自己按空格/`→` 进位 |
| 达标反馈（ADR-373/374） | 达标常驻「🎉 已达「字根」目标：…」；未达标时进度行始终写清还差多少字/多少正确率 |

### 2.4 工程

- 预览与正式包共用 `runtime-resources.txt` 复制清单，预览复制真实配置（报告 293/294）。
- 新增门禁：`Sources/*.swift` 必须被 `dev-preview.sh` 编译或在显式例外清单里（`test-preview-menu.py`）。

## 4. 已知限制

- 练习「回车」不再有作用（与输入法语义统一是有意为之）。
- 数字后用方向键/鼠标移开光标仍不消耗"数字后标点"标记（ADR-325 既有边界）。
- 练习窗口的暗色**离屏实拍**为空白（既有渲染路径问题，不影响真实窗口；报告 296 §4）。
- 五笔 86 覆盖率停在许可数据上限：3,000 字 `full` 2,614（87.1%），其余保持占位不猜（ADR-358/359）。
