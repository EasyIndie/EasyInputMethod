# 萤火虫 1.4.1 发布稿

> 状态：**待发布**。范围：安装体验四处修复（ADR-390 / 报告 332）。产品输入行为、词库、配置、隐私口径**零改动**。
> 上一次发布：[1.4.0](1.4.0.md)（2026-11-20，build 48）。

## 1. 为什么发这一版

1.4.0 发布后，在一台**不属于开发机的 MacBook Air、普通（非管理员）帐户**上走了第一次真实安装（产品页下载 → DMG →
「安装萤火虫」），四处问题全部暴露。这是 1.0–1.4 所有安装验收都漏掉的场景：**开发机全都有 Xcode / Command Line Tools**。

| # | 现象 | 根因 |
|---|---|---|
| 1 | 安装直接失败：`候选校验失败：/usr/bin/xcrun 校验失败` | 校验链调用 `xcrun stapler validate`，而 `xcrun` 只在装了 Command Line Tools 的机器上可用 |
| 2 | `LampyrisUpdateCheck.app` 双击打不开 | 只认 `--ui`；Finder 双击不带参数，程序打印一行后退出 |
| 3 | 「安装萤火虫」窗口顶部内容被标题栏压住 | 手写 326pt frame 放进 286pt 内容视图，超出的 40pt 从底部往上长 |
| 4 | 四个 app 图标一样、外面多一圈白边 | 共用同一份旧式 ICNS（自带白边圆角），macOS 26 会把它放进白色托板 |

## 2. 这一版做了什么

1. **安装期校验不再依赖 Xcode 工具链**：公证票据就是 bundle 里的 `Contents/CodeResources`，安装器只查它在且非空，
   「Apple 是否认可」交给 `spctl --assess --type execute`（离线只认票据）。`install.sh` 同一口径。
   **没有放宽任何一项校验**（身份 / Developer ID / hardened runtime / 票据 / Gatekeeper 全保留）。
2. **更新程序双击即开窗**：无参数启动与 `--ui` 同一入口。**开窗不联网**，仍只有用户按「检查更新」才发请求；
   `--check` / `--verify-payload` / `--drill-run` 不变。
3. **安装器窗口按内容定高**：约束布局（宽度固定 520）+ `fittingSize`，文案变长后重算并保持左上角不动。
4. **图标区分**：ICNS 母版换成 full-bleed 母版；安装器 / 卸载器 / 更新程序各一张「萤火虫 + 角色角标」。
   输入法本体图标保持纯萤火虫。

**不做什么**：不改输入法键盘行为、候选排序、词库、配置项；不改宿主零网络；不把背景程序 `Lampyris.app`
从 DMG 顶层挪走（打包结构变更另行评估）。

## 3. 这一版要求你验证什么

必须在**干净机器**（普通帐户、无 Xcode/Command Line Tools）上走真实下载链路：

1. 产品页下载 DMG → 双击「安装萤火虫」→ 点「安装」：**不得**再报 `候选校验失败`；
2. `~/Applications/LampyrisUpdateCheck.app` 双击：**必须**出窗口（且不自动联网）；
3. 安装器窗口：头像、标题、页脚完整可见；
4. DMG 里四个图标可区分、无白色托板。

以上四项在开发机（有 Xcode）上已验布局/图标/契约（报告 332 §4），但**干净工具链 + 普通帐户**只能由这一版真机确认。
