## 2. 行为变更（用户可感知）

这一版是**数据与文档版**：输入引擎、配置、窗口行为都没有改动，换的是教学数据。

### 2.1 学习区五笔 86 覆盖率到 100%（ADR-377/378/380/384）

| 指标 | 1.3.1 | 1.3.2 |
|---|---|---|
| GB2312 一级 3,755 字「完整码」 | 3,435（91.5%） | **3,755（100.0%）** |
| 学习字表 5,021 字 `full` | 4,546 | **4,993（99.4%）** |
| 学习字表 `partial` | 475 | **28** |
| 可解释识别码条数 | — | **2,739** |

用户能看到的变化：

- 练习与「学习」里的字，几乎所有字都能同时给出**拆字根序**和**识别码理由**（例如 `是 · 日+一+乛+U（捺·上下）`），
  不再只显示码串。
- 覆盖率口径仍是 **GB2312 一级**；一级之外的 28 字保持占位并写明缺口，**不猜**（ADR-382）。

### 2.2 新增《五笔输入原理》文档

从零学五笔的单页说明：五种笔画与 5×5 区位、25 句助记、键名字/成字字根、拆字四规则、取码四情形、
识别码网格与实例、简码与词组规则，以及本项目数据层的三个概念（码表 / 根序表 / 勘误表）与「不猜」原则。

### 2.3 标准与可核验性（仓库侧，不影响安装包行为）

- **LWS-86 1.0 草案**：本项目的五笔 86 拆字标准（规范 + conformance + 数据包 + 判定器），任何人可拿自己的
  码表跑一致性检查（L1–L4）。
- **码表勘误机制**：与许可源表分离的勘误层，`active` 必须有外部资料佐证（一次假阳性教训，ADR-384）。
- 与外部表的**码级交叉验证**：13,368 个共字中 13,363 个完全一致（99.96%），差异都是扩展区生僻字形。

## 3.1 性能门禁的一次越界（已归因，非回归）

验收脚本内 footprint 读到 44.1 MiB（硬顶 44.0），同一二进制单独复测 42.6 / 36.5 / 36.5 / 35.9 MiB，
装后首跑 57.3 MiB。真值 35.9 MiB（1.3.1 为 34.1，+1.8 MiB / 字表 +34%）；硬门禁 `heap live` 稳定 21.3–21.7（限 24）。
不改阈值，采样协议（预热→静置→再测）列入待办。

## 4. 已知限制

- 学习字表仍有 **28 字**为 `partial`（GB2312 一级之外）：5 条 IDS 只有一层、约 10 条生僻部件（菐/𥑒/縣）无拆法证据、
  约 13 条 IDS 与码表口径冲突；每条在 `docs/tasks/T-ROOT86.md` §2 与 `build/inference/` 有命名卡点。
- LWS-86 仍是**草案**，转正按 ADR-382 放到下一个大版本。
- 1.3.1 的已知限制依旧成立（练习回车无作用、数字后标点标记边界、练习窗口离屏实拍空白）。
