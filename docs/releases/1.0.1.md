## 2. 内容（相对 1.0.0）

- **设置页「字符宽度」（ADR-305）**：由复选框改为下拉（半角/全角），与「标点风格」「输出字形」一致；标题由「全角 ASCII」改为「字符宽度」。
- **⌥F 改为写配置并持久化**：面板同一行随配置即时刷新；重启后保持偏好。核心仍保留临时覆盖能力供 CLI/测试使用。
- **旧配置只读迁移**：`full_width = false/true` 读作 `half/full`，不主动改写用户文件；再次写入该键时把过期的「可临时切换」注释刷新为新说明。
- 修复范围仅限设置页与全半角状态，不改变候选顺序、键位与其它偏好。

## 3. 验证

- `ime-config` 新增 3 个单测：旧布尔迁移（含"不改写文件"）、枚举拒绝非法值、迁移后注释刷新
- `settings-presentation` 新增断言：字形/标点/宽度同为下拉、宽度选项为 半角/全角（模式为分段控件，属既有设计）
- `make verify` + 离线回归 56 文件 / 303 例全绿；PR #216/#217 四项 CI 全 PASS
- 实机：用户确认三条（下拉形态、⌥F 即时反映、设置改后芯片与重启保持）PASS

## 4. 已知限制

- 浏览器地址栏组合中失焦可能残留原始编码，Esc 取消（UX-1，macOS IMK 限制）。
- ⌥M 切到没有候选的模式时，候选窗隐藏、编码以预编辑文本留在输入框（ADR-302 的取舍）。
