# 1.2.1（build 40）

> **状态：候选开发中（2026-11-09）**——P0 补丁档：安装体验与练习页无障碍；不改候选顺序、不改引擎行为。
> 发布材料在打 tag 后回填资产与回读结果。

## 1. 内容（相对 1.2.0）

| 项 | 变化 |
|---|---|
| **覆盖安装后旧宿主** | 安装器检测到仍有宿主跑在被移走的备份 inode 时：交互式安装会询问是否重启（`LAMPYRIS_RESTART_HOST=1` 可自动），不再只打印"重新登录" |
| **输入源缺失** | 安装尾部（`LampyrisTIS` 回读未通过）时给出恢复步骤，并在交互式/`LAMPYRIS_OPEN_SETTINGS=1` 时直接打开「键盘 → 文字输入」设置页 |
| **练习页无障碍** | 作答格有 `textField` 角色与实时值、进度条有数值、判分结果用 VoiceOver 播报；键位图有说明性 help 文本 |
| **回归稳定性** | 离线回归默认并发 4（Swift 编译不再互相抢资源导致假超时）；个别测试的超时上限提到 180s |
| **文档** | `docs/故障恢复.md` 新增 §4.4（Terminal 里 ⌥L 被终端吞掉）；完成态计划归档、索引与待办对齐；删除死代码与死资源（见下） |
