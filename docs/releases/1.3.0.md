# 1.3.0（build 43，已发布）

> **状态：已发布（2026-11-13）**——小版本：输入体验、学练闭环与数据地基。tag `v1.3.0`、Release、站点均已上线。

## 1. 内容（相对 1.2.1）

### 输入体验

| 项 | 变化 |
|---|---|
| **五笔连续单字自动造词** | 新增 `wubi.auto_phrase`（默认关）：纯五笔、2–4 个单字、相邻 ≤2 秒、同一串 3 次后写入用户词库（ADR-341） |
| **日期 / 时间 / 星期候选** | 全拼 `riqi` / `shijian` / `xingqi` 首位给出当前日期、24 小时时间、星期；环境候选不学习（ADR-342） |
| **以词定字跟随高亮** | `[` / `]` 从方向键高亮的候选取首/末字，不再固定首选（ADR-339） |
| **三级简码** | 3,362 条官方三级简码入表（D17-ter，LGPL-3.0）；三码 + 空格精确上屏，四码自动上屏规则不变（ADR-345） |
| **延迟脚本** | 失焦轮次不再让性能汇总崩溃（报告 267） |

### 学练闭环

| 项 | 变化 |
|---|---|
| **首次启用上手提示** | 正式宿主第一次激活弹一次，列出模式/设置/练习/学习区快捷键；标记文件 `onboarding-done`（ADR-343） |
| **练习进阶建议** | 某题型练过 ≥30 字且正确率 ≥90% 时建议下一题型，不锁定（ADR-344） |
| **文章跟打** | 练习窗口新增入口：100 条自编短句，独立窗口，逐字判定，会话内统计（ADR-347） |

### 工程与边界

| 项 | 变化 |
|---|---|
| **安装器分支回归** | 自动重启旧宿主、打开键盘设置、强制覆盖三条路径纳入离线回归（报告 267） |
| **离线回归提速** | 共享 Swift 模块缓存，并发回到 6；62 文件 / 332 例约 35 秒（报告 267） |
| **验收私有数据根** | 键入样本默认使用 `LAMPYRIS_SUPPORT_DIR`，不再改用户词库/配置（ADR-340） |
| **CI 运行机可选** | `macos-acceptance.yml` / `release.yml` 可手动指定 runner（报告 267） |
| **核心/扩展边界** | 核心、可选内置、数据包三层边界；列出清理候选（ADR-346） |

## 2. 未包含 / 已知限制

- **高频字拆解补齐**：876 条 partial 中 738 条缺 D2 补充区私有字根身份，现有许可来源无法补齐；
  不猜测填充（报告 268 §2）。学习区仍显示「？」。
- **文章跟打**只有本次会话统计，不保存历史、不评分排名。
- 扩展词库、整句模型、多方案码表仍需外部数据与许可，未包含。
- 五笔造词默认关闭；开启后候选顺序会随学到的词变化。
- 三级简码的权重沿用全码频度，不是简码使用频度。
- 冷首键 ~28 ms、学习区常驻内存等沿用 1.2.x 的已知限制。
