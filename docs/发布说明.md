这一版只动更新链路与安装脚本，**输入路径代码未改**：

## 3. 功能与已知限制

- 默认**混输**（五笔优先、拼音兜底）；三模式「混输 / 五笔 / 拼音」可切换并持久化。
- 候选来源：混输页出现多种来源时，在候选后标注小号「五笔／拼」。
- 拼音反查：输入「你好」得到 `ni hao`（首选无调读音）。
- **简/繁切换**（`Ctrl+Shift+F`）：输出简体/繁体（数据 OpenCC，Apache-2.0；仅简→繁）。
- **辅助技术播报（本版新增，ADR-291）**：开启 VoiceOver 后，候选面板弹出会念输入编码；**换候选**念「第N项，文字，来源」（翻页时前缀「第M页，共K页」），**上屏**念「文字，已上屏」。候选容器同时暴露 `AXSelectedChildren`/`AXSelected`，屏幕阅读器可以自己浏览候选列表。不改变可见界面与键位。

- **从 0.1.14 升级时的已知限制**：0.1.14 的输入法菜单只按旧名 `~/Applications/Lampyris Update.app` 找更新程序，找不到就直接打开 Releases 网页；本版起改为按 bundle id 定位（ADR-294），不再依赖名字。
- **0.1.15 的更新窗口标题**：该版本在安装成功后不刷新标题（显示更新程序自身版本），以状态行「已安装构建 N」与「关于」页为准；**0.1.16 已修**（标题读已安装宿主并在安装后刷新）。另：换包后请关掉旧的更新窗口，旧进程会一直显示旧文案（报告214 §8）。

**数据上限与覆盖**：

- 默认拼音词表 `pinyin-core.tsv`（约 256 KiB），**不加载** 8.4 MB 全量词表（ADR-031）。
- 用户词库：有界 TSV v1 —— ≤ **2 MiB**、≤ **10000** 条；编码 ≤ 64 字节、文本 ≤ 256 字节（ADR-029）。
- 组合输入上限：**64 字符**，超出忽略后续字母（ADR-062）。
- 拼音为**轻量兜底**，不等同整句 / 长词质量。
- **升级方式**：本版 Release 同时提供独立的更新检查程序（`LampyrisUpdateCheck-0.1.14.zip`）与 appcast；DMG 内的安装器不包含自动更新。手动升级可直接用新版 DMG 覆盖安装，配置与词库保留。
- **VoiceOver（曾报、已复测不可复现）**：0.1.14/build 23 上曾观察到 air（macOS 27）开启 VoiceOver 后**已安装输入法**的输入上下文掉回 ABC（裸编码 + 菜单「正在加载…」）。0.1.16/build 26 按同一条件复测（VO 先开 → 宿主重启 → 立即打字）**正常组字**，实测打出「你」并有候选窗；报告215 已将其降级为不可复现的单次观察。若你仍遇到，请按报告215 §1 的条件 A/B 复现并附日志。
- **浏览器地址栏的预编辑残留（已知，UX-1）**：在 Chrome 地址栏组合中（候选窗已出现）切换窗口/点击页面、或 Safari 地址栏点击页面后，地址栏会留下原始编码字母（如 `nihao`）。原因在 macOS IMK：客户端失焦时 IMK 会把预编辑**原样取消标记**成普通文本，而该时机在输入法收到任何回调之前（详见 `docs/tasks/MVP-05.md` §2.2）。其它应用不受影响。

## 4. 快捷键与配置

| 快捷键（默认） | 作用 | 设置项 / 写入配置 |
|---|---|---|
| **单独按 `Shift`**（松开且期间无其它键） | 中/英切换 | `hotkey.toggle_english`；否 |
| **`⌥F`** | 全角/半角切换 | `hotkey.toggle_width`；否（会话级临时切换） |
| **`⌥M`** | 循环切换 混输 → 五笔 → 拼音 | `hotkey.toggle_mode`；是（写回 `config.toml`） |
| **`⌥P`** | 中/英标点切换 | `hotkey.toggle_punctuation`；是（写回 `config.toml`） |
| **`⌥T`** | 简/繁切换 | `hotkey.toggle_variant`；是（写回 `config.toml`） |
| **`⌥L`** | 显示/隐藏学习区 | `hotkey.toggle_wubi_learning`；是（写回 `config.toml`） |
| **`⌥,`** | 打开设置 | `hotkey.open_settings`；— |
| **`⌥A`** | 关于 | `hotkey.open_about`；— |
| **`,` / `.`**（组合态） | 上一页 / 下一页候选 | `candidate.page_with_comma`；否 |

> 每次状态变化（中英 / 全角半角 / 简体繁体 / 标点 / 模式 / 学习区）都会即时反馈：候选框可见时在顶部右侧（翻页区左边）更新两字状态芯片（混输/五笔/拼音、全角/半角、简体/繁体 + 标点；中英不显示，见 ADR-303）；候选框未显示时在光标上方弹出约 1.15 秒的提示（仅在聚焦文本输入框时）。两者都不抢焦点、不写配置。

> 各组快捷键都可在 `config.toml` 改：组合键写法 `ctrl|shift|alt|cmd + 键`（空格写 `space`）；`hotkey.toggle_english = "shift"` 表示“单独按 Shift”；任一项设为 `"none"` 即关闭。输入法菜单的状态项（混输/五笔/拼音、中文/英文、全角/半角、简体/繁体、中文标点/英文标点）**直接显示当前值**并在右侧列出快捷键（单按 Shift 切中英时在快捷键位显示 `⇧`）；菜单「偏好设置」打开设置面板（设置项即列出全部可调项与快捷键）；「版本信息」窗口含诊断，可「复制信息」或点「反馈问题」/「反馈漏洞」跳转。

唯一配置文件：`~/Library/Application Support/Lampyris/config.toml`（改后**无需重启/再按键即生效**；写坏时沿用上一份有效设置并提示）。全部可配置项只由 Schema 定义，见 `docs/配置架构.md`。

## 5. 用户词库导入 / 导出格式

```
# lampyris-user-dictionary v1
scheme	code	text	count
```

- `scheme` ∈ {`wubi`, `pinyin`}；`code` 为不带空格的小写编码；`count` 为正整数。
- 无效导入**不覆盖**原文件；重复导入合并取**最大**次数；导出不得覆盖配置或正在使用的词库。

## 6. 安装 / 卸载 / 恢复

- **安装**：用保留 Unix 执行权限的工具解压（Finder 或 `ditto -x -k`）；先 `install.sh --dry-run` 校验 Gatekeeper，再安装；注销/重新登录后在「系统设置 → 键盘 → 文字输入」添加。
- **卸载**：先切换 ABC、在系统设置移除输入源、注销，再 `uninstall.sh --input-source-removed`；**保留** config 与词库。
- **全新安装（一条命令）**：先切 ABC、在系统设置移除输入源并注销；重登后 `make macos-clean-install APP=<Lampyris.app 路径>`（等价于 `scripts/clean-install.sh --app <路径> --input-source-removed`），脚本会卸载旧包（带 `--purge-data`）、安装新包并校验签名/公证/执行 SHA；`ARGS=--keep-data` 可保留旧配置与词库。
- **全新安装（以默认行为为起点，手工步骤）**：步骤同上，但执行 `uninstall.sh --input-source-removed --purge-data`——旧包移入 `uninstalled/bundle.*/`，`config.toml` 与 `user-dictionary.tsv` 移入 `uninstalled/data.*/`（**移动而非删除**）。注销重登后装新包，首次启动按 Schema 默认值生成配置、学习词库为空，快捷键等行为就是当前版本的默认值。执行前先跑 `uninstall.sh --dry-run --purge-data` 看计划（预检不需要先退出宿主）。
- **故障恢复**（配置错误 / 词库残留锁 / 容量权限 / 数据缺失）：见 `docs/故障恢复.md`。

## 7. 隐私

默认**零网络、零遥测、无账号、无广告、无云同步**。源码侧 `make verify-no-network` 断言；实机可用 `lsof -nP -a -p <宿主PID> -i` 核查无外联。
