## 3. 功能与已知限制

- 默认**混输**（五笔优先、拼音兜底）；三模式「混输 / 五笔 / 拼音」可切换并持久化。
- 候选来源：混输页出现多种来源时，在候选后标注小号「五笔／拼」。
- 拼音反查：输入「你好」得到 `ni hao`（首选无调读音）。
- **简/繁切换**（`Ctrl+Shift+F`）：输出简体/繁体（数据 OpenCC，Apache-2.0；仅简→繁）。

**数据上限与覆盖**：

- 默认拼音词表 `pinyin-core.tsv`（约 256 KiB），**不加载** 8.4 MB 全量词表（ADR-031）。
- 用户词库：有界 TSV v1 —— ≤ **2 MiB**、≤ **10000** 条；编码 ≤ 64 字节、文本 ≤ 256 字节（ADR-029）。
- 组合输入上限：**64 字符**，超出忽略后续字母（ADR-062）。
- 拼音为**轻量兜底**，不等同整句 / 长词质量。
- **浏览器地址栏的预编辑残留（已知）**：在 Chrome 地址栏组合中（候选窗已出现）切换窗口/点击页面、或 Safari 地址栏点击页面后，地址栏会留下原始编码字母（如 `nihao`）。原因在 macOS IMK：客户端失焦时 IMK 会把预编辑**原样取消标记**成普通文本，而该时机在输入法收到任何回调之前（详见 `docs/tasks/MVP-05.md` §2.2）。其它应用不受影响。

## 4. 快捷键与配置

| 快捷键（默认） | 作用 | 设置项 / 写入配置 |
|---|---|---|
| **单独按 `Shift`**（松开且期间无其它键） | 中/英切换 | `hotkey.toggle_english`；否 |
| **`Shift+Space`** | 全角/半角切换 | `hotkey.toggle_width`；否 |
| **`Ctrl+Shift+M`** | 循环切换 混输 → 五笔 → 拼音 | `hotkey.toggle_mode`；是（写回 `config.toml`） |
| **`Ctrl+.`** | 中/英标点切换 | `hotkey.toggle_punctuation`；是（写回 `config.toml`） |
| **`Ctrl+Shift+F`** | 简/繁切换 | `hotkey.toggle_variant`；是（写回 `config.toml`） |
| **`,` / `.`**（组合态） | 上一页 / 下一页候选 | `candidate.page_with_comma`；否 |

> 各组快捷键都可在 `config.toml` 改：组合键写法 `ctrl|shift|alt|cmd + 键`（空格写 `space`）；`hotkey.toggle_english = "shift"` 表示“单独按 Shift”；任一项设为 `"none"` 即关闭。输入法菜单的状态项（混输/五笔/拼音、中文/英文、全角/半角、简体/繁体、中文标点/英文标点）**直接显示当前值**并在右侧列出快捷键（单按 Shift 切中英时在快捷键位显示 `⇧`）；菜单「偏好设置」打开设置面板（设置项即列出全部可调项与快捷键）；「版本信息」窗口含诊断，可「复制信息」或点「反馈问题」/「反馈漏洞」跳转。

唯一配置文件：`~/Library/Application Support/Lampyris/config.toml`（改后**无需重启/再按键即生效**；写坏时沿用上一份有效设置并提示）。全部可配置项只由 Schema 定义，见 `docs/配置架构.md`。

## 5. 用户词库导入 / 导出格式

```
# lampyris-user-dictionary v1
scheme	code	text	count
```

- `scheme` ∈ {`wubi`, `pinyin`}；`code` 为不带空格的小写编码；`count` 为正整数。
- 无效导入**不覆盖**原文件；重复导入合并取**最大**次数；导出不得覆盖配置或正在使用的词库。

## 6. 安装 / 卸载 / 恢复

- **安装**：用保留 Unix 执行权限的工具解压（Finder 或 `ditto -x -k`）；先 `install.sh --dry-run` 校验 Gatekeeper，再安装；注销/重新登录后在「系统设置 → 键盘 → 文字输入」添加。
- **卸载**：先切换 ABC、在系统设置移除输入源、注销，再 `uninstall.sh --input-source-removed`；**保留** config 与词库。
- **故障恢复**（配置错误 / 词库残留锁 / 容量权限 / 数据缺失）：见 `docs/故障恢复.md`。

## 7. 隐私

默认**零网络、零遥测、无账号、无广告、无云同步**。源码侧 `make verify-no-network` 断言；实机可用 `lsof -nP -a -p <宿主PID> -i` 核查无外联。

## 8. 分发与源码（GPL-3.0 §6(d)，ADR-064/065）

**发布渠道：GitHub Release（产物）+ GitHub Pages（下载指引）。** 同一个 Release 包含**两份产物**：
