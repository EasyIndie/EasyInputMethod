## 1. 术语与产物

## 2. 本机自动验收（基线）

前提：

- 萤火虫已安装，且在「系统设置 → 键盘 → 文字输入」里添加为输入源；
- **运行脚本的终端 App 已授权「系统设置 → 隐私与安全性 → 辅助功能」**（否则发不出按键）。

```sh
./platforms/macos/tests/run-imk-acceptance.sh                               # 14 项（默认）
IMK_ACCEPTANCE_PERF=1    ./platforms/macos/tests/run-imk-acceptance.sh      # +⑪ 引擎按键时延（较慢）
IMK_ACCEPTANCE_RESTART=1 ./platforms/macos/tests/run-imk-acceptance.sh      # +④ 重启宿主后仍生效
IMK_ACCEPTANCE_CONFIG_ERROR=1 ./platforms/macos/tests/run-imk-acceptance.sh # +⑥ 配置错误弹窗（模态，只跑一次）
```

- 通过标准：最后一行 `SUMMARY pass=<N> fail=0`。
- 脚本会临时改 `~/Library/Application Support/Lampyris/config.toml`，**退出时自动还原**；
  自建的 TextEdit 文档也会**自动关闭**，不会在桌面留窗口。
- `CONFIG_ERROR` 是模态、会让当前实例短暂降级 → 跑完建议注销重登（或切一次输入源）。

## 3. 剩余人工项（本机，约 15 分钟）

> 每项做完就在 [`MVP-05.md`](./tasks/MVP-05.md) 对应行把 `☐ 通过` / `☐ 不通过` 勾掉，
> 并在「证据 / 备注」写上机型 + 系统版本 + 你看到的现象。

打开面板：**输入法菜单 → 偏好设置**（面板顶部是「设置 / 词库」两段）。

### ⑦ 用户词库（新增 → 输入 → 重启后仍在）

1. 面板 → **词库** → **新增词条…**；
2. 方案选「五笔」，编码填 `fhqi`（小写字母），文本填 `验收词`，点「添加」；
3. 切到 TextEdit，**切到五笔模式**（输入法菜单 → 混输/五笔），输入 `fhqi` → 候选里应出现「验收词」，选它上屏；
4. **重启宿主**：`killall Lampyris`，再用 `Ctrl+Space` 切回来；
5. 再输入 `fhqi` → 「验收词」**仍在候选里**。

- ✅ 预期：第 3 步能上屏，第 5 步重启后词条仍存在。
- 落盘位置：`~/Library/Application Support/Lampyris/user-dictionary.tsv`（可直接 `cat` 看到该行）。

### ⑧ 导入 / 导出（往返 + 坏文件被拒）

1. 面板 → 词库 → **导出用户词库…** → 存成 `~/Desktop/lampyris-export.tsv`；
   打开看一眼：应是 `方案<TAB>编码<TAB>文本<TAB>次数` 的文本行。
2. 面板 → 词库 → **导入用户词库…** → 选刚导出的同一个文件 → **不应弹错误**，候选行为不变。
3. **坏文件**：用编辑器写一个 `坏文件.tsv`，内容随便写 `这是一行胡说八道`，同样导入；
4. ✅ 预期：第 3 步弹出「**用户词库操作失败**」提示，且**原有词条未被覆盖**（回面板再导出一次对比即可）。

### ⑨ 拼音反查

1. 面板 → 词库 → **拼音反查…**；
2. 输入框填 `你好` → 点「查询」；
3. ✅ 预期：结果窗显示 `ni hao`（内置词表首选读音，纯本地）。
4. 可补一个反例：输入一个生僻/超长文本 → 显示「未收录此读音…」。

### ⑩ 五应用 + `Cmd+Z`（TextEdit / Safari / VS Code / 微信 / Terminal）

在**每个**应用里都做一遍同样的 4 个动作：

| 动作 | ✅ 预期 |
|---|---|
| 输入一段中文（`nihao` → 空格） | 上屏位置在光标处，**候选窗跟在光标下方/上方，不跑到别的屏幕** |
| 用方向键把光标移到句子中间，再输入 | 新字**插在光标处**，已上屏的字不被破坏 |
| 输入中按 `Cmd+Z` | 撤销应回退**最后一次上屏**；不出现乱码/残留/重复 |
| 切换窗口/失焦再回来输入 | 预编辑被清空，不残留候选窗 |

- ✅ 结论：五个应用都正常 → 通过；记录哪个应用 + 哪个动作有问题（附最小复现步骤）。

### ⑬ 亮 / 暗主题

1. 系统设置 → 外观 → 切「浅色」与「深色」各看一遍；
2. 检查四处：**候选窗**、**输入法菜单**、**偏好设置面板**、**版本信息窗**；
3. ✅ 预期：文字与背景对比清晰，边框/选中项可见，**没有深色下黑字黑底之类的不可读**。

## 4. 第二台 Mac（多设备 / MVP-14 / P1-M5）

### 4.1 目标机要求

- macOS 版本**与本机不同**更有价值（例如本机 15.x → 目标机 14.x 或 26.x）；
- 安装 Xcode 命令行工具（脚本编译探针用）：`xcode-select --install`；
- 想跑 `IMK_ACCEPTANCE_PERF=1` 才需要 Rust 工具链 + `rust-toolchain.toml` 指定的版本。

### 4.2 安装 ad-hoc 候选包（不用 `install.sh`）

```sh
# 1) 把 Lampyris-0.1.0-<arch>.zip 与同名 .sha256 拷到目标机
cd ~/Downloads && shasum -a 256 -c Lampyris-0.1.0-universal.zip.sha256

# 2) 解压并去掉隔离属性（跨机拷贝会带 com.apple.quarantine）
TMP=$(mktemp -d) && ditto -x -k Lampyris-0.1.0-universal.zip "$TMP"
APP="$(find "$TMP" -maxdepth 2 -name Lampyris.app -type d | head -1)"
xattr -dr com.apple.quarantine "$APP" 2>/dev/null || true

# 3) 装到用户域（先备份旧版）
killall Lampyris 2>/dev/null || true; sleep 1
DEST="$HOME/Library/Input Methods/Lampyris.app"
[ -e "$DEST" ] && mv "$DEST" "$DEST.$(date +%Y%m%d-%H%M%S).bak"
mkdir -p "$HOME/Library/Input Methods"
ditto "$APP" "$DEST"
/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -f "$DEST"

# 4) 核对装的就是这个源码版本
cat "$DEST/Contents/Resources/SOURCE-COMMIT"
```

先 **移走旧版/同名旧构建**再说：本项目改名前的构建（`org.yinghuo.inputmethod.Yinghuo`）**显示名也叫「萤火虫」**，留着会在系统设置里变成两个同名输入法。

```sh
LSREG=/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister
OLD="$HOME/Library/Input Methods/<旧名>.app"
"$LSREG" -u "$OLD"          # 先注销登记，再移走
mv "$OLD" "$HOME/旧构建备份/"
```

**注销/重新登录**（或重启），然后：系统设置 → 键盘 → 文字输入 → 编辑… → `+` → 简体中文 → **萤火虫**。

### 4.3 跑自动验收

验收脚本在**仓库**里（不在候选包内），所以目标机需要源码：

```sh
git clone https://github.com/EasyIndie/EasyInputMethod.git && cd EasyInputMethod
git rev-parse HEAD          # 应与上面 SOURCE-COMMIT 一致（一致才能声称「验的是这个包」）
# 终端 App 授权「辅助功能」后：
./platforms/macos/tests/run-imk-acceptance.sh
```

（没有仓库时，也可用对应源码包 `Lampyris-0.1.0-source.tar.gz` 解开跑，脚本只依赖 `swiftc`。）

## 6. 已知坑（踩过就别再踩）

- **ad-hoc 包不能用 `scripts/install.sh`**：它要求 Developer ID + hardened runtime + 公证。
- **升级后必须注销重登**：否则 `imklaunchd` 可能仍加载旧二进制。
- **别留着解压出来的 app 副本**：被 LaunchServices 注册后会变成"影子副本"输入源。
  清了它：`lsregister -u <路径>`，或直接删掉解压目录。
- **终端必须授权辅助功能**：否则脚本第 2 步就退出。
- **`CONFIG_ERROR` 是模态**：会让当前实例降级（后续实时刷新失效），跑完切一次输入源或注销。
- **探针会被系统清理**：脚本把 `im-select` 编译到自己的临时目录，不受 `/tmp` 清理影响。
- **GUI 自动化不能在 SSH 里跑**：从 SSH 会话 `osascript` 会 `AppleEvent 超时（-1712）`；
  必须在目标机的**控制台终端**里跑（`launchctl asuser` 需要 root，通常没有）。
  所以远程只能做「传包 + `ditto` 安装 + 更新仓库」，**跑验收和人工项要到机器前面去**。
- **同名旧构建**：改名前的构建会在系统设置里与新包重名，安装前先 `lsregister -u` 再移走（见 §4.2）。
- **菜单项只能靠辅助功能（AX）读**：点击有时机抖动，读之前最好先让 IME 成为激活输入源。
