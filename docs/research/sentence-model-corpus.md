# 整句模型语料与方案调研（U3-1 / ADR-352 前置）

> 2026-11-14。**本次只调研，不下载语料、不改仓库数据、不改引擎代码。**
> 目标：为「拼音整句输入」选一条许可干净、可复现、体积可控的语料路线，并给出模型格式与内存/延迟预算。

## 0. 要解决什么

现有拼音兜底已有 ADR-299 的「多词分段拼接」：`wo|ai|ni` → 我爱你、`zhong|guo|ren` → 中国人。
它按「段数少 → 左长优先 → 权重和」选唯一路径，**不理解上下文**，因此：

- `chi fan ba` / `chi fan ba?` 这类句末 `吧/把/巴` 无法按语法选择；
- 多个合法分词路径分数接近时，只能靠最长匹配；
- 词与词的搭配（`吃饭` vs `吃返`）没有统计依据。

整句模型要做的是：在词格（word lattice）上用 **bigram** 给路径打分，选一条上下文更合理的整句候选。
它不改变单字/整词精确命中的优先级，也不替代用户逐段选词。

## 2. 数据管线（建议）

```text
fetch（固定 dump/分片 + SHA 校验，原始文件不入库）
  ↓ bz2 流式解压，逐 <page> 解析
  抽 <text> → 去模板/ref/表格/HTML 标签 → 只保留中文句子
  ↓ 用现有拼音词表做最长匹配分词（core 20k；扩展档另行评估）
  句边界重置；统计相邻词对 (w1,w2) 次数
  ↓ 剪枝：count ≥ 3；映射到词表内词；按 count 取前 200k–300k 对
输出 data/generated/pinyin-bigram.tsv（prev\tnext\tcount）
  + pinyin-bigram-report.json（源 SHA、词表 SHA、行数、剪枝规则、产物 SHA）
```

- 分词器复用 `data/generated/pinyin-core.tsv` / `pinyin-words.tsv` 的词表，构建期用 Python 最长匹配；
  不引入 jieba 运行时依赖，也不把分词结果入库。
- 句子切分按 `。！？；\n` 与长度上限（如 120 字）切；去掉纯数字/纯拉丁/模板残留。
- 训练/评测隔离：Wikipedia 只训练；评测用 `input-quality.tsv` holdout + 自编句子，绝不拿评测句训练。

## 3. 模型格式与运行时

| 方案 | 磁盘 | 预计常驻 | 优点 | 缺点 |
|---|---|---|---|---|
| **TSV `prev\tnext\tcount`** | 6–10 MB | 12–20 MiB（HashMap 字符串开销） | 可审计、与现有数据风格一致 | 字符串重复、加载慢 |
| 二进制定长表（词 ID + count，排序数组） | 3–5 MB | 6–10 MiB | 省内存、查找快 | 需可复现编译器 + 词表 SHA 绑定 |

**建议**：原型先用 TSV（可审计、最快落地）；如果实测内存超过可选档预算，再按 ADR-060 的「可复现二进制」路线
编译成 `pinyin-bigram.bin`，并在报告里给出 TSV→二进制的 SHA 与校验器。

- 词 ID 使用拼音词表的稳定顺序；模型头记录：
  `magic/version`、词表 SHA-256、bigram 数、剪枝阈值。词表 SHA 不匹配直接禁用模型并回退 ADR-299。
- 排序：`score = log P(w1) + Σ log P(w_i|w_{i-1})`；未见 bigram 回退到 unigram（加固定惩罚）。
- 候选：只在「整串不是精确词条」时参与；精确词条永远排前；整句候选 `consumed = 全部输入`。
- 配置：新增 `pinyin.sentence_model`（Bool，默认 **false**）。关闭时不加载模型，行为与 ADR-299 完全一致；
  打开后才读 `pinyin-bigram.tsv`。模型缺失/损坏时回退旧拼接并显示一次资源错误。
- 资源门禁：核心档 24 MiB 不变；整句模型作为可选档，另定门槛（预计 40–48 MiB），只作可选验收。

## 4. 预算与风险

- **内存**：200k 条 TSV 预计 12–20 MiB 常驻；词表已常驻，不重复计。若超 48 MiB，改用二进制/ID 表。
- **延迟**：输入 ≤64 字节、音节 ≤20；词格节点数百，bigram 哈希 O(1)；预计 p95 增量 <1 ms。
- **体积**：TSV 6–10 MB；压缩后包体增量约 2–4 MB。
- **风格偏差**：百科书面语对 `吧/把` 这类口语虚词的区分有限；先以评测数字为准，不宣称「理解语法」。
- **分词误差**：用现有词表最长匹配会产生错误切分，可能污染 bigram；需要在报告里统计切分失败率/未登录词比例。
- **许可**：CC BY-SA 4.0，派生模型同许可；分发时保留 Wikimedia 署名与许可链接；原始 dump 不入库。
