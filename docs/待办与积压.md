> 2026-11-09 重排（1.2.1 发布后）。**线上版本 = 1.2.1 / build 40**（tag `v1.2.1` → `168115e`，站点 `v1.2.1 · 构建 40`）。
> 这份文件回答"还剩什么、下一版装什么、哪些明确不做"。非目标见 [AGENTS.md](../AGENTS.md) §3。
> 成本口径：**S** ≤2 人日；**M** 3–5 人日；**L** 1–2 周；**XL** >2 周。"授权"= 是否需你单独批（换包/发布/删数据/联网下载）。

## 0. 版本语义

| 改动类型 | 版本 | 原因 |
|---|---|---|
| 改候选顺序 / 键位手感 / 简码 | 小版本（1.3.0…） | 用户要能用版本号区分手感变化 |
| 只加只读 UI（提示、练习窗） | 小版本 | 可关闭、不影响排序 |
| 纯缺陷 / 安全 / 安装体验 | 补丁（1.2.x） | 可回滚到"只修 bug"的状态 |
| 新平台 | 独立项目/里程碑 | 不跟 macOS 质量同批，否则回归无法归因 |

## 1. 现在的位置

- 1.2.1 的**代码改动全部落地**：安装器（旧宿主重启询问 / 输入源缺失时开设置页 / 强制覆盖）、练习页 VoiceOver 标签与播报、回归并发默认 4、死代码与死资源清理、CI 去 `install-action`（504 假红）。
- 剩下的**不是新缺陷**，而是"新能力还没被真实使用验证过"：无障碍只加了语义标签，没做一次真实 VoiceOver 朗读走查；安装器三条新分支没有自动化回归。
- pro 仍是 1.2.0/39，等你自己升级（命令见 `docs/releases/1.2.1.md` §3）。
