# 待办与积压（下一版迭代的范围来源）

> 2026-11-09 重排。**1.2.0 已发布并上线**（tag `v1.2.0`，站点与 air/pro 同包 1.2.0/39）。
> 这份文件回答"还剩什么、下一版装什么、哪些明确不做"。排序口径见 [MVP后执行计划](MVP后执行计划.md)，非目标见 [AGENTS.md](../AGENTS.md) §3。
> 成本口径：**S** ≤2 人日；**M** 3–5 人日；**L** 1–2 周；**XL** >2 周。"授权"=是否需用户单独授权（换包/发布/删数据/联网下载）。

## 0. 版本语义

| 改动类型 | 版本 | 原因 |
|---|---|---|
| 改候选顺序 / 键位手感 / 简码 | 小版本（1.3.0…） | 用户要能用版本号区分手感变化 |
| 只加只读 UI（提示、练习窗） | 小版本 | 可关闭、不影响排序 |
| 纯缺陷 / 安全 / 安装体验 | 补丁（1.2.x） | 可回滚到"只修 bug"的状态 |
| 新平台 | 独立项目/里程碑 | 不跟 macOS 质量同批，否则回归无法归因 |

### P3 · 长期/研究性

- **corpus 全量**（3,000 字 ≥98% 可解释）：依赖 P1-3/P1-4。
- **D3 oracle 替代**（TBD-5）：D3 已降级为"未声明许可、仅构建期"，需要新的可许可来源。
- **客户端自动回读缺口**（Safari/Chrome/Xcode 在自动矩阵 BLOCKED）：仍需人工补，成本 M。

### 明确不做（非目标，不再列入排期）

云输入 / 云同步 / 账号 / 广告 / 皮肤商店 / AI 写作 / 打字统计与画像 / 剪贴板历史 / 跨设备同步 / 本地语音（P6 之前）。
平台扩展（Windows TSF、Linux Fcitx5、Android、iOS）**单独立项**，不与 macOS 质量批次同期。
