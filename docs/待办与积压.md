## 0. 版本语义

| 改动类型 | 版本 | 原因 |
|---|---|---|
| 改候选顺序 / 键位手感 / 简码 | 小版本（1.3.0…） | 用户要能用版本号区分手感变化 |
| 只加只读 UI（提示、练习窗） | 小版本 | 可关闭、不影响排序 |
| 纯缺陷 / 安全 / 安装体验 | 补丁（1.2.x） | 可回滚到"只修 bug"的状态 |
| 新平台 | 独立项目/里程碑 | 不跟 macOS 质量同批，否则回归无法归因 |
