# macOS 首版发布前清单

当前版本 0.1.0，双架构 **universal（arm64 + x86_64）** 候选由 CI 产出（签名 + 公证 + 离线复现）；仓库保持 private，尚未创建正式 Release。实机验收（MVP-05）由用户安排。该清单汇总状态，详情以报告 003/005/006 及 HANDOFF 为准；**用户可见的版本说明见 [发布说明](发布说明.md)**。

需求与实现差距（MVP-01…14）见 [报告006](reviews/006-macos-mvp-gap-review.md)。该报告补充候选来源、配置刷新/错误反馈等工程待办；本清单中“已完成”不等于Phase 1验收关闭。
