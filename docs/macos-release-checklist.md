## 发布流程与范围

渠道为 GitHub Release（产物）＋ GitHub Pages（指引）。现有工作流就绪不代表版本已发布；tag/publish 是独立发布动作。发布时核对实际工作流配置、候选附件和保护规则，不重复执行已完成的转公开/首次 Pages 启用流程。

已接受 UX-1 浏览器地址栏残留需继续披露；MEM-1 已关闭，不重复作为阻塞。其他系统版本、分层图标、菜单替代设计和引擎替换按迭代计划的范围及触发条件处理。
