# macOS 首版发布前清单

当前版本0.1.0，定稿候选源码 `6d7e8435`，arm64；仓库保持private，尚未创建正式Release。实机验收由用户安排后续完成。该清单汇总状态，详细证据以报告003/005及HANDOFF为准。

需求与实现差距（MVP-01…14）见 [报告006](reviews/006-macos-mvp-gap-review.md)。该报告补充候选来源、配置刷新/错误反馈等工程待办；本清单中“已完成”不等于Phase 1验收关闭。

## 已完成

- [x] 默认五笔优先与拼音兜底、三模式切换、拼音反查。
- [x] 实体输入、翻页选择、退格/Esc、失焦清理、回车原码和空格中文确认。
- [x] 官方图标定稿，用户确认图标显示正常；全部历史资产保留。

- [x] 用户域安装、卸载备份与重复安装预检，配置及词库保留。
- [x] ZIP 11,251,870字节，小于15MB；完整源码/vendor、SBOM、依赖和数据许可、SHA附件。

## 后续增强（不扩首版范围）

- Intel/通用包以及其他macOS版本实机兼容性。
- 第三方Actions固定到完整commit SHA；普通CI明确只读权限，作为CI供应链加固单独改动。
- 组织套餐允许时配置并验证main必需PR/CI保护；现有套餐限制不能推断保护已启用。
- 公开仓库前复核历史日志、附件及个人信息；当前无公开计划。
