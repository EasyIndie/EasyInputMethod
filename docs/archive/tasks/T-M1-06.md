# T-M1-06：词组码自动生成

- **状态**：待认领
- **模型建议**：flash（规则确定、纯组合，照规格实现）
- **前置**：T-M1-05（需要单字码表）
- **目标**：由"词表 + 单字码表"按五笔词组规则生成"code → 词组"码表。

## 规则（标准，勿改）

| 词长 | 取码 |
|---|---|
| 2 字词 | 每字取**前 2 码**：`AaAbBaBb` |
| 3 字词 | 1字首码 + 2字首码 + 3字首码 + 3字次码：`AaBaCaCb` |
| 4 字及以上 | 1字首码 + 2字首码 + 3字首码 + 末字首码：`AaBaCaZa` |

- 单字"全码"取该字**最长**的码（4 码或不足 4 码的实码）；首码=第 1 个字母，次码=第 2 个字母，依此类推。
- 含**非汉字**（字母/数字/符号）的词条：跳过（不生成）。

## 步骤

1. 词表来源：`mozillazg/phrase-pinyin-data` 的 `pinyin.txt`（MIT）——下载脚本 + SHA-256 登记（同 T-M1-04 的做法）。
2. 写生成器（`crates/wubi-encoder` 的 example 或 `tools/` 脚本）：读词表 + 单字码表（T-M1-05 产物），按规则生成 `data/generated/wubi86-phrases.tsv`（`code\t词组`）。
3. 去重：同一词组只保留一个码（若规则碰撞，保留权重高的词组——权重来自 T-M1-07 之前的临时权重）。
4. 统计输出：生成条数、跳过条数（含非汉字）。

## 验收

- 生成器可复现；`wubi86-phrases.tsv` 生成；
- 用已知样本断言：`中华人民共和国 → kwwl`、`输入法 → ltif`、`中文 → khyy`（这些在测试里写死验证）；
- `make verify` 全绿。

## 铁律提醒

- 词表登记许可 + SHA-256；不提交大文件，提交脚本。

## 禁止

- 不改编码规则；不做拼音输入（那是 P1-M2）。
