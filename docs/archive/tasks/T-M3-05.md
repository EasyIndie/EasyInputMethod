# T-M3-05：独立调试窗口

- **状态**：✅ 完成（2026-10-08）
- **来源**：用户要求大多数功能迭代脱离系统输入法装载流程
- **设计**：ADR-024；`platforms/macos/README.md`

## 实现

普通 AppKit 调试应用复用 `ImeSession`、`ime-ffi`、`CandidateWindow` 和真实词典；支持末尾输入、组合串、临时模式切换、选字、退格、Esc、清空。`make macos-preview` 增量构建并直接运行，无需开发者签名、公证、系统安装或重启；不修改正式输入法。

## 验证

- `dev-preview.sh --smoke-test`：实际 NSTextView 按键适配器、文本渲染、五笔/拼音候选、空格/数字/回车选字、退格/Esc、清空通过。
- 桌面窗口：`wq→你`、`nihao→你好`、数字选字、退格、Esc、回车、模式切换、清空通过。
- `make verify` 全量检查；结果见 HANDOFF。

## 边界

调试区只支持末尾输入；IMK 分发、跨应用光标与系统注册仍需正式宿主实机验收。配置只经 ime-config 读取，临时模式不持久化；未新增依赖或网络能力。
