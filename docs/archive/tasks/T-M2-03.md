# T-M2-03：拼音反查完善 + `ime-config` 接入 `ime-cli`（pro）

- **状态**：完成
- **模型建议**：pro（跨 crate 集成 + 反查语义）
- **前置**：T-M2-01（ime-config）、T-M2-02（ime-pinyin）
- **目标**：收口 P1-M2 验收——**改 `config.toml` 即时生效**，并让拼音反查返回**首选读音**。

## 步骤

1. **拼音反查完善**（`ime-pinyin`）：
   - `reverse_lookup` 由"字典序最小读音"改为**首选读音**（按词频/常用度排序；数据可在生成期排序或运行时选最高频）；
   - 单测：`你→nǐ`、`的→de`、`行`（多音字，返回一个合理首选）。
2. **`ime-cli` 接入 `ime-config`**：
   - 启动时 `ConfigStore::load(config.toml)`；**默认路径可由 `--config <路径>`/环境变量指定**（不写死平台路径，平台路径属 P1-M3）；
   - 读取 `mode`（决定初始输入模式）、`candidate.count`（每页候选数）等；
   - `subscribe()` 订阅变更：**文件被外部编辑后，CLI 行为即时改变，无需重启**。
3. 保持"唯一写者"铁律：CLI 只读快照 + 订阅；**写配置仅经 `ime-config::set()`**（可在 CLI 加一个 `:set <key> <value>` 调试命令验证写入路径）。

## 验收

- `你` 反查返回首选读音（无需精确声调，拼音串正确即可）；
- 运行中外部修改 `config.toml`（改 `candidate.count` / `mode`）→ **CLI 即时生效**（打印订阅事件或行为变化）；
- `:set <key> <value>` → 校验 → 原子写文件 → 快照更新 → 广播；
- 单测覆盖反查 + 配置接入；`make verify` 全绿。

## 禁止

- 不写 `UserDefaults`/注册表/第二个配置文件（铁律 R1）；
- 不改 `ime-core` 合并逻辑；
- 不引入 tokio。
