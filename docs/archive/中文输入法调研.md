# 中文输入法调研（Windows / macOS / Linux）

> 目标：盘点三大桌面平台上可用的中文输入法，比较优缺点，并逐个分析功能与隐私/安全性，回答"是否会偷隐私"。
>
> 说明：本报告撰写环境无法稳定联网检索（搜索引擎反爬），涉及具体年份/版本号/处罚批次的地方标了 **(需复核)**，落地前建议对照官方通报原文。产品功能与隐私政策会随版本变化，请以最新版本为准。

---

## 0. 先给结论（TL;DR）

**"偷隐私"要分三档，不能一概而论：**

| 档位 | 含义 | 典型产品 |
|---|---|---|
| A. 没有证据表明偷 | 开源、可审计、默认离线 | RIME（小狼毫/鼠须管/ibus-rime）、Fcitx5/IBus + libpinyin、fcitx5-chinese-addons |
| B. 不"偷"，但会大量收集 | 闭源，有云输入/云同步/遥测，隐私政策里写了会收集，默认常开启 | 微软拼音、百度输入法、搜狗输入法、讯飞输入法、QQ输入法、微信输入法 |
| C. 有明确违规/漏洞记录 | 被监管通报过超范围收集、被披露过高危漏洞、有捆绑/弹窗历史 | 搜狗、百度、讯飞、QQ输入法（均被 2021 年通报整改过） |

**核心技术风险（所有输入法共有）：**
输入法为了工作，必须挂进前台进程、读取全部按键、常驻内存、常驻网络。这意味着：
- 它是**天然的键盘记录器**——正常工作时它就得"记录"你打的每一个字；
- 它一旦有漏洞/后门/供应链污染，密码、聊天、身份证号全暴露；
- 它默认就能访问**剪贴板、网络**，语音输入还要**麦克风**；
- 关键区分点只有三个：**开不开源（能不能审计）、联不联网（数据去哪）、有没有历史劣迹**。

**一句话建议：**
- 追求隐私 + 愿意折腾 → **RIME** 或 **Fcitx5/IBus + libpinyin**（开源、默认离线）。
- 要开箱好用又要相对可控 → **微软拼音**，装完第一件事是去「设置 → 隐私 → 输入法个性化 / 在线语音识别」把云建议、文本建议、遥测关掉。
- 商业云输入法（搜狗/百度/讯飞/QQ）→ 能用，但建议关闭云输入/云同步/用户体验计划，并用防火墙阻断其外联，别在能输入敏感信息的机器上默认信任。

## 1. 平台输入法架构（理解差异的前提）

| 平台 | 官方框架 | 第三方怎么接入 | 安全含义 |
|---|---|---|---|
| Windows | TSF（Text Services Framework），旧 IMM32 | 注册为 TSF 文本服务，注入到各进程 | 权限极高，能读全键盘 |
| macOS | InputMethodKit (IMK) | 打包成 .app，装到 ~/Library/Input Methods | 需要"输入监控"权限，能读全键盘 |
| Linux | Fcitx5 / IBus（D-Bus 总线式），X11 也可 XIM | 引擎作为框架插件/独立进程 | 架构相对隔离，但仍能读键盘 |

> Linux 的优势是**框架与引擎解耦**：你换引擎不用换框架，且绝大多数引擎开源。Windows/macOS 的商业输入法基本都是"整包闭源"。

## 4. 逐个安全性与隐私分析

评分：隐私风险 **★=低 ~ ★★★★★=高**（在**默认配置**下，且假设软件诚信）。

### 4.1 微软拼音（Windows 内置）

- **功能**：系统级集成最好，兼容性/稳定性最强，无广告。
- **联网点**：
  - 「云建议 / 文本建议」会把你的输入上下文发到微软以生成候选；
  - Windows 诊断数据（遥测）可能包含输入相关统计；
  - 微软账户可选同步自学习词库。
- **隐私要点**：微软隐私声明明确会收集，属"告知后收集"，不是偷；但**默认开启**，多数用户不知道。
- **建议**：设置 → 隐私和安全性 → 输入法个性化 / 在线语音识别，全部关闭；组策略可关遥测。
- **风险**：★★☆☆☆（关掉云功能后 ★☆☆☆☆）
- **缺点**：功能相对朴素、云联想不如国产，词库更新慢。

### 4.2 搜狗拼音/五笔

- **功能**：词库和云联想长期最强，皮肤/表情/自定义最丰富，全平台。
- **联网点**：云输入（上传拼音串）、账户词库同步、更新、推广/运营组件、统计。
- **已知问题**：
  - 2013 年前后乌云平台曾披露其存在可导致输入内容/隐私泄露的高危漏洞，后续修复 **(需复核具体版本)**；
  - 历史上被指**捆绑安装、弹窗推广**；
  - 2021 年因**违法违规收集使用个人信息被国家网信办/工信部通报并要求整改**，随后在部分应用商店下架 **(需复核批次日期)**；
  - 2021 年搜狗被腾讯收购，数据归属/共享策略变得更复杂。
- **优点**：真的好用，候选准、长句强。
- **隐私风险**：★★★★☆（默认配置 + 闭源 + 云 + 广告史 + 通报史）
- **结论**：不属于"秘密偷"，但属于**超范围收集/默认外发风险最高**的一档。要用就关云、关同步、关"用户体验改进"，并防火墙限制其外联。

### 4.3 百度输入法

- **功能**：拼音/语音/手写/AI 齐全，PC+Mac+Linux 都有。
- **联网点**：云输入、语音上云、词库同步、AI 功能、广告组件。
- **已知问题**：同样在 2021 年输入法整治中被点名通报 **(需复核)**；国内 App 生态里有广告/推广记录；隐私政策赋予的收集范围很宽。
- **隐私风险**：★★★★☆
- **结论**：与搜狗同档。默认大量联网，数据主要用于改进产品/广告生态。

### 4.4 讯飞输入法

- **功能**：**语音识别是行业标杆**，方言/中英混说强，PC/Mac/Linux/移动全平台。
- **联网点**：语音输入**必然把录音上传讯飞云**（这是产品原理，不是偷偷摸摸）；云输入、同步。
- **已知问题**：2021 年输入法整治中被通报 **(需复核)**；语音是敏感生物特征数据。
- **隐私风险**：★★★★☆
- **结论**：语音场景下，你等于把麦克风交给云端。合规文件齐全，但是否信任其留存策略要看你自己。**涉密/敏感场景不要用云语音。**

### 4.5 QQ输入法

- **功能**：拼音 + 五笔，界面干净，PC 端多年不更新。
- **联网点**：云输入、同步。
- **现状**：2014 年被搜狗收购，PC 版事实停更，主要靠手机端。
- **隐私风险**：★★★★☆（叠加了搜狗的体系）
- **结论**：不推荐作为主力，也不推荐作为"更安全的选择"。

### 4.6 微信输入法 / 微信键盘

- **功能**：简约、无广告、拼音/双拼，逐步覆盖 Win/Mac/iOS/Android。
- **宣称**：强调**隐私保护**——不保存、不收集、不上传输入内容，本地处理为主。
- **现实**：
  - **闭源**，所有"安全"声明无法被独立验证；
  - 仍需要联网做词库/模型更新；
  - "微信生态"本身意味着它与你的社交身份强绑定，数据用途的解释权在腾讯。
- **优点**：确实无广告、轻量、比搜狗/百度克制。
- **隐私风险**：★★★☆☆（宣称好、闭源不可验证）
- **结论**：比搜狗/百度更值得信任，但它**不是隐私工具**。真正的隐私工具必须开源可审计。

### 4.7 手心输入法 / 华宇拼音

- **手心**：主打无广告、轻快，PC 时代口碑不错，现基本停更，维护与安全更新存疑 → **停更的产品有未修复漏洞风险**。
- **华宇（原紫光）**：无云无广告，简洁，但闭源、更新慢、界面老。
- **隐私风险**：★★☆☆☆（联网少）但**维护风险**高。
- **结论**：不作为主力，尤其别在联网生产机上用停更软件。

### 4.8 微信输入法之外的"小厂五笔"（万能/极品/陈桥等）

- **常见问题**：官网下载站劫持、捆绑安装、弹窗广告、静默推广。
- **隐私风险**：★★★★☆（供应链 + 广告 SDK）
- **结论**：这类是**实际被投毒概率最高**的一档，能不用就不用。

### 4.9 RIME（小狼毫 / 鼠须管 / ibus-rime / fcitx5-rime）

- **功能**：引擎与词库全本地，拼音/双拼/五笔/仓颉/自定义码表通吃；跨平台同一套配置。
- **安全优点**：
  - **开源（GPLv3）可审计**；
  - **默认零联网**，没有云输入、没有账户、没有遥测；
  - 词库是本地文件，可自己备份/同步（Syncthing/网盘）。
- **缺点**：配置是 YAML + 词库编译，**上手门槛高**；默认拼音体验不如搜狗；无语音/手写。
- **隐私风险**：★☆☆☆☆（这是桌面端隐私最优解之一）
- **结论**：**能接受折腾就选它。** 想在 Windows 舒适使用可配「小狼毫 + 雾凇拼音」。

### 4.10 Fcitx5 / IBus + 开源中文引擎（Linux 主路径）

- **组成**：fcitx5-chinese-addons、ibus-libpinyin、ibus-sunpinyin、ibus-table 等。
- **安全优点**：GPL/LGPL 开源、离线、无遥测、由发行版打包可复现构建。
- **缺点**：拼音联想/纠错弱于商业输入法；不同发行版打包体验不一。
- **隐私风险**：★☆☆☆☆
- **结论**：**Linux 上默认推荐**。

### 4.11 搜狗/百度/讯飞 Linux 版

- **性质**：闭源整包，多基于 Fcitx 包装，功能介于商业版与开源版之间。
- **隐私风险**：★★★☆☆～★★★★☆（闭源 + 云功能）
- **结论**：只在"实在想要更好的拼音体验又不换框架"时用，同样建议关云并断网。

## 6. 怎么判断"有没有偷隐私"——可操作的检查清单

1. **看是否开源**：闭源产品无法证明清白，只能基于信任。开源产品（RIME、Fcitx5、IBus）可以审计。
2. **抓网络流量**：用 Little Snitch（macOS）、GlassWire / Windows 防火墙（Windows）、Wireshark / tcpdump（Linux）看它**在没有输入法云功能时是否仍持续外联**。持续心跳/上报就是可疑信号。
3. **看隐私政策与开关**：找「云输入」「云同步」「用户体验改进计划」「个性化推荐」四项，全部关闭。
4. **剪贴板与权限**：确认它是否读取剪贴板、是否需要麦克风/屏幕录制。非语音场景不需要麦克风。
5. **查历史**：搜索"产品名 + 通报 / 漏洞 / 隐私 / 下架"。
6. **看更新**：停更的输入法 = 未修复漏洞。宁可换新。

## 7. 给 EasyInputMethod 的启示（产品角度）

如果目标是做一个"更值得信任的中文输入法"，差异化点已经很清楚：

1. **架构上默认离线**：云输入做成显式开关、默认关，且开关处写清"会把拼音串发送到 X 服务器"。
2. **开源或至少可审计**：引擎/词库格式开源，二进制可复现构建，是区别于搜狗/百度的最强信任背书。
3. **不做键盘记录式上传**：只上传聚合统计（若必须），永不上传原始按键/上下文/剪贴板；最好端侧学习。
4. **不捆绑、不弹窗、不改主页**。
5. **跨平台同引擎**：学 RIME 的"一份配置三平台通吃"，但把上手门槛降下来（图形化配置、内置优质方案）。
6. **明确的数据契约**：一份人话隐私说明 + 一份可验证的网络行为（可选 telemetry 端到端可见）。
7. **安全工程**：输入法天然是高危组件，要防 DLL 注入、防供应链、签名发布、最小权限、及时更新。
