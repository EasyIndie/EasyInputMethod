## 审核建议路径

1. 读 `技术方案.md` §1–§5（定位、产品、竞品、选型、架构）——判断方向；
2. 读 §6–§8（引擎、词库自建、拼音）——判断技术可行性；
3. 读 `配置架构.md` + `隐私与安全.md`——判断系统性与合规；
4. 读 `决策记录.md`——确认所有冻结项无异议；
5. 有异议 → 在对应文档提，或新增 ADR。
