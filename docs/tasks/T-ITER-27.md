# IT-27：拼音基础隔音符与默认候选质量

- 状态：待设计/待实施；调研及隔离样例已确认。
- 优先级：P1核心完整性。
- 证据：词表有西安，xa可首选；xi'an在默认中文标点路径中途提交。xian冷启动见/省/先使用全字权重，常用读音质量需要固定集。
- 第一个独立改动：先ADR定义拼音模式及混输中ASCII隔音符的语法/标点消歧，支持xi'an明确音节，不影响英文/五笔引用标点。逐次输入不得提前提交、重复上屏或记录错误学习。
- 后续独立改动：用既有合规词表复核常用多音读音权重，保留合法罕见读音；未量化不要手改词频列表。
- 最小边界：保持现有后端；不要求整句、神经模型、全简混拼或自动造词，不新增配置。
- 验收：xian与xi'an可区分，分隔/退格/取消/原码/简拼、v代ü、词表已有常用词及引号标点路径正确；质量集记录候选位置而非只测“有结果”。来源许可/可复现/包体与延迟门禁保持。
