# T-P2-01：简繁转换（含 Ctrl+Shift+F 默认键）

- **状态**：✅ 完成（2026-10-10；ADR-069，OpenCC 数据 + `Ctrl+Shift+F`，仅简→繁）
- **模型建议**：**pro**（涉及数据许可 + 引擎 + 配置 + 快捷键 + UI，需判断）
- **前置**：ADR-014/016（数据来源）、ADR-068（快捷键对齐）、Skill `add-config-option` / `add-data-source`；**先写 ADR**（新增功能 + 新数据）
- **目标**：提供 简↔繁 转换；默认快捷键 **`Ctrl+Shift+F`**（对齐搜狗/微软），可配置、可持久化。
  - 2026-10-18 ADR-208：默认改为 **`Ctrl+Shift+T`**，因为 `Ctrl+Shift+F` 与常见编辑器的全局查找冲突；可配置不变。

## 背景

主流中文输入法都提供 `Ctrl+Shift+F` 简繁切换。我们目前**无简繁转换**（`docs/reviews/007`/`008` 已记为 P2）。用户已确认要对齐并预留该默认键。

## 步骤（草案，实施前细化）

1. **数据决策 + 登记（铁律 4）**：选 GPL-3 兼容的简繁映射源（如 OpenCC 词典需核许可；或自建映射表），登记 `docs/数据来源与许可.md` + `data/sources.toml`（来源/许可/SHA-256）；写 ADR 说明取源与转换口径（一字多繁、词组优先等）。
2. **引擎侧转换**：在上屏前对候选/提交文本做简↔繁映射（可参考 `ime-core` 候选管线；避免在 `ime-core` 里硬编码数据）。
3. **配置**：新增 `input.chinese_variant = "simplified" | "traditional"`（Schema 默认 `simplified`）；如需要，加转换方向/范围选项。默认值只写在 Schema。
4. **快捷键**：新增 `hotkey.toggle_variant`（默认 `"ctrl+shift+f"`），切换并**写回配置**（同 `toggle_punctuation` 模式，ADR-068）。
5. **状态显示**：菜单状态行显示「简/繁」（沿用 ADR-067/068 的状态描述）。
6. **文档**：`docs/配置架构.md` §6、`docs/发布说明.md` §4、`docs/技术方案.md`（若有引擎变更）。

## 验收

- `Ctrl+Shift+F` 切换简/繁并**持久化**（与主流一致）；
- 转换正确（一字多繁/词组优先规则有测试）；往返稳定；
- 数据许可登记齐全、`cargo deny` 通过；
- `make verify` 全绿；预览冒烟有对应断言。

## 铁律提醒

- 数据先登记（`数据来源与许可.md` + `data/sources.toml`）；
- 配置只走 `ime-config`（禁止第二配置）；
- 核心 `forbid(unsafe_code)`、不联网；
- 新增功能先写 ADR。
