# T-M3-04：CI 加 macOS runner（覆盖 Swift 前端）（flash）

- **状态**：✅ 完成（本地与远端 Linux/macOS 全部通过）
- **模型建议**：flash（CI 配置）
- **前置**：T-M3-02（Swift 宿主代码存在）
- **目标**：让 CI 在 macOS runner 上编译 Rust workspace + Swift 宿主，防止前端悄悄编不过（对应 `docs/reviews/001.md` P2-5）。

## 交付物

1. `.github/workflows/ci.yml` 增加 `macos-latest` job：
   - Rust：`make verify`（fmt/clippy/test/deny/隐私断言）；
   - Swift：跑 `platforms/macos/build.sh`（或等价的编译步骤），**构建 + 独立预览冒烟，不装载系统输入法**。
2. 缓存 Rust 构建（`Swatinem/rust-cache` 或 actions/cache）；控制超时。
3. 若 runner 无 Xcode，确认 CI 镜像自带 Xcode（GitHub macOS runner 自带 Xcode）→ 可正常跑 swiftc。

## 验收

- workflow 语法合法；本地 `act` 不可用时可只做静态检查；
- 文档说明该 job 覆盖什么、不覆盖什么（**不含真机装载/交互验证**）；
- 不改变现有 Linux job 的通过性。

## 禁止

- 不在 CI 里做签名/公证；
- 不让 macOS job 成为其它 job 的硬依赖（除非明确需要）。
