# IT-28：核心编辑与安全输入边界补验

- 状态：待取证，不代表已发现故障或泄漏。
- 优先级：首版可靠性/隐私验收；实际损害发现后P0。
- 范围：非组合/组合/取消后，Tab、前向Delete、Home/End、CapsLock、Command快捷键和非US布局；数字/英文/小数/路径/标点混排；密码型自有字段与Terminal安全键盘输入按系统允许方式验收。
- 目标：不丢字、不出控制字符、不抢客户端焦点、不绕过宿主/系统安全限制；禁止在不应参与的受保护输入中学习。是否仍收到IME事件与是否可学习分别取证，不根据系统选项名推断。
- 安全：仅自有窗口与虚拟文本、独有数据根；不输入真实密码、不读取用户文档/词库、不关闭系统保护以获得测试结果。
- 方式：并入IT-14/22/23矩阵，先通过离线NSEvent/FFI边界再空闲时做原生；权限/系统限制BLOCKED如实保留。
- 验收：场景及源/焦点/数据前后结果可核对；原IT-24修复、撤销/退格/IME切源不回退。不为覆盖检查增加密码管理器、全局键盘监听或额外守护进程。
- 参考：[报告011](../reviews/011-core-completeness-and-scope.md)、既有隔离验收规范。
