## 环境约束（本机已确认，务必遵守）

- 本机 **仅 CLT、无 Xcode** → **禁止使用 Interface Builder / Asset Catalog**（`actool`/`ibtool` 是 stub）。**所有 UI 用纯代码 AppKit 绘制**。
- 构建方式：`swiftc`（CLT）+ `cargo build --release -p ime-ffi`（`staticlib`）+ 脚本拼装 bundle。
- Phase 1 **不做签名/公证**；如需装载用 **ad-hoc 签名**（`codesign -s -`）。

## 交付物（建议放 `platforms/macos/`）

1. **Swift 源码**（`Sources/`）：
   - `main.swift`：`NSApplication` 启动 + `IMKBundle` 注册；
   - `InputController.swift`：`IMKInputController` 子类，处理 `handle(_:client:)`，把按键转给 `ime_session_key`，用 `ime_session_candidates` 更新候选、`ime_session_commit` 上屏；
   - 候选窗（`NSPanel`，**代码绘制**，不用 IB）。
2. **`build.sh`**：编译 Rust staticlib + `swiftc` 编译 + 拼装 **`Yinghuo.app`**（`Info.plist` + `PkgInfo` + `MacOS/` 可执行 + `Resources/`）。（卡原写 `.inputmethod`，实测 macOS 13 不支持，见下）
3. **`Info.plist`**：按 IMK 要求（`cfBundlePackageType`、`tsInputModeListKey`、`InputMethodServerControllerClass`、`InputMethodConnectionName` 等；**自行查证正确键名**）。
4. **扩展 `ime-ffi` 以加载真实数据**：当前 FFI 会话用内置样本引擎 → 增加可指定数据路径的入口（如 `ime_session_new_with_data(config, wubi_core, pinyin_chars, pinyin_words)` 或等效设计；保持 ABI 简洁、`catch_unwind`）。
5. **`README`**：如何 `build.sh` → 装载 → 注销/重登 → 在 TextEdit 测试。
