# T-M2-02：内置轻量拼音引擎 `crates/ime-pinyin`（pro）

- **状态**：完成
- **模型建议**：**pro**（拼音切分 + 简拼 + 数据生成 + 接入引擎，逻辑密集）
- **前置**：T-M2-01（配置，可选）、P1-M1（码表/词频）
- **目标**：按 ADR-008 实现 `PinyinBackend` trait + **内置轻量兜底**，实现 `ime_core::Engine`，让 `ime-cli` 的拼音模式与混输可用。

## 背景

- `ime-core` 的**混输合并已实现**（`Session::recompute()` 合并所有活跃引擎、按 `weight` 去重降序）——**本卡只需提供拼音引擎**，不要改合并逻辑。
- 词表来源（均 MIT）：D5 `mozillazg/pinyin-data`（字→拼音）、D4 `mozillazg/phrase-pinyin-data`（词→拼音）、D10 `fxsjy/jieba`（词频）。

## 交付物

1. `crates/ime-pinyin`（`#![forbid(unsafe_code)]`、零网络）：
   - `pub trait PinyinBackend: Send + Sync`：核心查询接口（自行设计签名，需说明理由）；
   - `TablePinyinBackend`：基于内存表的**轻量兜底**实现；
   - **音节切分**：把连续 ASCII 拼音（如 `nihao`）切成合法音节序列（最大匹配 vs 音节集合）；
   - **简拼**：`nh` → 匹配「你 好」类词（首字母）；
   - `PinyinEngine`：实现 `ime_core::Engine`（`convert` 返回 `Candidate{ source: Pinyin, .. }`）。
2. 数据生成（`examples/` 或 `tools/`）：
   - `data/generated/pinyin-chars.tsv`：`音节\t字\tweight`（D5 + D10 词频）；
   - `data/generated/pinyin-words.tsv`：`拼音(空格分隔)\t词\tweight`（D4 + D10）；
   - fetch 脚本 + SHA-256 + 登记 `data/sources.toml`（D5 由候选转正式）。
3. `ime-cli`：加载拼音表 + `:mode pinyin` / `mixed` 可用。

## 验收

- `:mode pinyin` + `nihao` → 出现「你好」（或等价高分候选）；`wo` → 「我」；
- 简拼：`nh` → 「你好」；
- `:mode mixed`：五笔码有结果时优先；**无五笔结果时自动出拼音候选**（ROADMAP P1-M2 验收）；
- 解析器/切分器有单测（含边界：空串、非法串、超长）；`make verify` 全绿。

## 关键约束

- `Candidate.source` 必须正确标记 `Pinyin`（引擎类型）；权重用真实词频（D10）；
- 不引入 `pinyin` 之外的重量级依赖前先说明；新依赖过 `cargo deny`；
- 不联网；数据登记（AGENTS.md 铁律 4）。

## 禁止

- 不改 `ime-core` 的合并/去重逻辑（已实现）；
- 不引入 `inputx-pinyin`（那是 T-M2-03 spike 的内容）；
- 不硬编码大表进代码。
