# T-M3-01：`ime-ffi` C ABI（pro）

- **状态**：完成（会话 ABI + 配置 ABI + C 头文件 + C/Swift 冒烟；详见 `crates/ime-ffi/`）
- **模型建议**：**pro**（唯一 `unsafe` 集中地；FFI 边界必须零 panic、零 UB）
- **前置**：P1-M1/P1-M2（引擎 + 拼音 + 配置均已就绪）
- **目标**：实现 `crates/ime-ffi`，暴露窄 C ABI（会话 + 配置），供 Swift 宿主调用。

## 必读

- `docs/技术方案.md` **§5.3**（会话 ABI）、`docs/配置架构.md` **§9**（配置 ABI，含契约）。

## 交付物

1. **`crates/ime-ffi`**（`crate-type = ["cdylib", "staticlib"]`）：
   - `#![deny(unsafe_op_in_unsafe_fn)]`；**唯一** `unsafe` 集中地（其它 crate 仍 `forbid`）；
   - **会话 ABI**（§5.3）：`ime_session_new/free/key/candidates/select/page/commit/focus_out/reset` + `ime_string_free`；不透明句柄 `ImeSession`；
   - **配置 ABI**（§9）：`ime_config_snapshot/get/schema/set/reload/subscribe/unsubscribe`。
2. **C 头文件**：`crates/ime-ffi/include/ime.h`（手写或 `cbindgen` 生成）+ `module.modulemap`（供 Swift `import ime`）。
3. **C 冒烟测试**：用 `clang` 链接 `staticlib` 编译一个小 C 程序，验证 ABI 可链接可用（脚本或 `tests/`）。

## 硬契约（违反即错误）

- **绝不 panic 穿越 FFI**：所有入口 `catch_unwind` 兜底，返回错误码。
- 纯 C；**不透明句柄**；UTF-8 字符串；错误用返回码（`int32_t`）。
- 线程绑定/线程安全按文档；`snapshot` 返回**借用**，调用方不得释放。
- `forbid(unsafe_code)` 仅本 crate 例外；**不联网**（`verify-no-network` 仍须通过）。

## 验收

- Rust 侧单测：创建会话 → 喂键 → 取候选 → 选择 → commit 得到文本；
- **坏输入不崩**：空指针/非法 UTF-8/超长输入 → 返回错误码而非 panic；
- C 冒烟程序编译并运行成功（打印候选/commit）；
- 头文件可被 C 与 Swift 使用（至少 `swiftc -typecheck` 一个 `import ime` 的文件）；
- `make verify` 全绿；`verify-no-network` 通过。

## 禁止

- 不在其它 crate 引入 `unsafe`；
- 不让 FFI 层承载业务逻辑（只做转换与边界防护）；
- 不改动 `ime-core` 的 `Engine`/合并语义。
