# T-M1-05b：自建独立的结构/末笔数据集（IDS + 基础部件末笔表）（pro）

- **状态**：待认领
- **模型建议**：**pro**（许可核实 + IDS 解析 + 递归推导 + 与 D3 对照裁定）
- **前置**：T-M1-03、T-M1-04、T-M1-05a（结论：无现成合格来源 → 自建）
- **目标**：产出一份**不依赖 D3** 的「字型结构 + 末笔笔画」数据，供识别码（T-M1-05）使用。

## 思路（把 2.7 万字问题缩小到几百个基础部件）

1. **结构** ← **IDS**（表意文字描述序列）：
   - 取**许可明确且 GPL-3 兼容**的 IDS 来源（首推 **Wiktionary dump，CC BY-SA 4.0**，务必核实兼容性；其它候选见 ADR-018）。
   - IDS 运算符 → 五笔 3 类：`⿰/⿲`→左右；`⿱/⿳`→上下；其余（`⿴⿵⿶⿷⿸⿹⿺⿻`）→杂合。
2. **末笔** ← 沿 IDS 树递归到**最后一个被书写的部件**，取其末笔：
   - 自建一张 **`基础部件 → 末笔笔画`** 表（约 300–500 条，**本项目自有数据**，可人工核对/公开可验证），**提交入库**（CC-BY-SA-4.0 或 CC0）。
   - 末笔只用这张自有表 + IDS，**不用任何第三方笔画数据**。
   - ⚠️ 注意 IDS 的**书写顺序语义**（尤其包围结构 `⿺/⿻` 等）——需用对照**验证并处理例外**（如 `辶/廴` 最后写）。
3. **对照**：与 D3 派生版本比较**仅作检查**；分歧**逐条人工裁定**并记录理由（本数据不依赖 D3）。

## 交付物

1. `data/sources/fetch-ids.sh`：下载所选 IDS 来源 + SHA-256 校验（大文件不入库）。
2. `data/wubi86/base-components.tsv`（或类似）：**自建**基础部件→末笔表（提交）。
3. 生成器（`tools/` 或 `crates/wubi-encoder/examples/`）→ `data/generated/wubi86-structure-laststroke.tsv`，**schema 与 ADR-017 版本一致**（`字\t结构\t末笔\t五笔码`），使 T-M1-05 可直接替换。
4. 对照报告 `data/generated/structure-vs-d3.txt`（一致率 + 分歧清单 + 裁定）。
5. `docs/数据来源与许可.md` + `data/sources.toml`：登记 IDS 来源（许可/SHA-256）+ 自建部件表（自有许可）。
6. 需要时追加 ADR（如 ADR-019）。

## 验收

- **结构/末笔均不来自 D3**：生成器只读 IDS + 自建部件表；
- 与 D3 一致率：GB2312 一级 **≥ 98%**（未达标须逐条说明，不能靠改规则对齐 D3）；
- 生成器可离线复现；自建部件表已提交；
- `make verify` 全绿。

## 禁止

- 不用 Arphic 系（makemeahanzi/hanzi-writer/cnchar）或任何 GPL-3 不兼容 / 许可不明的数据；
- 不用 D3 作为结构/末笔来源；
- 不为了"对齐 D3"而篡改规则（分歧要**裁定**，不是**拟合**）；
- 不提交大文件。

## 若 IDS 来源仍不达标

**停下并写结论**（更新 ADR-018/新增 ADR），列出：具体障碍、可选替代、以及"若长期无解"的降级方案（例如接受 ADR-017 的 PROVISIONAL 数据作为 Phase 1 技术债）。**不要伪造、不要退回 D3 冒充独立。**

## 参考

- ADR-016、ADR-017、ADR-018；`docs/tasks/T-M1-05a.md`、`T-M1-05.md`；`docs/数据来源与许可.md` §1.2–1.3

## 结论：首次尝试失败（2026-10-08，人工复核补充）

**执行结果**：worker 采用了「下载完整 Wiktionary dump」的重量级路线，下载 **1.8 GB** `enwiktionary-*.bz2` 后超时被杀。**该路线不可行**（dump 体积/解析成本远超单卡预算）。

**人工核实的许可结论（补充 ADR-018）**：

| 候选 | 许可实况 | 判定 |
|---|---|---|
| `cjkvi/cjkvi-ids` | GitHub 无 license；README：「`ids.txt` 派生于 CHISE，许可从其条款」；「其余数据 **GPLv2**」 | ❌ `ids.txt` 不明；其余 **GPLv2-only 与 GPL-3 不兼容** |
| `chise/ids` | 仓库无 LICENSE | ❌ |
| `kfcd/chaizi` | `NOASSERTION / Other` | ❌ |
| Wiktionary dump | CC BY-SA 4.0（可用） | ⚠️ 但 dump **>1 GB**，离线/单卡不现实 |

**结论**：今日**不存在**同时满足「GPL-3 兼容 + 许可明确 + 体积可用的独立 IDS/结构来源**。此路（真正独立的结构/末笔数据）在当前约束下**不可达成**。

**建议的替代路线**（需 ADR 决策）：见会话结论 —— 保留自建编码器，用**多个独立 oracle（码表）**交叉校验 ADR-017 的派生数据，以"多源验证"替代"数据独立"。
