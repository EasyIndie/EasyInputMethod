# T-M1-01：字根表建模与编码器 crate 骨架

- **状态**：待认领
- **模型建议**：flash（纯机械：建 crate、定义类型、解析 TSV、写测试）
- **前置**：无
- **目标**：建立 `crates/wubi-encoder` crate，能加载五笔86字根表并做"字根→键"查询。

## 步骤

1. 创建 `crates/wubi-encoder/Cargo.toml`（`name = "wubi-encoder"`，**零外部依赖**）与 `src/lib.rs`，文件顶部写 `#![forbid(unsafe_code)]`。
2. 按下方"规格"定义类型，**不引入任何 IO / 网络 / 平台代码**。
3. 实现 `RadicalTable::from_tsv(&str) -> Result<RadicalTable, EncodeError>`：
   - 每行格式 `key\trad1,rad2,...`；`key` 是**单个** `a`–`y` 字母；
   - `#` 开头的行跳过；空行跳过；非法行返回 `EncodeError::ParseError`。
4. 实现 `radical_to_key(&self, radical: &str) -> Option<char>`。
5. 在 `#[cfg(test)]` 里放一份**最小字根表夹具**（至少 5 个键：`G/F/T/Y/N`，各 3–5 个字根；字根必须取自公开的五笔86字根表，例如 G=王/一/五/戋，F=土/士/二/干/十/寸/雨，T=禾/竹/丿/彳，Y=言/讠/方/丶/广，N=已/己/巳/尸/乙/羽）。
6. 写单测：能查到；查不到返回 `None`；未知键报错；注释/空行被跳过。

## 规格（公开 API 必须一致）

```rust
pub enum Stroke { Heng, Shu, Pie, Na, Zhe }              // 横竖撇捺折
pub enum Structure { LeftRight, UpDown, Mixed }           // 左右/上下/杂合
pub enum EncodeError {
    UnknownRadical(String),
    UnknownKey(char),
    EmptyInput,
    ParseError(String),
}
pub struct RadicalTable { /* 内部字段自定 */ }
impl RadicalTable {
    pub fn from_tsv(input: &str) -> Result<Self, EncodeError>;
    pub fn radical_to_key(&self, radical: &str) -> Option<char>;
}
```
