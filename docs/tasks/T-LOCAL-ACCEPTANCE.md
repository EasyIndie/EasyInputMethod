# 本地逐场景自动验收记录（ADR-192）

- 用户要求：先本地自动化测试，先前手工覆盖缺少确定记录；合入/公证/安装暂停。
- 范围：复用六个既有原生探针，为菜单视图、真实FFI菜单同步、设置、候选/缺字、关于/反馈表单和学习区补逐场景观测；不改产品行为，不把离屏结果当正式MVP。
- 入口：`make macos-local-acceptance`或run-local-acceptance.py --output新目录；保存HTML/Markdown/JSON、源树/测试源码快照和哈希、编译探针/依赖锁哈希、截图与日志。--check可以独立复核证据。
- 防假通过：必需ID完整、源树稳定、原始观测和汇总一致、证据完整且哈希匹配、探针退出正常。拒绝缺项/重复/未知ID、源码/产物被改、失败进程伪装成功、遗漏源码快照、提升整体MVP结果；超时仅清理自己的进程组。
- 边界：直接AX动作、合成NSEvent、外链打开模拟只证明对应组件；实际系统菜单/物理键盘/VoiceOver等仍单列BLOCKED。历史口头确认只保留为用户反馈，不补写步骤或观察值。
- 验证：test-local-acceptance.py的合成fixture验证拒绝路径，六组真实探针验证业务；实际结果见报告041和运行目录。正常退出保留证据，失败记录不覆盖。
