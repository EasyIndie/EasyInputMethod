# T-M2-01：`ime-config` 配置子系统（pro）

- **状态**：待认领
- **模型建议**：**pro**（并发快照 + 原子持久化 + 健壮性，是后续所有组件的地基）
- **前置**：无（可独立于 P1-M1）
- **目标**：实现 `crates/ime-config`，严格遵循 `docs/配置架构.md`（四条铁律 R1–R4）。

## 必读

- **权威设计**：`docs/配置架构.md`（全文，尤其 §1 铁律、§4 实时生效、§6 v1 七项、§7 健壮性、§8 Schema、§10 落点、§11 验收）。

## 交付物（按文档 §10 结构）

```
crates/ime-config/
├── src/schema.rs   # OptionSpec 全表（唯一真值定义；v1 七项）
├── src/config.rs   # Config 结构体 + 「Schema 默认值 + 文件值」合并
├── src/persist.rs  # 原子写(temp+fsync+rename) / 文件锁 / 迁移 / 首次生成带注释文件
├── src/watch.rs    # 文件监听(mtime 轮询或 notify) + debounce → reload
└── src/lib.rs      # ArcSwap 快照 + get/set/subscribe
```

**v1 七项**（§6）：`mode`、`wubi.auto_commit`、`wubi.z_key`、`pinyin.fuzzy`、`candidate.count`、`appearance.theme`、`hotkey.toggle_mode`。

## 关键约束

- **R1**：`config.toml` 是唯一持久真值（**禁止** UserDefaults/注册表/环境变量/第二个文件）。
- **R2**：运行时只有一份 `ArcSwap<Config>`；读零拷贝无锁。
- **R3**：**只有 `set()` 能改**：校验 → 原子写 → 发布快照 → 广播。
- **R4**：选项只在 `schema.rs` 定义一次（默认值/范围/说明唯一出处）。
- 不引入 **tokio/异步运行时**；不引入 TOML 热重载黑魔法。
- 依赖建议：`arc-swap`（必需）；写文件用 **`toml_edit`**（保留用户格式/未知键/注释）；文件监听**优先 mtime 轮询**（极简，免 `notify` 依赖树）。新增依赖须过 `cargo deny`。
- `#![forbid(unsafe_code)]`；不联网。

## 验收（可测）

1. 文件不存在 → 用 Schema 默认值；首次改动时按 Schema 生成**带中文注释**的 `config.toml`。
2. `set("candidate.count","9")` → **原子写文件** + **快照更新** + **订阅回调收到 `candidate.count`**。
3. 删掉文件某一行 → 该项**回落到 Schema 默认值**。
4. **语法错误** → 保留上一份可用快照、不崩、报告错误行号。
5. **未知键** → 忽略并警告，**不删除**用户写的未知键。
6. 非法值（类型/范围）→ `set` 返回错误，文件不变。
7. 单测覆盖 1–6；`make verify` 全绿。

## 禁止

- 不实现 §9 的 C ABI（属 `ime-ffi`，P1-M3）；
- 不引入第二个配置文件 / 不写注册表；
- 不让 `ime-cli` 之外的组件各自缓存配置副本。
