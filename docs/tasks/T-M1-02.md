# T-M1-02：键名字 + 成字字根编码规则

- **状态**：完成
- **模型建议**：flash（规则确定，已给出完整规格，照实现即可）
- **前置**：T-M1-01
- **目标**：在 `crates/wubi-encoder` 实现"键名字"与"成字字根"两类单字的编码。

## 背景知识（照此实现，不要自行发挥）

- **键名字**：每个键有一个代表字（如 G=王、F=土、T=禾、Y=言、N=已…）。规则 = **键连打四次**，例如 王=`gggg`。
- **成字字根**：本身是字、且出现在字根表里的字根（如 一、五、戋、士、二…）。规则 = **键 + 首笔 + 次笔 + 末笔**。
- **笔画→键**（五笔86 笔画区）：横=G、竖=H、撇=T、捺/点=Y、折=N。

## 步骤

1. 在 `RadicalTable` 增加：`key_name_char(key) -> Option<char>`（键名代表字）与 `is_radical_char(&str) -> bool`（该字是否在字根表中）。
   - 键名代表字固定为 25 个：G王 F土 D大 S木 A工 H目 J日 K口 L田 M山 T禾 R白 E月 W人 Q金 Y言 U立 I水 O火 P之 N已 B子 V女 C又 X纟。
2. 实现 `encode_key_name(key: char) -> String`：返回 `key` 重复 4 次（如 `g`→`"gggg"`）。
3. 实现 `encode_chengzi(radical: &str, strokes: &[Stroke], table: &RadicalTable) -> Result<String, EncodeError>`：
   - 若 `strokes.len() < 2` 返回错误；
   - 首笔=strokes[0]，次笔=strokes[1]，末笔=strokes[last]；
   - 返回 `键 + stroke_to_key(首) + stroke_to_key(次) + stroke_to_key(末)`。
4. 实现 `fn stroke_to_key(s: Stroke) -> char`（横G 竖H 撇T 捺Y 折N）。
5. 写单测（见下）。

## 规格（公开 API 必须一致）

```rust
impl RadicalTable {
    pub fn key_name_char(&self, key: char) -> Option<char>;
    pub fn is_radical_char(&self, c: &str) -> bool;
}
pub fn encode_key_name(key: char) -> String;
pub fn stroke_to_key(s: Stroke) -> char;
pub fn encode_chengzi(radical: &str, strokes: &[Stroke], table: &RadicalTable) -> Result<String, EncodeError>;
```

## 验收（单测断言）

- `encode_key_name('g') == "gggg"`；`encode_key_name('f') == "ffff"`；
- `stroke_to_key(Stroke::Heng) == 'g'`、`Shu=='h'`、`Pie=='t'`、`Na=='y'`、`Zhe=='n'`；
- 用夹具：成字字根 `一`（键 `g`，笔画 [Heng]）→ 笔画数 < 2 时报错（`[Heng]` 应报错）；
- 用 `五`（键 g，笔画 [Heng,Shu,Heng,?] 按真实五笔笔画 = 一丨𠃍一? 简化起见用 [Heng, Shu, Zhe, Heng]）→ `g` + 首(Heng=g) + 次(Shu=h) + 末(Heng=g) = `"gghg"`；
- `cargo test -p wubi-encoder`、`make verify` 全绿。
