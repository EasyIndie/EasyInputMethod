# T-M1-09：正式码表接入 ime-table / ime-cli（pro）

- **状态**：待认领
- **模型建议**：**pro**（跨 crate 集成，需理解现有 `ime-table`/`ime-cli` 结构并决定加载方式）
- **前置**：T-M1-05（单字）、T-M1-06（词组）、T-M1-07（权重）
- **目标**：用**真实自建码表**替换 M0 的示例码表，让 `ime-cli` 能用正式数据打字。

## 步骤

1. 决定 `ime-table` 如何加载正式码表（先沿用 M0 的排序数组 + 从 TSV 构建，`cedarwood` 换型留到后续体积优化；**不要在本卡强行引入 cedarwood**）。
2. 在 `ime-table` 增加从 TSV（`code\ttext\tweight`）构建 `Table` 的加载器（带解析错误处理；解析器要有单测）。
3. `ime-cli` 改为从 `data/generated/*.tsv` 加载（路径通过参数或环境变量传入，不要写死绝对路径）。
4. 保留一个最小的内置回退表（用于无数据文件时的 CI 测试）。
5. 更新单测：用真实样本 `wq→你`、`kwwl→中华人民共和国`、`gggg` 重码排序（王/一按词频）。

## 验收

- `ime-cli` 用正式码表能打出验收样本；
- 解析器单测覆盖：正常行、缺列、空行、非法权重；
- `make verify` 全绿；
- 本卡完成后 `ROADMAP.md` 的 P1-M1 全部勾选。

## 铁律提醒

- 解析器是"唯一不可信输入"入口 → 必须 fuzz（至少手工构造边界用例；`cargo fuzz` 目标可随后补）；
- `forbid(unsafe_code)`；不联网。

## 禁止

- 不引入 `cedarwood`（体积优化另行立项）；
- 不在 `ime-core` 里写码表相关特判。
