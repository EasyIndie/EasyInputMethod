# T-P2-02：偏好设置面板（Schema 驱动）

- **状态**：✅ 完成（2026-10-11；ADR-070）
- **模型建议**：**pro**（跨 Rust Schema/FFI ABI + Swift UI + 观察者模型，含设计决策）
- **前置**：ADR-070（先写 ADR）、`docs/配置架构.md` §8/§9/§11、Skill `add-config-option`
- **目标**：提供 macOS 设置面板，用户**无需改 `config.toml`** 即可调整全部偏好，改动即时生效。

## 背景

`PROD-01/ARCH-08`、`UX-01/TD-04`：所有偏好只能改配置文件。`ime_config_schema()` 早已备好，`配置架构.md` §11 验收第 6 条要求界面零硬编码。

## 步骤

1. **Schema 补展示元数据**：`OptionSpec` 增 `title_zh`（短标题）与 `enum_labels_zh`（枚举显示名，与 `values` 一一对应）；15 项全部填齐。
2. **ABI 扩展**：`ImeConfigSchemaOption` 追加 `title_zh`、`enum_labels_zh`（NUL 分隔、空串终止）；`build_schema` 保留缓冲；头文件 `ime.h` 同步。
3. **宿主 UI**：新增 `platforms/macos/Sources/Settings.swift`——`NSPanel` 非模态、Schema 驱动建表（bool/int/enum/string 四类控件），分组按 `scope`；值读 `ime_config_get`，写只经 `ime_config_set`。
4. **多观察者**：`ConfigWatcher` 支持多 owner，宿主控制器与设置面板各自订阅（配置被其它入口改动时面板同步）。
5. **入口**：`InputController.menu()` 加「偏好设置…」（⌘,）。
6. **测试**：预览冒烟断言 Schema 项数/标题/说明/枚举一一对应、面板行数、`ime_config_set` 往返。

## 验收

- 设置面板**零选项硬编码**（选项/类型/范围/默认/分组全来自 Schema）；
- 改动即时生效并写回 `config.toml`（唯一写入路径，无 `UserDefaults`/第二文件）；
- 预览冒烟含设置断言；`make verify` 全绿。

## 铁律提醒

- 配置只走 `ime-config`（R1–R4）；
- 不联网、不扩非目标功能；核心 `forbid(unsafe_code)`（ABI 改动只在 `ime-ffi`）。

## 禁止

- 不自解析/写 TOML；不用 `UserDefaults`；不引入 SwiftUI 或新依赖；不新增配置项（字号/字根等留后续）。
