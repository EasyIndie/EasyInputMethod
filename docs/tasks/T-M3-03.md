# T-M3-03：安装/卸载与签名公证流程

- **状态**：进行中（脚本实现；真实签名候选及最终安装验收待完成）
- **前置**：T-M3-02，ADR-023/032；用户要求开发使用独立窗口
- **目标**：让签名、公证、源码许可附件和安全安装可复现，不绕过 Gatekeeper。

## 交付物

1. platforms/macos/install.sh：默认用户域；--system 显式系统域；先检查标识、签名、公证和 Gatekeeper，不重复签名。相同版本幂等，不覆盖不同版本，--dry-run 不写安装目录。
2. platforms/macos/uninstall.sh：先人工移除输入源及关闭宿主，再移出 bundle 到备份目录；不删除配置词库。
3. packaging/macos/sign.sh：--sign 本地 Developer ID 签名；--submit 显式上传 Apple、等待结果、staple/validate/assess。日常构建不运行这一步。
4. packaging/macos/prepare.sh：严格数据构建；发布候选附完整源码+vendor、CycloneDX、依赖/数据许可与 SHA。--signed 必须通过可信检查且源码提交一致。

## 验收

- [x] bash -n 和异常参数检查；未公证候选不可安装；数据缺失严格失败
- [ ] 真实签名公证产物的安装、卸载与重复安装经实机验证
- [ ] 用户域与系统域的装载分别验证，不据此前系统域成功推断用户域成功
- [ ] 完整发布候选多应用验收
- [ ] make verify 全绿（每次提交执行）

旧任务卡的“不引入 Apple 账号、ad-hoc 后手动放行”要求由 ADR-032 取代；本机 SIG-1 已证明该方案不足以可信装载。当前会话不自动重装系统输入法。
