# T-M3-03：安装/卸载脚本 + Gatekeeper 说明（flash）

- **状态**：待认领
- **模型建议**：flash（脚本 + 文档）
- **前置**：T-M3-02（bundle 产出）
- **目标**：让别人也能一键安装/卸载，并说明"为什么需要手动放行"。

## 交付物

1. `platforms/macos/install.sh`：拷贝 bundle 到 `~/Library/Input Methods/`、`codesign -s -` ad-hoc 签名、提示注销/重登。
2. `platforms/macos/uninstall.sh`：移除 bundle + 提示。
3. `platforms/macos/README.md`：手动装载步骤 + **Gatekeeper** 说明（Phase 1 无签名/公证 → 系统可能拦截；如何"仍要打开"/本地 ad-hoc 签名的取舍）。
4. 检查 `build.sh`/`install.sh` 的幂等与错误处理（目录不存在、权限等）。

## 验收

- 脚本 `shellcheck` 风格（或 `bash -n`）通过；`install.sh` 在本机可重复执行；
- README 步骤经人工走一遍可行（记录结果）；
- `make verify` 保持全绿（纯脚本/文档）。

## 禁止

- 不引入需要 Apple 开发者账号的步骤；
- 不写系统级目录（只装到当前用户 `~/Library/Input Methods/`）。
