# T-M1-05a：引入独立的「字型结构 + 末笔」数据源（pro）

- **状态**：完成（结论：暂无合格独立来源，按卡规「停下并写结论」交付）
- **模型建议**：**pro**（数据源调研 + 许可判定 + 派生实现 + 与 D3 的"独立"对照设计）
- **前置**：T-M1-03（编码器）、T-M1-04（D2/D3 就绪）
- **目标**：为识别码提供**独立于 D3** 的「字型结构（左右/上下/杂合）」与「末笔笔画」数据，替换 ADR-017 的 PROVISIONAL 派生数据。

## 为什么

- T-M1-03 的结构/末笔是**从 D3 反推**的（ADR-017），导致"与 D3 对照"实为**自证**。
- 长期正确性要求：识别码的输入必须来自**独立数据**，否则"自建码表"（ADR-016）不成立。

## 要评估的候选来源（自行调研并核实许可）

**结构（左右/上下/杂合）——倾向 IDS（表意文字描述序列）**
- `cjkvi/cjkvi-ids`（`ids.txt` 等）——**先核实许可**
- CHISE IDS 数据库（`chise/ids`）——**先核实许可**
- 思路：IDS 的 12 类结构 → 归并到 3 类（⿰/⿲→左右；⿱/⿳→上下；其余→杂合），并**抽样验证**该归并与五笔字型结构一致。

**末笔笔画（横/竖/撇/捺/折）**
- `KanjiVG`（CC BY-SA 3.0）笔画路径 → 末笔方向归类
- `skishore/makemeahanzi` / `chanind/hanzi-writer-data` 的笔画数据（**注意其源自 Arphic 字体，许可需重点核实**）
- 思路：取该字**最后一笔**的走向 → 归入五类。

> ⚠️ 任何来源都必须：许可与 **GPL-3 兼容**、可固定 SHA-256、可离线复现。
> 若**找不到**合格的独立来源，**停下并写结论**（不要伪造数据、不要退回 D3）。

## 交付物

1. `data/sources/fetch-*.sh`：下载所选来源并校验 SHA-256（大文件不入库）。
2. `docs/数据来源与许可.md` + `data/sources.toml`：登记新来源（含许可、SHA-256、风险、用途）。
3. 生成器（`crates/wubi-encoder/examples/` 或 `tools/`）：独立来源 → `data/generated/wubi86-structure-laststroke.tsv`，**schema 与 ADR-017 版本一致**（`字\t结构\t末笔\t五笔码`），便于 T-M1-05 直接替换。
4. **独立性对照报告**（`data/generated/structure-vs-d3.txt` 或 `docs/`）：
   - 与 D3 派生版本的一致率（**作为一致性检查，不作真值**）；
   - 不一致抽样 + 归因；
   - 明确说明"本数据**不依赖** D3"。
5. 若涉及设计取舍 → 追加 ADR（如 ADR-018）。

## 验收

- 独立来源已登记（许可 + SHA-256），**结构/末笔不再来自 D3**；
- 生成器可离线复现；
- 与 D3 的一致率报告存在（GB2312 一级字目标 ≥ 98%，不达标须说明）；
- `make verify` 全绿。

## 禁止

- 不用 D3 作为结构/末笔的来源（那正是本卡要消除的）；
- 不引入许可不明 / 与 GPL-3 不兼容的数据；
- 不提交大文件（用 fetch 脚本）。

## 参考

- ADR-016、ADR-017、ADR-007；`docs/tasks/T-M1-03.md`、`T-M1-05.md`；`docs/数据来源与许可.md` §1.2

## 结论（2026-10-08 完成，调研止步）

- **结论：没有找到合格的（GPL-3 兼容 + 许可明确 + 简体覆盖足够）独立结构/末笔来源，本卡按「停下并写结论」交付，未引入任何数据。**
- 许可核实要点：
  - **末笔**：`KanjiVG`（CC BY-SA 3.0，GPL-3 兼容 ✓）只覆盖日本汉字，GB2312 一级仅 **2395/3755（63.8%）**；`makemeahanzi`/`hanzi-writer-data`（源自 Arphic 字体）为 **Arphic Public License**，FSF 明确判定 **incompatible with the GPL**。
  - **结构**：`cjkvi/cjkvi-ids`（ids.txt 派生自 CHISE，"许可从其条款"）、`chise/ids`（数据无 LICENSE 声明）均**许可不明确**。
- **未**伪造数据、**未**退回 D3；ADR-017 PROVISIONAL 数据继续作为 T-M1-05 临时输入。
- 产出：**ADR-018** + `docs/数据来源与许可.md` §1.3（候选许可判定表）+ 本结论。
- 阻塞：T-M1-05（单字码表生成）继续阻塞，待找到合格来源（候选路径见 ADR-018「下一步」）。
- 验证：`make verify` 全绿（纯文档变更）。
