# T-M1-04b：接入第二个 oracle 码表（rime-wubi，LGPL-3）（flash）

- **状态**：待认领
- **模型建议**：flash（下载 + 解析 + 登记，机械）
- **前置**：T-M1-04（D3 已就绪）
- **目标**：把 `rime/rime-wubi` 的 `wubi86.dict.yaml` 接为**第二个验证 oracle**（ADR-019），供 T-M1-05 做多源对照。

## 背景

- ADR-016/019：第三方码表**仅作验证 oracle，不进入发布产物**。
- 选定 oracle #2 = `rime/rime-wubi` `wubi86.dict.yaml`（**LGPL-3**）。
  - ⚠️ 其表源自**极点五笔（Jidian）**→ **仅用于测试对照，绝不分发**（既有文档已允许极点系数据作回归对照）。

## 步骤

1. 新增 `data/sources/fetch-wubi-oracle2.sh`：下载 `wubi86.dict.yaml` + **固定 SHA-256 校验**（文件不入库，`.gitignore` 已覆盖 `data/sources/*`）。
2. 在 `data/sources.toml` + `docs/数据来源与许可.md` 登记：
   - id（如 D9）、url、上游 `rime/rime-wubi`、**许可 LGPL-3**、SHA-256、`used_for = ["wubi86-code-oracle"]`、`role = "validation-oracle"`、`ship = false`、风险=中（极点来源）。
3. 写一个解析器（`tools/` 或 `crates/wubi-encoder/examples/`）把 Rime 字典转成 **`字\t码`** 的单字表：
   - 只保留**单字**条目（`text` 长度为 1 个汉字）；
   - 输出 `data/generated/wubi86-oracle2-single.tsv`（可提交，小文件）。
4. 抽样核对：`的→rqyy`、`一→ggll`、`你→wqiy`、`中→khk`、`好→vbg`（与 D3/规范一致）。
5. 统计：单字条目数、与 D3 的**简单一致率**（粗报即可，正式对照在 T-M1-05）。

## 验收

- `fetch-wubi-oracle2.sh` 可运行且校验和匹配；
- 登记完成（含 `ship = false` / `role = validation-oracle`）；
- `data/generated/wubi86-oracle2-single.tsv` 生成，抽样 5 字全部正确；
- `make verify` 全绿。

## 禁止

- 不把 oracle 数据提交进发布产物 / 不打包；
- 不改编码逻辑；
- 不引入 `wubi-jidian` 以外的**许可不明**来源。
