# T-M1-06b：词表与词频升级（jieba dict.txt，MIT）（flash）

- **状态**：待认领
- **模型建议**：flash（下载 + 过滤 + 重生成 + 赋权，机械）
- **前置**：T-M1-05（单字码表）、T-M1-06（词组生成器）
- **目标**：用**通用词表 + 词频**（`fxsjy/jieba` `dict.txt`，MIT）重生成词组码表，并给单字/词组**统一赋权**（替代临时权重）。本卡**同时交付 T-M1-07 的词频目标**。

## 背景

- T-M1-06 用 D4 生成的词表**不完整**（常见 2 字词缺 60%）。
- `fxsjy/jieba` `dict.txt`：**MIT**，349,045 条「词\t频次\t词性」，覆盖通用词汇。
- ADR-013 要求「可用的默认权重（词频）」为 P1-M1 必交付 → 由本卡完成。

## 步骤

1. 新增 `data/sources/fetch-jieba-dict.sh`：下载 `dict.txt` + **SHA-256 校验**（不入库）。
2. 登记 **D10**（`data/sources.toml` + `docs/数据来源与许可.md`）：上游 `fxsjy/jieba`、**MIT**、SHA-256、`used_for=["wubi86-wordlist","wubi86-frequency"]`、风险（数据 provenance 说明）。
3. 生成器（改 `examples/generate_phrases.rs` 或新增）：
   - 读 jieba 词表，**只保留纯汉字词**（过滤含字母/数字/符号的词）；长度 2–10；
   - 用 `encode_phrase` 生成词组码；**同码保留权重最高者**；
   - 输出 `data/generated/wubi86-phrases.tsv`（`code\t词组\tweight`，**真实词频**）。
4. 单字赋权：`data/generated/wubi86-single.tsv` 的 `weight` 改为**真实词频**（jieba 中该字的频次；缺者给一个小的默认值），保持重码降序。
5. 报告：词条数、过滤数、同码丢弃数；抽样 `中华人民共和国→kwwl`、`世界`、`人民`、`计算机` 均在表中。

## 验收

- `wubi86-phrases.tsv` 含 **世界/人民/中文/输入法/计算机/经济学/图书馆/中华人民共和国**；
- 单字/词组 `weight` 均来自 jieba 词频（可复现）；
- `data/sources.toml` D10 登记完整（含 SHA-256）；
- `cargo test`（含 `encode_phrase` 样本）、`make verify` 全绿。

## 禁止

- 不引入许可不明来源；不硬编码词表进代码；
- 不改编码规则（词组规则由 T-M1-06 已定）。
