# T-M1-05：单字码表生成 + 对照回归（pro）

- **状态**：待认领
- **模型建议**：**pro**（需判断编码正确性、裁定拆字分歧、设计重码合并与回归）
- **前置**：T-M1-03、T-M1-04
- **目标**：生成"code → [字 + 权重]"单字码表，并用公开码表做**对照回归**。

## 步骤

1. 用 `crates/wubi-encoder` 对拆字数据逐字编码（键名字/成字字根走 T-M1-02 逻辑，合体字走 T-M1-03 逻辑）。
2. 对 T-M1-04 的分歧清单逐条**人工/程序裁定**，裁定依据记录到 `data/generated/chaizi-diff-resolved.tsv`。
3. 反转索引得到 `code → [字]`；重码按一个临时权重（先按 GB2312 一级字>二级字>其它 + 笔画数）排序。
4. 输出 `data/generated/wubi86-single.tsv`（`code\t字\tweight`，不提交大文件则提交生成脚本与统计）。
5. **对照回归**：用一份公开码表（如 Rime `wubi86.dict.yaml` 或 `wubi86_jidian.dict.yaml`，**仅作测试对照、不打包、不分发**）：
   - 计算与我们的编码一致的字的占比；
   - 不一致清单抽样输出，**分析原因**（规则错？拆字错？识别码？）；
   - 目标：常用字（GB2312 一级 3755 字）一致率 ≥ 99%。
6. 把回归脚本与结果摘要写进 `docs/`（一致率、主要差异原因）。

## 验收

- `data/generated/wubi86-single.tsv` 由脚本可复现生成；
- 对照回归脚本存在，一级字一致率 ≥ 99%（或明确记录未达标原因与后续计划）；
- 差异分析写入文档；
- `make verify` 全绿。

## 铁律提醒

- 对照用的公开码表**不打包、不分发**（AGENTS.md 铁律 4；`docs/数据来源与许可.md` 有说明）；
- 自产码表用 CC-BY-SA-4.0（ADR-014）。

## 禁止

- 不把对照用的第三方码表提交进仓库；
- 不硬编码码表进代码。
