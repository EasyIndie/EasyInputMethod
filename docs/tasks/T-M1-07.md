# T-M1-07：词频权重接入

> ℹ️ **已并入 [T-M1-06b](T-M1-06b.md)**（jieba `dict.txt` 既提供词表也提供词频）—— 本卡不再单独执行。

- **状态**：✅ 已由 [T-M1-06b](T-M1-06b.md) 完成（2026-10-08）
- **模型建议**：flash（机械：接入一份公开词频，做归一化映射）
- **前置**：T-M1-05（先给单字用；词组在 T-M1-06 之后同样处理）
- **目标**：用公开词频给候选赋权重，使**重码按高频在前排序**（这是五笔可用性的关键，ADR-013）。

## 步骤

1. 选定一份**许可明确**的公开中文词频表（候选：`rspeer/wordfreq`（数据多源，需逐个核实）、开放语料统计、或 `phrase-pinyin-data` 自带的覆盖度近似）。**必须先核实许可**并登记到 `docs/数据来源与许可.md` D7。
2. 写归一化脚本：把词频映射到整数权重（如 `weight = round(log2(freq+1) * 100)`，具体公式自定但要在脚本里注释说明）。
3. 把权重回填到单字码表与词组码表（T-M1-05/T-M1-06 产物）。
4. 更新 `ime-table` 的测试样例，验证"同码候选按权重降序"。

## 验收

- 权重字段在码表产物中存在且可复现；
- 一个明确的重码样例（如 `gggg` → 王/一）按词频排序，高频在前（测试断言）；
- 词频来源与许可已登记；
- `make verify` 全绿。

## 铁律提醒

- 词频数据登记许可 + SHA-256；不打包第三方数据（仅用其生成权重）。

## 禁止

- 不引入网络获取词频（用本地下载脚本）；
- 不做"学习"（用户词频学习在 P1-M4）。
