# T-M2-04：`inputx-pinyin` spike（flash）

- **状态**：待认领
- **模型建议**：flash（调研 + 写结论，不实现产品代码）
- **前置**：无（可与 T-M2-03 并行）
- **目标**：按 ADR-008 评估 `inputx-pinyin`，产出**是否接入**的结论（不改变当前内置兜底）。

## 调研项（写进 `docs/reviews/` 或任务卡结论）

1. **许可**：`inputx-pinyin` 上游许可（项目为 GPL-3，须兼容）；数据许可。
2. **API**：切分/整句/简拼接口是否满足 `PinyinBackend`（T-M2-02 的 trait）？能否 `impl Engine`？
3. **质量**：抽 20 个常用词（你好/中国/输入法/…）对比现内置兜底的候选质量。
4. **体积**：编译进产物后增加的体积（对比 0.6MB 预算）。
5. **可移植**：是否纯 Rust、无 C 依赖、可交叉编译到移动端。
6. **维护度**：最近提交、issue 活跃度。

## 验收

- 产出**结论**：推荐「接入 / 不接入 / 观察」，附**依据数据**（许可、体积、质量样例）；
- 若推荐接入 → 写一张后续卡（不改本卡内代码）；
- 若涉及决策 → 更新/追加 ADR（ADR-008 的终局决定）；
- 不改产品代码；`make verify` 保持全绿。

## 禁止

- 本卡**只调研不集成**；
- 不因"省事"就放弃 trait 抽象（ADR-008 的核心是不绑定单一引擎）。
