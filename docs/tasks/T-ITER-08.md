# T-ITER-08：简繁与拼音资源错误

- 状态：已完成（ADR-097）
- 前置：无
- 目标：资源缺失/损坏/无有效数据可见，保持简繁懒加载；状态显示与实际输出一致。
- 验收：临时夹具缺失、损坏、空有效数据均有明确错误；繁体不可用时保持输入且标明简体回退，不冒称繁体；修复后重新启用可恢复。make verify零诊断、strict宿主及隔离预览通过。
- 约束：不新增数据来源、不在真实资源文件注入故障、不改默认输入方案。

## 验证结果

FFI回归覆盖缺文件、损坏/空映射、有效状态与候选简体回退、重新注入恢复；拼音加载拒绝空字表和显式空词表。隔离预览坏映射与恢复通过，默认简体未解析映射的单测保留。make verify零诊断、strict arm64构建、预览冒烟通过；宿主显示异常菜单及候选徽标。
