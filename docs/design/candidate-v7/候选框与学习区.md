# 候选框 v7：主体优先与安静的学习区

2026-10-14，用户指出v6学习区抢主、重复字词且冗余，本版修正视觉层级并细化翻页。显示偏好沿ADR-155，不改产品源码。

## 主次与信息去重

主体的候选文字17pt，当前项semibold，不加背景；其余项regular。序号11pt，原始码12pt，均不比候选突出。学习区只有一条细分隔线，普通文字12pt、规则11pt，完整码13pt等宽medium；不再使用18pt目标字、22pt字根、卡片或强调色。

上方已能识别当前项，学习区不再重复“你／你好”标题，也不重复“五笔86 · 完整码”常驻标签。方案本项目固定五笔86，显示在设置及说明；学习区只需“完整码 WQIY”。用户输入的原始码与目标完整码语义不同，分别保留，不能为去重将它们合并。

单字三行：完整码；根键对应“亻 W · 勹 Q · 小 I”；识别码解释“Y：末笔点 · 左右结构”。无需四个巨大字根格。

词组：只显示一次词组完整码；逐字一行列出单字完整码及根键映射，不重复整词标题和拼接后词组码。保留取码规则及识别码逻辑。逐字的“你／好”是必要的映射标签，不是重复整词标题。数据缺失仅一条准确说明，不放空结构或警示图标；已有完整码仍保留。

学习区可能因长词比主体高，主次不靠强行裁掉解释达成，而靠文字大小、字重、低干扰颜色和信息去重。必要说明保持项目可读对比，不用极淡灰色制造层级。当前稿仍使用AppKit动态语义色，次级色按背景对比判断回退，不硬编码低对比灰。

## 翻页：紧贴页码的轻量控件

右上角原始码同行：前向chevron、页码、后向chevron。使用真实SF Symbols chevron.left/right；样例图仅原生图形/文字的结构稿，不是已接线控件证据。

| 状态 | 呈现与操作 |
|---|---|
| 单页 | 隐藏整个翻页组，不显示1/1或两个禁用箭头 |
| 多页首页 | 上一页禁用，下一页启用，页码1/N |
| 中间页 | 两侧启用，页码p/N |
| 末页 | 下一页禁用，上一页启用，不循环回首 |
| 无候选 | 不显示页码或翻页箭头 |

页码只读，不能点开跳页或要求输入页号。上一页/下一页采用24×24pt命中区域、约10pt图标、11pt等宽数字参考排版；总页数位数变化按所需宽度测量，不能与原始码重叠。箭头禁用用系统disabled角色；悬停和按下只在命中范围给予原生轻反馈，不常驻方块背景。无鼠标悬停动画或整组强调色。

实际控件应为非激活面板中的可访问动作：名称“上一页”“下一页”，页码值“第p页，共N页”，边界disabled并禁止动作。Tooltip显示对应现有有效翻页绑定，不印两套常驻按键教程；无绑定时只显示动作名。

鼠标仅翻页，不提交、取消组合、激活窗口或移动插入点。保留原页内数字映射；翻页后空格目标与学习区关联采用现有候选契约，不能保留上一页的字词解释。键盘继续既有减号/等号及可选逗号/句号翻页设置，**不将左右方向键映射为新选词／翻页操作**，IT-24导航保护保持。

非循环边界是本版交互提案，实施前核对引擎现有边界行为并统一ADR/回归；不允许只在UI禁用而后台继续循环。末页不足配置数量时不画空候选格，页码计算以实际过滤后候选和页大小为准；总数变更导致页越界时应采用引擎合法页结果，不显示假页码。

## 尺寸和稳定性

400pt仅四项短词参考宽。收起高度74pt；学习区展开保持候选文字和翻页控件位置不变，扩展在下方。长候选整页纵排和长说明换行按实际测量处理，不能改变配置候选数或截掉关键文字。屏幕边缘定位、候选数3–9、大字、三位数页码、短词/长词转场及真实点击仍待实机验证。
