2. **figma-swiftui**：实际加载共享Apple原生规则；采用系统模式识别、语义色、SF Symbols按名字引用，未执行Figma/SwiftUI代码迁移。本项目是macOS/AppKit，不使用其中iOS标签栏或触控尺寸作为Mac强制规范。
3. **apple-native-product-design**：保留项目交互/状态/输出边界，加入这次验证暴露的原生真实性检查；不再把自绘静态控件标作原生视觉验证。

## 原生真实性：这版怎么形成

- `native-render.swift`是独立出稿源，位于docs/design，仅链接AppKit，没有IMK/引擎/配置接口。生产Swift/Rust源码未变。
- 使用真实NSWindow、NSToolbar、NSSegmentedControl、NSPopUpButton、NSTextField、NSButton、NSStepper、NSProgressIndicator与SF Symbols，以系统字体和NSColor绘制；没有PIL/CSS仿画按钮、交通灯或图标。
- 36张2× PNG：亮暗各16张，加两种增加对比度appearance的输入/候选共4张。PNG保留原始pt/像素关系，图库以1×pt大小展示，不把控件放大成网站表单。
- 窗口禁止成为真实key/main，始终离屏，未激活桌面、发键、访问产品配置/词库或注册输入源。因此窗口chrome及默认按钮显示**非激活外观**；它不是最终App真实活跃窗口截图。悬停、按下、键盘焦点、sheet呈现与背景折射未作实机验证，不伪造蓝色按钮证明。
- 候选是项目特有内容，用原生文字/颜色与NSBox背景展示其布局。菜单图是**NSMenu排版规格**，不是实际系统弹出菜单截图；sheet图只展示原生字段/按钮的内容，不冒充真正的模态父子窗口状态。

## 设计方向

**像一件安静的Mac输入工具。** 系统负责框架、控件和颜色，项目负责候选可读、状态可信与焦点不被夺走。窗口内不重复品牌标题、宣传口号、工程UUID或版本长串；关于页保留正式品牌图标与必要身份信息。

### 设置：固定工具栏的四个pane

采用Mac设置窗口的工具栏分区“输入 / 候选 / 快捷键 / 词库”，使用真实SF Symbols：keyboard、text.bubble、command、character.book.closed。工具栏不可自定义/隐藏，当前pane可识别；窗口标题随pane变为“输入 — 萤火虫”等。窗口只需要关闭，不把最小化/最大化做常用动作。分区切换按内容高度调整，650pt是本稿参考宽度，字体变化时重新量测；不能将这份固定尺寸原型作为响应式实现证据。

最近pane可在会话内记忆；跨重启恢复若需新增持久状态，必须先按项目配置唯一规则决策，不写UserDefaults。输入法不同于普通文档App，设置入口仍在输入源功能菜单，**不能截获宿主客户端的全局⌘,**。

| Pane | 已有配置/动作 | 视觉与操作 |
|---|---|---|
| 输入 | mode | 原生三段选择：混输、五笔、拼音；一行解释五笔优先 |
| 输入 | input.chinese_variant、input.punctuation | 原生弹出选择；失败不显示假成功 |
| 输入 | input.full_width | 原生复选框“默认全角ASCII”；明确临时会话切换 |
| 输入 | wubi.auto_commit、wubi.z_key、pinyin.fuzzy | 复选框与选择器，按五笔/拼音相关性分组 |
| 候选 | candidate.count、candidate.page_with_comma | 原生数值字段+步进器，3–9；翻页复选框 |
| 候选 | appearance.theme | 默认跟随系统；既有浅深覆盖保留兼容，不添加皮肤 |
| 快捷键 | hotkey.toggle_mode、hotkey.toggle_english、hotkey.toggle_width、hotkey.toggle_punctuation、hotkey.toggle_variant | 首层显示Mac键位符号，通过“编辑…”在原生sheet修改现有表达式；非法/重复不保存，原设置保留 |
| 词库 | 新增、精确删除、导入、导出、反查 | 普通原生按钮，省略号表示后续输入/选择，不虚构词库列表或搜索 |

即时生效没有全页“保存”。默认成功不放一块绿色状态卡；仅在必要处短暂反馈。失败通过相关行说明和恢复动作持续呈现，焦点留在用户正在编辑的字段。

### 候选：紧凑、贴近插入点

**2026-10-14更新：以下为v2历史候选布局，当前待审阅基准改为[候选框v3](../candidate-v3/候选框设计.md)。**

稿件常态约424×120pt，默认文字16pt，索引11pt，顶层原始码12pt。第一候选仅以**系统强调色的轻提示、加粗文字与序号1**标明空格提交目标；不是键盘焦点。当前机器系统强调色为绿色，这不是写死的品牌绿。来源在混合页按项显示，单来源页省略；底层仅五笔键位提示和页码，不摆设置/升级/反馈按钮。

长词整页纵排，数字映射与排序不变；布局转换是设计提案，不偷偷改变页大小。无码命中保留原始码及可编辑提示，不弹系统警报。屏幕边缘定位/跨屏/缩放须实机验收。

交互沿既有契约：数字选词、空格首项、Enter原码、退格修改、Esc取消；模式更改取消组合；配置重算不能自动上屏。IT-24/ADR-151的新方向键保护不是箭头选词，签名包原生复验前阻塞保持。候选及AX选择不激活面板，提交到原客户端。

### 功能菜单：原生NSMenu的明确状态

拟设计结构：输入模式子菜单（✓混输、五笔、拼音）；中文输入；全角ASCII；繁体输出；中文标点；分隔；设置…、关于萤火虫…。布尔项勾号表示启用状态，快捷键显示真实配置，不为每项配彩色图标。不要出现测试UUID、营销文字或第二个输入法专属状态栏入口。

**子菜单三选一是本版新交互提案**，替代现有一级循环；实现前须ADR，不当成已存在功能。系统输入源总菜单归macOS，应用外观覆盖不改变它。

### 词库/反查/关于：使用Mac原生任务模式

- 新增词条采用设置窗口附属sheet，永久字段标签“输入方案 / 完整编码 / 词条”。Return仅在有效时添加，Esc取消。失败留输入、定位错误；当前稿只是sheet内容。
- 删除确认精准对象，取消为安全默认；使用NSButton破坏性语义，不把整个窗口刷成红色。原生确认流程和真实焦点返回仍待验。
- 导入/导出用系统文件面板，不自制路径浏览器。父pane内显示结果，提供准确行号/原因；只在事实证明时显示“原词库未变”。
- 反查一个窗口内输入/结果；读音按引擎实际nihao格式显示，不增加未支持的音调/多音字能力。复制仅在有效结果时启用。
- 关于页使用现有正式图标、名称、版本、开源说明与诊断/用户主动反馈入口。截图里的版本只是设计样例；源码身份实际读最终包。

## 配色、字体与材料

完整角色在`native-color-reference.json`：windowBackgroundColor、controlBackgroundColor、labelColor、secondaryLabelColor、disabledControlTextColor、separatorColor、controlAccentColor、selectedContentBackgroundColor、keyboardFocusIndicatorColor与systemRed/Orange/Green。RGBA是**本机/该appearance的解析参考**，不是生产常量，必须含alpha解释。

必要说明优先可读：本次原生次级角色在固色离屏面上约4:1，未达项目4.5:1目标；原型会在这种情况下选用labelColor，把层级交给字号和分组，而不硬编码灰色。默认文字13pt、解释12pt、元信息11pt；不会把桌面所有控件改为44pt触控尺寸，也不使用品牌展示字体。

错误用符号+明确文字，成功用文字+可选系统符号；普通信息文字不用低对比红/绿色。默认按钮、勾选、禁用、忙碌由原生控件角色表达，文字含义不靠颜色猜。

亮暗默认跟随系统。Increase Contrast：采用系统accessible appearance并实测必要边界；本次appearance渲染不能替代真实全局辅助偏好检查。Reduce Transparency：候选和工具内容采用不透明标准表面，系统工具栏/按钮遵系统降级；Reduce Motion：无自定义弹跳、漂浮、每键变形或玻璃光效。Liquid Glass由新系统原生控件获得，内容层不自制折射；macOS13使用对应旧原生外观，不模拟27 API。

## 实施与验收边界

本版先设计审阅，无生产代码授权。未来小步：确认菜单三选一与pane导航 → 原生框架/语义色 → 候选内容 → sheets与反馈 → 实机辅助/多屏矩阵。每项另行ADR/PR并保持配置唯一与零网络。

需要原生实机补验：真实NSMenu、活跃/非活跃默认按钮、当前pane视觉标记、Tab/VoiceOver名称/角色/值/错误、sheet关闭返回对象、复制反馈、13/27系统差异、暗色高对比、系统强调色变化、半透明背景、长文本/大字/小屏边缘。无上述证据时不称HIG合规或无障碍全通过。

图中候选排序、页码及版本是设计样例，不是引擎实机结果；菜单／sheet／反馈窗口的合成展示不规定新增产品窗口。原生控件状态图属于设计评审器，底部范围说明不进入产品UI。

快捷键编辑是现有字符串编辑能力的交互重组，表达式留在编辑sheet，主pane仅展示可读键位符号。未实现按键录制、不截取全局键盘；非法/重复绑定保留编辑sheet及字段，允许取消返回。
