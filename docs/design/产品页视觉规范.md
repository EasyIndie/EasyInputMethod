# 产品页视觉规范（GitHub Pages）

> 适用于 `site/` 下的产品页。后续 Windows / Linux / 移动端介绍页**沿用本规范**，
> 只替换平台信息与下载入口，不重新发明视觉语言。

## 1. 原则

1. **一种安装入口**：macOS 页只讲 DMG 图形安装；命令行安装/卸载不作为页面内容。
2. **极简**：一屏一个主张，段落短，卡片只放一个观点。
3. **可验证**：签名、公证、开源许可、零网络等表述必须有事实依据。
4. **本地资源**：页面不加载第三方字体、脚本、统计或图片；图标随 `site/assets/` 发布。
5. **亮暗同源**：所有颜色走 CSS 变量，亮暗模式只改变量值。
6. **面向普通用户**：不用终端、不用 sudo 作为默认路径；技术细节放到“源码/发布记录”。

## 2. 色彩

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#f6faf8` | `#0c1411` | 页面底色 |
| `--surface` | `#ffffff` | `#111d18` | 卡片/导航 |
| `--surface-soft` | `#eef7f3` | `#16251f` | 侧栏、次级块 |
| `--text` | `#10231d` | `#eef7f2` | 主文字 |
| `--muted` | `#5c7169` | `#9db3aa` | 说明文字 |
| `--line` | `#dce9e3` | `#24362e` | 分隔/边框 |
| `--accent` | `#0b6b52` | `#62d3ab` | 主按钮、强调 |
| `--accent-soft` | `#e2f3ec` | `#17332a` | 胶囊/图标底 |
| `--warm` | `#c58a1c` | `#edc16b` | “不可恢复”等警示标签 |

- 主色是深绿/薄荷，不使用高饱和渐变；Hero 只用一层很淡的径向光。
- 阴影保持轻：`0 10px 30px rgba(16,35,29,.06)`（暗色降低透明度）。

## 3. 版式

- 内容宽度：`min(1040px, calc(100% - 40px))`。
- 字体：系统字体栈（`-apple-system` / `PingFang SC` / `Microsoft YaHei`）。
- 标题：Hero `clamp(40px, 6vw, 60px)`，字重 720，负字距；章节标题 `26–34px`。
- 圆角：按钮 11px，卡片 16px，大容器 22px，胶囊 999px。
- 间距：章节上下 24/78px；卡片内边距 22–24px；移动端收窄。

## 4. 结构

1. `nav`：图标 + 产品名 + 锚点（特性/安装/卸载/源码）。
2. `hero`：一句核心主张（五笔优先、拼音兜底）+ DMG 下载 + 信任信息。
3. `features`：6 张卡片，3 列 → 2 列 → 1 列；每张：图标、标题、一句说明。
4. `install`：三步编号 + “DMG 里有什么”侧栏；只写 DMG 流程。
5. `uninstall`：两个并列选择（保留/彻底清理），标明“不可恢复”。
6. 平台状态、开源收尾、隐私/许可页脚。

## 5. 组件规则

- 主按钮：实心 `--accent`，白字；一个页面只保留一个主 CTA。
- 次按钮：白底/描边，文字按钮不使用下划线。
- 图标：内联 SVG，`stroke=currentColor`，24×24 视图框，线宽 1.8。
- 标签：小号胶囊，用 `--accent-soft` 或暖色低透明底。
- 链接：默认绿色；必须有 `:focus-visible` 轮廓。
- 动效：只允许按钮 1px 位移；`prefers-reduced-motion` 下关闭。

## 6. 内容规则

- 版本号只出现在下载按钮的元信息与页脚；更新时同步 `site/index.html` 的 DMG 文件名。
- 不承诺未验证的事项（例如“最快”“零延迟”）。
- “离线/零遥测”限定为输入法内核；更新检查必须说明是手动、独立程序。
- 卸载说明必须区分“保留配置与词库”和“彻底清理”；后者标注不可恢复。
- 页脚保留 GPL-3.0-or-later、隐私声明、源码/发布记录/故障恢复入口。

## 7. 响应式与验证

- 断点：860px（Hero 单列、安装单列）、560px（特性单列、按钮满宽）。
- 检查：headless Chrome 在 1280px 与窄屏各截一次；亮暗各检查一次。
- 发布：`site/**` 变更后手动触发 Pages 工作流。
