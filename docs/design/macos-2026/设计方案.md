# 萤火虫 macOS 交互与视觉设计方案 v1（历史，已由v2替代）

日期：2026-10-13。用户否定其Apple平台调性，当前设计以[原生v2](../macos-native-v2/设计方案-v2.md)为准。状态：**设计提案，未实现、不修改产品代码**。依据已装d429cec首版、审计009、已有配置Schema与ADR；IT-24修复78b6762另行获批准，经PR #40合入809efdb；已装包仍为d429cec，新签名候选复验尚未完成。不以视觉稿关闭任何MVP功能/实机门禁。

入口：[全界面视觉稿](visual-spec.html) · [语义设计令牌](tokens.json) · [验证报告](validation.json) · [依据与第三方评估](来源与评估.md)。视觉稿是离线设计证明，控件仅改变稿件状态，不读取/保存用户配置、不注册输入源、不访问网络。

## 1. 产品观点与范围

**让候选清楚、操作可信、打字不断。** 面向五笔优先、偶尔需要拼音兜底的中文输入者。保留混输、五笔86、有限拼音、输入状态切换、词库增删/导入导出、反查、设置、版本/诊断与用户主动反馈。品牌出现在识别入口和关于页，日常候选以文字为中心。

现有候选把状态、候选、来源、翻页提示挤在同一行；设置是大量Schema行加工具按钮。重设计改为候选主层/解释次层、可见的首候选、固定设置信息架构、非模态的操作反馈。所有颜色具有同一语义，不用“红/绿”区分五笔/拼音。

不新增云、账号、统计、广告、AI、剪贴板记录；不更换工程技术栈、不承诺整句拼音。搜索词库列表、快捷键录制、字号新设置、箭头选词属于未来能力，不混入本轮首版视觉稿。

## 2. 官方原则与本项目的选择

Apple HIG要求使用熟悉平台模式、动态系统色与可访问性适配。这里采用系统菜单、窗口、按钮、字段、检查框、弹出选择、文件选择面板；自绘仅限IMK候选内容。具体间距、窗宽与候选高亮是本项目设计决策，并非Apple强制值。

截至本次核验，官方设计资源提供macOS27 UI Kit。新系统使用原生控件自带外观，macOS13仍采用原生传统材料；不假装旧系统支持新API。Liquid Glass用于系统提供的控制/导航层；文字密集候选优先标准popover材料与不透明阅读面，不做自制玻璃折射、炫光、发光绿边或额外动画。

HIG建议尽量避免独立外观开关；本项目已经有appearance.theme，故保留兼容能力但放在“外观”页，默认跟随系统。系统输入源总菜单始终由macOS控制，不伪造为可强制亮暗的应用菜单。

## 3. 全部界面信息架构

| 界面 | 入口 | 焦点/生命周期 | 关键内容 |
|---|---|---|---|
| 系统输入源菜单 | macOS菜单栏输入源入口 | 系统拥有，不创建第二个常驻入口 | 正式源仅“萤火虫”，无UUID/测试包；使用现有模板图标 |
| 萤火虫功能菜单 | 已选萤火虫后的系统入口 | 按系统菜单行为关闭 | 当前模式、语言、宽度、字形、标点；设置…、关于萤火虫…；异常时附一条可定位状态 |
| 候选面板 | 当前客户端非空预编辑 | 非激活面板，保留客户端插入点 | 候选、序号、默认提交目标、条件来源、页码/键位提示 |
| 设置窗口 | 设置… | 独立可激活窗口；关闭不退出输入法 | 输入、候选与外观、快捷键、词库与工具，4页 |
| 词库新增/删除 | 设置→词库与工具 | 窗口附属sheet；只有一层 | 方案、完整编码、词条；精确删除确认 |
| 导入/导出 | 词库与工具 | 系统文件选择器；失败留在原窗口 | 本地文件、成功计数或具体原因；不暴露完整路径到截图 |
| 拼音反查 | 词库与工具 | 单一非模态工具窗口 | 输入、反查、结果、复制；空/未知/失败状态 |
| 关于/诊断/反馈 | 关于萤火虫… | 紧凑独立窗口 | 版本、源码身份、许可、数据声明、复制诊断、项目/反馈外链 |
| 设置/资源错误 | 原窗口行内/菜单状态 | 输入不被每键弹窗打断 | 状态未变化、具体原因、可执行恢复路径 |

**功能菜单顺序**：输入模式（当前值）→中文/英文→半角/全角→简体/繁体→中文/英文标点；分隔；设置…、关于萤火虫…。键位在右侧读取配置真值，禁用键位不显示。一级模式继续循环，完整三选一放在设置；菜单文案如“输入模式：混输”，tooltip解释点击切换下一模式，不伪装已实现子菜单。

菜单项全为系统原生，文案13pt参考、不批量添加彩色图标；状态可用短标题+当前值，不靠勾号同时表达多个互斥状态。只有一个语义默认操作。省略号用于还需输入/选择的动作；打开设置/关于按平台一致命名，不绑定会抢走客户端快捷键的全局⌘,。

## 4. 候选面板规格

参考尺寸：横向常态约560×96pt，候选字18pt、序号12pt、元信息12pt；内边距10pt、候选间隔8pt。这些是视觉起点，不能覆盖用户缩放或中文字形基线。默认首候选为柔和蓝色底、加粗序号1和文本；它表示“空格提交目标”，不是键盘焦点或鼠标选择状态。

- 悬停：中性底变化；首候选仍保留默认目标标记。焦点：独立系统焦点环，不用悬停色冒充。按下：反馈短且稳定，无缩放弹跳。
- 五笔/拼音混合来源页：各候选附12pt灰色“ 五笔/拼音”；单来源页省略标签。页面不可用颜色代替来源文字。
- 页码固定在次层右侧；只提示当前确实启用的翻页键。首/末页导航不可用时保留布局并明确禁用；不越界跳页。
- 状态在次层用“混输 · 半角 · 简体”；五笔键位提示在有值时显示“W 人 · Q 金”，明确它不是拆字图。
- 横向不足：**当前页整体改为纵向，保持原页候选顺序、页大小和数字对应，不将一项拆成两行。** 长词优先完整显示；仍需截断时尾部省略，tooltip及AX提供全文。布局模式自动选择属于提案，实施须ADR，不加用户设置。
- 锚定客户端caret下方，贴合插入点，距可见屏幕边8pt；下方不足移到上方。屏幕/Spaces变化重新定位，不能横跨显示器或覆盖关键输入文字。纵向9项最大约340pt，在极小可见空间中滚动当前页，不默默丢候选。
- 切主题、改变页大小/模糊音仅重算与重绘，禁止因为配置通知自动上屏。鼠标选词和AXPress均应提交到原客户端并保持输入焦点，不能先激活面板。

### 输入状态与事件契约

| 状态/动作 | 用户看到 | 交互目标 |
|---|---|---|
| 空闲 | 不显示候选 | 普通方向/编辑键交给客户端 |
| 有效组合 | 客户端原始码带预编辑、候选可读 | 数字选词；空格首项；Enter原始码；退格改缓冲；Esc取消 |
| 无码命中 | 原始码保留、次层“暂无候选” | 仍能编辑；空格/Enter按已定义原码回退；不用空白面板伪装失败 |
| 四码唯一 | 仅符合既有条件时直接提交 | 设置重算不能触发自动提交 |
| 方向键 | IT-24/ADR-151拟消费无命令修饰方向、保持组合 | 首版不宣称箭头选词；最终签名实机复验前保持阻塞 |
| 模式变化 | 组合取消，状态同步 | 不提交未经确认的候选；入口间真值一致 |
| 中英/宽度等变化 | 显示有效会话状态 | 不将“默认设置”与“当前临时状态”混淆；具体组合处理沿已有ADR，不靠稿件改变 |
| 点击外部/失焦 | 按既有finish/focus-out约定结束组合 | 不新增隐式字词；统一客户端/引擎清理，不复用残留候选 |
| 资源/写入失败 | 行内持久错误与“沿用原状态” | 不丢输入、不因错误导致未消费快捷键落入客户端 |

以上目标必须与ADR/实现逐条对齐，不把任意目标视为已存在行为。箭头问题、完整失焦协议与未知控件场景仍是实现/验收工作。

## 5. 设置与所有配置项映射

窗口参考740×580pt，最小640×480pt；左侧170pt，内容内边24pt。标题“萤火虫设置”；sidebar使用图标+文字，不只显示图标。主层按用户意图排序，Schema保留唯一值来源。行高按文本自适应，长说明不截断。

| 页 | 配置/动作 | 控件与说明 |
|---|---|---|
| 输入 | mode | 混输/五笔/拼音三段选择，解释五笔优先/拼音兜底 |
| 输入 | input.punctuation | 中文/英文标点选择 |
| 输入 | input.full_width | 默认全角ASCII检查框；旁注明菜单/快捷键可能为当前会话临时状态 |
| 输入 | input.chinese_variant | 简体/繁体选择；资源异常提供恢复说明 |
| 输入 | wubi.auto_commit | 四码唯一自动上屏检查框 |
| 输入 | wubi.z_key | Z万能键/关闭弹出选择 |
| 输入 | pinyin.fuzzy | 模糊音检查框+现有支持范围说明，不宣传全量模糊音 |
| 候选与外观 | candidate.count | 3–9步进器；不以更大数值暗示更多候选质量 |
| 候选与外观 | candidate.page_with_comma | 逗号/句号翻页检查框 |
| 候选与外观 | appearance.theme | 默认跟随系统；浅色/深色兼容选项，不新增主题皮肤 |
| 快捷键 | hotkey.toggle_mode、hotkey.toggle_english、hotkey.toggle_width、hotkey.toggle_punctuation、hotkey.toggle_variant | 可编辑文本+键位徽标预览，失效/冲突定位本行；none/单Shift按现有规则 |
| 词库与工具 | 新增、精确删除、导入、导出、反查 | 分“用户词库”和“编码工具”；不虚构词库检索表格能力 |

设置即时持久化，无虚假的全页“保存”按钮；成功只在本行短暂显示“已生效”，失败保留用户输入并说明“未保存，仍使用…”。焦点不能因重绘跳行。部分模式不相关配置仅解释适用范围，值保留，不因模式切换删除配置。程序未能判定系统级快捷键冲突时，说明限制，不能显示“全部无冲突”。

## 6. 工具、按钮与反馈

新增sheet：标题“新增用户词条”；三个永久字段标签“输入方案”“完整编码”“词条”，示例wqiy/你，tooltip说明精确编码。主要按钮“添加”，次要“取消”；空/非法输入禁用主要操作并给字段错误。提交期间按钮禁用，完成关闭sheet并在父窗口显示结果；失败保持输入、焦点到首个错误。不额外增加现有能力之外的重复项合并策略。

删除sheet：同样三个字段，说明只删除用户词库、内置数据不受影响。确认“删除这条词条？”给精确对象；取消为安全默认，不用Enter默认触发删除。操作后结果“已删除”/“未找到该用户词条”，失败保留字段。删除不等同清空词库，不提供“一键清空”。

导入/导出：系统文件面板；任务完成显示“已导入…”或“已导出”，数量仅在实际引擎提供时显示，未提供不虚构统计。错误文案“未导入，第24行编码格式不正确。已有词库未改变。”只在事实符合时使用；不得用预览固定文案当运行时保证。换行、超长路径、只读/容量/坏格式有明确区分。无需每次成功modal。

反查：一个窗口中输入与结果，替代连续模态对话框。结果“你好 · nǐ hǎo”仅是稿件表达，当前实现若只返回nihao则展示实际输出，不能假定音调或多音字候选已存在。初始给输入示例、未知显示“未找到读音”，查询失败显示原因；复制只在有有效结果时启用，显示“已复制”。

关于：既有正式图标、萤火虫、0.1.0、开源/默认离线简述；“复制诊断”“反馈问题…”“项目主页…”，诊断内容显式说明不含输入文字，是否满足以代码核验为准。外部链接由用户点击才打开；系统浏览器联网不等同核心输入法自动联网。复制成功反馈不能只靠按钮变色。

按钮语义：默认/悬停/按下/禁用/键盘焦点/忙碌/错误均有独立状态。主操作每区域最多一个；普通按钮用系统边框，删除只在确认危险操作时用破坏性角色，不整页红色。help不做浅灰低对比装饰。单图标按钮具有可访问名称和tooltip，SF Symbols按最低支持系统确认可用替代。

## 7. 亮暗、色彩与可访问性

全部元素由tokens.json语义角色覆盖：背景/层级、正文/次级/禁用、边框/分隔、强调/强调前景、默认目标/hover、error/errorFill、success、warning、focus和品牌。HEX是sRGB**稿件参考值，不是Apple固定色或实机采样**；实现使用NSColor语义API，默认尊重用户系统强调色，候选首项非key窗口的提示色须独立测试。

默认跟随系统。Increase Contrast：提高正文/次文/重要边界，去掉仅阴影区分的层级；Reduce Transparency：候选/菜单/侧栏换不透明材料；Reduce Motion：禁用自定义布局/渐变动画；字体变化：重新量测面板，不复用缓存宽度。应用暗色不意味着截图背景随意换成纯黑。

项目设计验收目标：普通信息文字≥4.5:1、大字≥3:1、必要边界/焦点≥3:1；颜色不是唯一信息载体。所有状态均有文字/图形依据。阴影与装饰分隔、禁用内容不冒充通过这些指标。真实半透明材料须在复杂/亮/暗背景上测试，离线固色验证只证明稿件配对。

候选AX：序号、全文、来源、是否默认提交目标；有按下动作，动作后焦点仍在客户端。重要错误只在出现/变化时宣布，绝不逐键朗读全页；辅助选词与键盘焦点不能混淆。每一设置字段有label/value/help/error关联，Tab阅读顺序与视觉一致，关闭窗口返回原客户端。VoiceOver、Full Keyboard Access必须实机验证，HTMLaria和PNG不能作为通过证据。

## 8. 交付与后续实施

visual-spec.html含亮暗/高对比/减少透明效果的设计稿及本地交互模拟，覆盖菜单、横/纵候选、无码命中、4页设置、字段错误、词库sheet、反查、关于、资源恢复及按钮状态。预览主题开关属于设计评审器，不是新增产品设置；稿件宽度用CSS像素按1:1示意pt，真实AppKit尺寸另验。

实施顺序：先关闭IT-24与数据/焦点可靠性；再实现语义令牌与首候选层级；统一设置导航；工具sheet与反馈；最后做材料/辅助功能实机矩阵。每一步独立ADR/PR并跑项目门禁。设计审阅通过不自动授权代码、推送、安装或发布。

设计评审矩阵：macOS13及27、浅/深/高对比/减少透明/减少动态、3/9候选、长词/英文/混合来源、RTL窗口边界、中文字体替代、窄窗/屏幕上下边、多显示器/不同缩放/全屏/Spaces、错误与按键恢复。未知项标未验，不以装饰完成度代替产品质量。
