# 官方依据与第三方方案评估

核验日期：2026-10-13。官方HIG主体通过Apple公开DocC JSON读取；JS页面的空壳没有当作已读内容。源地址`https://developer.apple.com/tutorials/data/design/human-interface-guidelines/<topic>.json`，实际读取macOS、menus、typography、accessibility、materials、layout、buttons、text-fields、settings、dark-mode。官方资源页面已核实macOS27 UI Kit。核验日期不等于每页更新日期；不推断未读取的2026平台API可用性。

## 直接依据

| 来源 | 实际用于本提案 | 项目决定的边界 |
|---|---|---|
| [Design Resources](https://developer.apple.com/design/resources/) | 最新官方原生资源与系统字体入口，页面提供macOS27模板 | 未复制/打包Apple专有UI Kit或字体，保持原项目品牌图标 |
| [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos) | 键盘/指针、窗口和大屏环境 | 浮动候选焦点不抢客户端来自本项目IMK约束 |
| [Color](https://developer.apple.com/design/human-interface-guidelines/color) | 动态系统颜色、明确语义、自定义色亮暗和高对比适配 | 所有HEX是原创稿件参考值，不是官方色采样 |
| [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode) | 默认尊重系统外观；谨慎独立外观选择 | 本项目已有theme选项，保留兼容但默认跟随系统 |
| [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) / [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) | 控制导航层与内容层区分；材料随辅助设置适配 | 候选是文字密集内容，以标准材料为主；13与27分别原生适配，不自制玻璃 |
| [Menus](https://developer.apple.com/design/human-interface-guidelines/menus) / [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) | 熟悉动作结构、清楚标签与状态 | 菜单仍遵现有模式循环，主要操作及设置分组是本提案 |
| [Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields) | 永久字段标签，输入量与宽度一致 | 词库字段及精确删除对象来自已有功能，非扩展词库浏览器 |
| [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) / [Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | 系统字体、重要性层级、可读密度 | HIG本次macOS默认13pt/最低10pt作为参考；本提案信息文字12–18pt、尺寸非硬规定 |
| [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) | 不仅靠颜色、系统偏好、可理解可操作 | 4.5/3:1为项目验收目标，固色稿件不代替真实材质、VoiceOver和键盘检查 |

没有宣称Apple专门规定了本项目的候选配色或方向键行为；这些是产品决策，未来实施须与ADR及实测相符。
