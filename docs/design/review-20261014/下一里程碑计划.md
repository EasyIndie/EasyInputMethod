# NEXT-UI：下一里程碑 macOS UI 重构

- 状态：已登记、暂缓，当前不认领实施。
- 优先级：当前功能与使用体验收敛之后的下一里程碑；不排日期。
- 依据：用户2026-10-14明确要求先补功能体验，整套UI重构稍后进行（ADR-158）。
- 设计基准：[统一方案](统一设计方案.md)、[50张图库](index.html)。整理完成不等于全部视觉/交互已获批准。

## 目标与范围

原生设置四pane、输入源功能菜单、候选主次/翻页、独立可选学习区、长词教学披露、词库sheet与反馈、关于及亮暗/辅助模式统一。不引入云、皮肤或额外常驻状态栏入口。

学习区反查/完整码/拆字解释不是纯视觉替换，单独作为功能与数据依赖处理；本次新增教学能力暂缓，不能为了开始重构把未核验教学数据塞进UI。

## 启动条件

1. 当前P0输入可靠性问题及关键功能体验验收收敛，IT-24在新签名候选原生复验，不用旧包通过替代。
2. 汇总用户对统一设计的审阅结论，复核未定行为：翻页边界、菜单三选一、长词披露/滚动/高度。
3. 确认教学数据来源许可、字体字形与结构准确性，明确反查/FFI实现子任务；不足时先交不依赖教学的数据层或原生框架，不能虚构结果。
4. 启动时按主工作区/已合入版本实际状态创建小步任务，保留原有未提交改动；不自动批量重写或安装新包。

## 实施顺序（启动后再拆卡）

- UI-01：确认设计与行为ADR、关键交互回归基线。
- UI-02：教学模型/码反查/窄FFI、数据及规则校验（与既有核心隔离）。
- UI-03：两项学习偏好/快捷键Schema、唯一配置写入/热更新/失败恢复。
- UI-04：候选及翻页、主次字号、非激活焦点与动态布局。
- UI-05：有限高度学习区、根上码下、长词明细/滚动及AX。
- UI-06：原生设置/菜单/词库工具/反馈统一，小步更新。
- UI-07：亮暗、高对比、减少透明/动态、macOS13/27、目标应用及双设备验收。

## 完成标准

统一方案中已审定范围有对应实现与证据；配置唯一、零网络/零遥测、来源登记及许可门禁保持。make verify零诊断，strict宿主构建、关键输入回归通过；原生TextEdit/Safari/Terminal验证不丢字、不污染控制字符、不抢焦点。

3–9候选、长词/大字、单页/首末页、屏幕边缘/多屏、设置失败、真实点击/滚轮/Tab/VoiceOver通过相应验证；学习数据缺失准确反馈且不阻碍输入，展开高度有界。最终同一签名包按两设备条件验收，不凭静态图宣布完成。

## 当前明确不做

不实施新UI框架/教学区/新设置键，不重新设计更多画板，不因此改变当前MVP可靠性和发布门禁。可继续修复现有UI的功能性、焦点或可访问性缺陷，但不得借修复顺手推进整体重构。
