# 萤火虫 macOS 统一设计方案 · 全面审阅版

版本：2026-10-14 / Review 1。状态：已整理留档，整体重构暂缓至下一里程碑（ADR-158）；全面审阅结论尚未确认。仅设计与独立原型，未实施产品代码。

**本文件与同目录图库是当前统一审阅入口。** 先前v1–v10保留历史推演，不作为并列实施基准。原生框架沿v2，显示偏好沿v5，主次/翻页沿v7，根码上下对应沿v8，紧凑首行/长词高度沿v10；本版对单字与两字词稿、完整设置也同步这些要求。

## 1. 目标与原则

默认混合输入：五笔优先、拼音兜底。选词是第一任务，五笔学习为按需辅助。默认离线、零遥测、无广告/账号，所有教学查询本地完成。不新增云、皮肤、统计或AI写作。

系统负责窗口、控件、字体和语义色；项目负责候选及字根内容。候选浮窗不夺取宿主输入焦点。学习内容可读但不压过候选，信息只在需要的位置显示一次。

## 3. 候选主体

保留原始预编辑码、候选文字、序号，以及仅多页出现的翻页组。移除重复模式、逐项来源、常驻字根键名、快捷键教程和工具按钮。

候选17pt；当前项semibold、无背景，其他regular。序号11pt、原始码12pt。当前高亮与学习内容关联，但不表示面板获得键盘焦点。默认关联空格目标首项，不能从稿件推导新增方向键选择。

短词优先横排；实测超出可用宽度时整页纵排。按配置保留3–9候选及数字映射，不为稿件硬改页大小。长文本换行/高度按内容测量，不能截掉影响选词的内容。

数字选词、空格首项、Enter原码、退格编辑、Esc取消与既有翻页键保持。候选点击即按现有选择契约提交，不增加“首次点击仅教学预览”。学习区中的逐字披露只改变学习内容，不选择/提交候选。

## 4. 翻页

右上原始码同行：“‹ p/N ›”。页码只读；单页/无候选隐藏整组，多页首末分别禁用前/后。边界不循环是ADR-156提案，实施需先核对并统一引擎行为。

图标约10pt，命中区24×24pt；页码11pt、数字宽度稳定。总数位数变化重新测量，不覆盖原始码。仅悬停/按下轻反馈，不常驻方块背景。AX为上一页、下一页、第p页共N页及真实禁用状态。

鼠标只翻页，不提交、取消或激活窗口。键盘保持减号/等号及可选逗号/句号；不新增左右方向键动作。翻页后页码、合法候选与学习内容同步更新，不留下上一页解释。IT-24方向键保护与新签名包复验仍待完成。

## 5. 学习区：独立开关、低权重、有限高度

设置“候选”pane提供“显示编码与拆字说明”，快捷键pane提供“显示/隐藏学习区”。两入口更新同一持久显示偏好，默认收起；快捷键提案默认未绑定，可自定义/禁用。不能通过输入模式自动开关，纯拼音也可展开本地五笔反查。

候选主体几何保持，学习区向下扩展；屏幕边缘允许整体定位调整，不承诺绝对不移动。无候选/组合时不单独弹学习窗，显示偏好保留。切换不得提交、取消、修改marked text或夺取焦点；写入失败保留旧偏好。

完整码13pt等宽medium，字根15pt regular，键码11pt等宽regular，规则11pt；系统必要次级色，不通过过淡灰制造层级。无选中背景、键帽、彩色编码或大字根。

**首行合并完整码与简要规则。** 单字例：完整码WQIY + Y识别码：点/左右；两字词例：完整码WQVB + 两字各取前两码。下方严格“字根在上、键位在下”，每列中心对齐，识别码单独标注。长说明可自然换行，不压低字号、不截断关键规则。

学习区不重复主体当前字词标题；词组逐字标签是对应关系所需，不删。无码显示“五笔编码暂缺”，有码无拆分保留码并显示“拆字说明暂缺”。隐藏时不暴露旧教学内容。

## 6. 长词：中华人民共和国

完整码KWWL与“前三字＋末字首码”同行；下方上行中/华/人/国，下行K/W/W/L。这里是取字摘要，不把整字称作字根。中间“民、共、和”不参与词组码，但可逐字学习。

默认只有摘要，“逐字拆分”入口放在对应行末。展开明细按原词顺序七字列表，每字独立披露；上根下码，识别码另解释。候选主体与词组摘要固定，明细区域滚动，不翻候选页。披露/滚动是新交互提案，未实施。

参考总高：摘要242pt，展开428pt，明细可视137pt。实际以可用空间为上限；不可无限撑高或遮住输入行。明细展开状态为当前组合会话，不新增配置；换词重置，不能带入旧解释和滚动位置。

## 7. 菜单与设置

系统输入源菜单归macOS，本产品不额外创建第二个专属状态栏入口。功能菜单：输入模式子菜单（混输/五笔/拼音单选）、中文输入、全角ASCII、繁体输出、中文标点；分隔；设置…、关于萤火虫…。布尔勾号表示实际状态，快捷键显示规范绑定，不配彩色图标。模式子菜单是ADR-152待实施提案。

设置采用固定不可自定义的Mac工具栏，四pane：输入/候选/快捷键/词库；SF Symbols按名称使用。当前标题如“候选 — 萤火虫”，默认即时生效，不放全页保存。窗口只需要关闭；不要截获宿主客户端全局⌘,。会话内可记最近pane，跨重启持久化须另走配置唯一规则。

| Pane | 配置/动作 |
|---|---|
| 输入 | mode、input.chinese_variant、input.punctuation、input.full_width、wubi.auto_commit、wubi.z_key、pinyin.fuzzy |
| 候选 | candidate.count、candidate.page_with_comma、appearance.theme；拟candidate.show_wubi_learning |
| 快捷键 | hotkey.toggle_mode、toggle_english、toggle_width、toggle_punctuation、toggle_variant；拟hotkey.toggle_wubi_learning |
| 词库 | 新增、精确删除、导入、导出、现有拼音反查 |

现有15个配置项＋拟2个学习项。拟项尚未写入代码Schema，不得宣传可用。默认值未来仅ime-config Schema定义，所有设置和快捷键通过其规范读写/订阅，禁止UserDefaults或偏好副本。非法、重复或保存失败不显示假成功，保留旧设置与输入。

快捷键首层用Mac符号显示，通过sheet编辑现有表达式；不引入全局捕获或录制器。关闭绑定沿既有none语义，实际冲突与键盘布局需实机核验。

## 8. 词库、工具、关于与反馈

新增：父设置窗口sheet，永久字段标签输入方案/完整编码/词条。有效时Return添加，Esc取消；错误定位字段且保留输入。

删除：精确对象确认、取消安全默认，破坏性语义由原生按钮表达，不刷整窗红色。确认后焦点返回原对象。

导入/导出使用系统文件面板；稿件不重画系统文件浏览器。结果在词库pane内简述，失败给具体原因/行号，仅有证据时承诺原词库未变。取消无数据变化。

拼音反查工具沿现有能力：本地文字→内置首选读音（nihao），不混称已实现五笔反查或多音字功能。学习区五笔反查为待实现的新能力。

关于：现有正式图标、名称、实际版本、开源说明、主动复制诊断/反馈。版本样例不是最终包身份。普通成功不常驻绿色卡片；失败按相关行持续呈现准确文案和恢复动作。反馈及控件状态画板是评审样例，不规定新增产品窗口。

## 9. 系统视觉与可访问性

原生NSWindow/NSToolbar、NSButton、选择器、输入字段、SF Symbols；自定义仅业务候选/根码内容。亮暗默认跟随系统，现有强制浅/深设置保留兼容。配色API与本机参考RGBA见native-color-reference.json；不是生产HEX常量。

labelColor、必要次级色、separatorColor、controlBackgroundColor、用户强调色及原生disabled/错误角色。次级说明对比不足时升级文字角色，以字号/分组建立层级；必要文字固色目标4.5:1。增强对比、减少透明、减少动态遵系统；内容不模拟玻璃折射，新旧系统分别使用自身原生控件外观。

AX候选读序含序号/文字，来源可按实际需求保留；学习逐对朗读字根与键，而非先读所有根再读所有码。翻页、披露、设置、输入错误有名称/值/状态。Tab和VoiceOver流不等于窃取客户端焦点，须按不同窗口真实验证。

## 10. 数据与证据边界

现有D13只有键名字提示，不是拆字。reverseLookup现只查拼音。完整五笔反查、结构解释模型、窄FFI、合法字根字形与覆盖率待工程落实。D2/D3表示差异、PUA和D3非发布oracle边界保持；不得直接发布oracle字串或凭码猜拆分。

现有码表核验样例你WQIY、好VBG、你好WQVB、中华人民共和国KWWL及七字完整码。字根/识别码内容是设计样例，不证明教学数据正确率。字体覆盖、成字字根/键名字/识别码类别及长词取码需逐类校验。

全部图为真实AppKit离屏渲染，自定义业务排版；窗口非key，菜单是排版规格、sheet是内容而非实际模态过程。NSScrollView为原生视图，不证明滚轮路由、点击或AX已通过。没有桌面背景的材质真实性证明。HTML图库为离线审阅载体，未浏览器实测。
