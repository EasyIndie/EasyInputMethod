# 学习区 v10：编码与规则同行，高度有界

2026-10-14，按用户反馈细化v9长词布局，仅设计，不改产品代码。

完整码和取码规则合并首行：`完整码 KWWL    前三字＋末字的首码`。完整码用13pt系统等宽medium，解释11pt必要次级文字，彼此留白不使用按钮或胶囊。下方继续字／根在上、对应键在下，不恢复交替单行。

单字应用同一原则：`完整码 WQIY    Y识别码：点／左右`，下方根键对应；上下结构不变，识别码解释无需再占底部一行。词组完整码与简要取码规则同行，详细逐字规则留在明细，避免重复。

本稿以中华人民共和国展示：默认总高242pt，较v9的264pt少22pt；其中候选主体仍147pt，学习摘要约95pt。展开总高428pt，较v9的520pt少92pt；逐字明细可视137pt，内部滚动。保持主体和摘要固定，明细不继续撑高整窗。

这些是静态样例，不是硬编码适用于所有字体的高度。实施时以可用屏幕空间为上限，并设置明细视口上限；若屏幕不够，不强制展开到428pt。候选内容按既有数量和实测排版，不能为教学删减候选。学习摘要与逐字明细需要在多屏边缘实机验证。

规则较长时优先使用准确简述；仍放不下一行，则只让该行自然换行，不压低字号或截断关键规则。展开明细本身始终在有限视口内滚动。无可靠拆字数据时维持准确缺失说明，不编造紧凑解释。

“逐字拆分”入口移到根键行末的剩余空间，避免与编码/规则首行竞争；字根过多时另测量入口位置，不允许覆盖内容。真实控件点击、滚轮、AX、动态排版未验，原生离屏稿仅示意。
