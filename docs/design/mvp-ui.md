# MVP基础UI实施规格（ADR-165）

用户批准基础UI纳入MVP。功能基线66ab513保留；本文件是可独立实施的首版子集，原50张统一设计中的教学能力仍后移，不能把设计稿当全功能批准。

## 范围与次序

1. 候选主体：输入码、序号、17pt首项semibold/其他regular、无选中背景；原生翻页按钮和页码，短词横排/超宽纵排、长词可换行/超高内部滚动。
2. 设置/输入源菜单：现有Schema按输入、候选、快捷键、词库任务分组，外观归候选；原生控件、即时写入和失败回读保持。模式/中英/宽度/字形/标点仍可查当前状态。
3. 既有词库、读音反查、反馈与关于：统一字号、标签、边距、空/失败/成功和长内容，保留现有功能与错误恢复，不引入新管理平台。
4. 外观/访问性：语义字体/颜色与原生控件，亮暗、长词/最窄窗/多屏、键盘及辅助动作；真实VoiceOver和全局辅助外观仍最终包实测。

## 候选行为和状态

| 场景 | 行为 |
|---|---|
| 默认/单页 | 输入码与候选；第一项是现有空格目标，数字顺序不改；无翻页组 |
| 多页 | 输入码同行显示上一页、第p/N页、下一页；首末禁用对应按钮，既有键盘翻页仍钳制 |
| 鼠标/AX | 候选点击/AXPress沿现有提交契约；页按钮只翻页且非激活，不新增箭头选词或先预览后确认 |
| 来源/状态 | 来源完整保留AX标签/帮助；模式和宽度用现有菜单查看，不在每个候选重复；繁体失败保留可见简体回退提示与完整原因 |
| 键位提示 | 既有W人/Q金等键名字作为低权重附行保留，不是新学习区/完整拆字 |
| 超宽/超高 | 超640pt或屏幕可用宽时整页纵排；长词换行，视口最大320pt且受屏幕约束，内部滚动；提交完整文本 |
| 空/取消 | 清除旧候选回调与辅助动作，隐藏页面/提示，不得保留旧可执行候选 |

数字11pt、输入码12pt、辅助提示11pt、候选17pt；具体密度/640/320上限是项目设计决策。浮窗不能成为key/main，不模拟系统键盘事件、不截取用户窗口。

## 语义令牌和证据

canvas=NSColor.windowBackgroundColor、text=labelColor、separator=separatorColor、accent=controlAccentColor；次要与错误角色沿既有实测可读颜色，必要信息保证与实际背景对比。首项只以字重/位置/AX首选描述表达；hover仅暂态轻反馈，主题改变需重算CGColor。默认不透明表面，无新增动画。

使用实际AppKit控件截图和离线产品组件契约断言；亮暗/长词/翻页/错误和帮助齐全。实际宿主焦点、屏幕布局、VoiceOver及系统辅助设置须新签名最终包原生验收，离屏截图不能替代。

## 后移与冻结

完整码反查、真实根码对应、多字词逐字教学、学习开关/快捷键属于后续独立功能和数据任务。当前不改输入算法/模式种类/排序或增加配置。核心66ab已单独合入并公证；UI4e660af随后获批准，并获同类公开/合入/CI公证的持续授权。完整UI包独立签名核验，不覆盖旧候选身份；安装/Release另行安排。

## UI02实施

四个任务pane采用不可定制NSToolbar（输入/候选/快捷键/词库），原生SF Symbols与iconAndLabel，标题随pane更新。最近pane仅进程内保留；没有会话时词库操作禁用。菜单增加状态类别、设置/关于动作省略号；现有循环/快捷键不改。官方依据2026-10-14核验：[Settings](https://developer.apple.com/design/human-interface-guidelines/settings)、[Menus](https://developer.apple.com/design/human-interface-guidelines/menus)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)，官方DocC数据回退已读取。

## UI03实施

词条表单用对齐的显式标签和原生输入/方案控件，错误换行、失败保留字段；删除默认取消。导入/导出沿系统文件面板并说明本地操作范围。关于/反查结果统一任务标题、可缩放窗口、可选择正文、原生复制/反馈按钮及行内结果；反馈失败保留可复制地址。所有反馈链接仅显式点击打开系统浏览器，诊断不自动发送。实际表单及信息窗口离屏图位于build/mvp-ui03-review，测试工具未带正式Bundle版本，所以关于图显示?，最终包元数据仍由现有门禁核验。

原生17pt候选控件字号与富文本字号保持一致；无页头/附行时以实际渲染倍率核验中文可见字形中心，容许2.5pt原生光学偏差（项目选择）。不把字形墨迹像素当控件几何边界。

## UI04工程与产品边界

显式亮/暗也尊重系统高对比；辅助文字高对比不透明，候选边界增强。使用系统辅助显示通知刷新窗口与已解析图层色，主题/hover无隐式动画，候选内容表面始终不透明。设置切页结束旧字段编辑并重算原生key-view loop，可见行内结果发布AX值变更通知。亮暗原生色及高对比语义策略26对配色全部达标（正文4.5:1、必要高对比边界3:1，项目验证目标），几何覆盖左侧/负坐标/边缘与320pt窄视口；不能替代实际VoiceOver、全局显示设置和真实多屏。

设置帮助保留Schema规定的键位/默认值/效果，UI展示去除内部竞品对齐说明；原Schema和值域不变，不新增另一份配置真值。

### ADR-172设置还原

按统一稿恢复650pt默认窗口、任务分组/缩进与右列对齐、原生模式分段、带标题布尔选项及选择性可见说明（全部帮助仍在AX）。快捷键首层显示规范化Mac符号，通过原生sheet编辑原有表达式；取消不写，失败保留输入，关闭或切离的旧行不接受异步保存。Schema仍唯一提供17项值域/默认/标题/校验，新键有其他分组兜底。

### ADR-173关于还原

恢复正式图标/产品名/实际版本/定位与许可层级，诊断仅主动复制。问题与安全漏洞两入口保留在原生反馈下拉中，用户选择后才打开浏览器；失败给地址回退，不自动发送任何诊断。InfoWindow继续保留长内容与错误，不将其通用文本布局当关于稿还原。

ADR-174：候选400pt基准/16pt边距/20pt序号槽及短词等列留白向统一稿还原；学习开关不再改变主体宽度，窄屏仍钳制。真实长词/3–9项/翻页契约保留。
