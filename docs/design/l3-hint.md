# L3 教学提示 · 视觉与行为规格（B3 批，待实现）

> 2026-11-06 提案，用户确认「**默认关闭**」。视觉样例见 [`l3-hint-mock.png`](l3-hint-mock.png)。
> 数据来源：`data/generated/B0-runtime.tsv`（ADR-311，3,000 字，96 B/字）。

## 1. 放在哪里

**候选窗内、候选行下方的一行**（不是独立面板）：

```
┌──────────────────────────────────────────────┐
│  1 是  2 时  3 十  4 事  5 实          jghu  │
│ ──────────────────────────────────────────── │
│ jghu｜字根：日(j) 一(g) ？(h)｜拆解待核验…   │
└──────────────────────────────────────────────┘
```

- 关闭时：**完全回到现在的候选窗**（高度不变、无分隔线），用户感知不到这个功能存在。
- 打开时：窗口高度 +30 pt，分隔线 1 pt（10% 灰），提示文字 11 pt、次级灰。

## 2. 显示什么

按 `B0-runtime.tsv` 的第四列**原样显示**（构建期已定稿，宿主不拼句子）：

| 质量 | 显示 |
|---|---|
| `full` | `jghu｜字根：日(j) 一(g) 止(h)｜识别码 u（末笔捺+上下）｜一级简码 j` |
| `partial` | `jghu｜字根：日(j) 一(g) ？(h)｜拆解待核验（部分字根字形未识别）｜参考识别码 u` |
| `unknown` | 不显示提示行（窗口高度不变），避免"暂无资料"占地方 |

- 优先显示**当前高亮候选**（默认第 1 项）的讲解，随上下键切换实时更新。
- 拼音模式、标点、英文候选**不显示**提示。
- 单行显示，超出宽度**尾部截断加「…」**，不换行、不滚动。

## 3. 开关

复用既有开关 `candidate.show_wubi_learning`（默认 **false**），**不新增配置项**：

- 关闭：不加载 `B0-runtime.tsv`（省内存），候选窗与 1.1.0 完全一致；
- 打开：启动时读入 `[String: String]`（3,000 条约 150 KB 常驻），键入时按候选字查表；
- 资源缺失/损坏：提示静默关闭，其余功能不受影响（ADR-311）。

## 4. 性能与边界

- 提示文本来自内存字典，单次查表；**不进按键热路径**（只在候选窗刷新时取一次）。
- 稳态 p95 目标不变（≤16 ms）；若实测有劣化，先降级为"只在候选稳定 120 ms 后显示"。
- 不记录任何用户行为（不做"看过哪些提示"的统计）。

## 5. 验收（B3 完成标志）

| 项 | 口径 |
|---|---|
| 关闭态 | 与 1.1.0 候选窗逐像素一致（截图对比） |
| 打开态 | `full`/`partial` 文案与 `b0_query.py` 一致；`unknown` 不出提示行 |
| 截断 | 长文案尾部「…」，窗口宽度不超出候选行 |
| 性能 | 稳态 p95 ≤16 ms 不劣化；候选窗刷新无额外延迟 |
| 内存 | 打开后宿主常驻增加 ≤1 MiB |
| 资源缺失 | 删掉 `B0-runtime.tsv` 后功能静默关闭，输入正常 |
