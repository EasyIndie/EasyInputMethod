# 学习区（⌥L）· 草图与规格（B3 批，待评审后实现）

> 2026-11-06 第三稿。用户裁定：**候选窗保持简洁，零改动**；学习信息只在 ⌥L 学习区；
> 学习区自己也必须精简；并且——**学习区不重复当前字/词**（它已在候选窗里处于选中态）。
> 草图见 [`learning-area-mock.png`](learning-area-mock.png)（五格：现状 + A/B/C + 高度对比）。

## 1. 原则

1. **候选窗不动**：不加提示行、不改高度、不改配色——第一稿"候选窗下方加一行"的方案作废。
2. **只在学习区**：沿用既有的 ⌥L 开关（`candidate.show_wubi_learning`，默认关）。
3. **学习区也要短**：单字最多两行；**词组合成一行**；长内容一律收进「逐字 ▸」，不铺开。
4. **不重复当前字/词**：候选窗里已经高亮选中，学习区只讲"这个字怎么来的"，不再画一遍字。

## 2. 现状（草图第 1 格）

```
完整码 TKG    识别码G：横、左右
 禾     口            ← 识别码也被当成字根格子排在末尾
 T      K
```

三个问题：① 码与说明挤一行、识别码用"G：横、左右"这种压缩写法；② 识别码被混进字根格子里；
③ 词组要展开「逐字拆分」才能看逐字信息。而且学习区**重复显示候选字**（下图中「和」占一整行）。

## 3. 提案（草图第 2–4 格）

### A. 单字（两行，不重复字）

```
TKG                                  一级简码 T
──────────────────────────────────────────────
禾      口            识别码 g
t       k             末笔 横 · 结构 左右
```

- 第一行只有**完整码**（mono）+ 右侧简码（有才显示）；
- 分隔线后：字根格子（字形上、键位下，键位小号灰）+ 右侧识别码依据两行；
- 无简码/识别码时留空，不写"无"。

### B. 拆解待核验（两行，不编造）

```
JGHU                                    拆解待核验
──────────────────────────────────────────────
日      一      ？        参考识别码 u
j       g       h
```

- 未知字根显示 **？**（键位照常），右上角橙色小字「拆解待核验」；识别码标「参考」。

### C. 词组（一行）

```
LTIF          输      入      法        逐字 ▸
              l       t       i
```

- 一行放下：完整码 + 前 3 字的字根/首码 + 「逐字 ▸」；
- 展开后是紧凑列表（每字一行、可折叠），不再铺开大段文字。

### 高度对比（草图第 5 格）

| 场景 | 现状 | 提案 |
|---|---|---|
| 单字 | 84 pt | **74 pt** |
| 词组 | 71 pt | **32 pt** |
| 候选窗 | — | **不变** |

## 4. 数据来源

| 内容 | 来源 | 说明 |
|---|---|---|
| 完整码 / 字根 / 键位 | `data/generated/B0-runtime.tsv`（ADR-311） | 3,000 字、96 B/字；`full`/`partial`/`unknown` 分级 |
| 识别码依据（末笔 × 结构） | 同上（`full` 才有） | 预渲染时已写死，宿主不推导 |
| 简码（一/二级） | 同上 | 随 `full` 记录输出 |
| B0 未覆盖的字 | 现有 D14 派生数据兜底 | 只有全码与部分拆字；文案按 `partial` 规则显示 |

> 两套数据**不混排**：命中 B0 就整条用 B0（含 quality 标记）；未命中才走 D14 兜底，且必须显示"按旧数据"。

## 5. 状态与降级

| 情况 | 表现 |
|---|---|
| ⌥L 关闭（默认） | 学习区不出现，候选窗与 1.1.0 完全一致 |
| 资源缺失/损坏 | 退回 D14 兜底；再没有就整块隐藏（不报错、不弹窗） |
| `unknown` 字 | 只显示「暂无拆解资料」，不显示格子 |
| 拼音/英文/标点候选 | 学习区不显示 |

## 6. 尺寸

- 面板宽度跟随候选窗内部宽度；单字 **74 pt**（两行 + 分隔线），词组 **32 pt**（一行）；
- 字号：完整码 mono 12.5、字根 15、键位 mono 10.5、说明 10.5–11；
- 颜色：正文近黑、键位与说明次级灰、`拆解待核验` 用系统橙（不新增自定义色）；
- 候选窗本身尺寸、配色、圆角**一律不动**。

## 7. 验收（B3 完成标志）

| 项 | 口径 |
|---|---|
| 候选窗 | 关闭/打开 ⌥L 时**候选窗本身逐像素不变** |
| 文案 | 与 `B0-runtime.tsv` 第四列一致；`partial` 必带「拆解待核验」 |
| 高度 | 单字 ≤ 74 pt、词组 ≤ 32 pt（超出进「逐字 ▸」），候选窗高度不变 |
| 性能 | 稳态 p95 ≤16 ms 不劣化；学习区刷新不阻塞候选 |
| 内存 | 打开 ⌥L 后常驻增加 ≤1 MiB |
| 降级 | 删掉资源文件后仍能显示全码（D14 兜底），不崩溃 |

## 8. 待确认的三点

1. **简码**放第一行右上角（现方案），还是并到第二行与识别码同侧？
2. 识别码依据写成「识别码 g / 末笔 横 · 结构 左右」两行（现方案），还是压成一行「g（横/左右）」？
3. 词组只显示**前 3 字**是否够（4 字词省略第 4 个，其余进「逐字」）？
