# 候选框 v3：让候选成为主体

2026-10-14，待审阅设计提案；仅替代 v2 的候选框部分，其他界面仍沿用 v2。生产代码未实施。

## 信息取舍

| 信息 | 新版处理 | 理由 |
|---|---|---|
| 预编辑码 | 顶部保留一份，12pt | 明确正在输入什么；宿主是否同步显示仍按既有 marked-text 契约 |
| 候选文字 | 16pt，主体 | 第一眼读词，而非读来源 |
| 选词序号 | 11pt，与文字同行 | 保留数字选词可发现性 |
| 模式、每项来源 | 默认视觉省略 | 不影响选词，不需要每次重复；输入模式仍在系统功能菜单确认 |
| 页码 | 仅多页显示，右上角一处 | 不再占据底部整行；单页完全省略 |
| 五笔字根提示 | 默认省略 | 教学信息不应常驻占用候选区；若未来需要，另提按需教学方案，当前不新增设置 |
| 翻页键、Esc 说明 | 常态省略 | 快捷键契约和帮助保留；操作本身不改变 |
| 键盘图标、分隔线、底栏 | 移除 | 减少装饰和视觉扫描 |

来源仍可保留在无障碍描述中；这是视觉信息减量，不要求删除引擎来源字段。AX描述应简短，是否朗读来源须实机评估，不能靠静态稿宣称验证通过。

## 布局与状态

- 常态参考 **320×74pt**：上行预编辑码与条件页码，下行序号和候选。相比 v2 的424×120pt，高度减少约38%。尺寸是四项短词样例，不能硬编码为所有候选的固定宽度。
- 长词参考 **288×150pt**，整页纵排，候选行高36pt。实际按字号、可用屏幕和全部候选测量；保留3–9项既有配置及数字映射，不因排版删候选、改变顺序或页大小。
- 短词优先横排。全页实测宽度超出可用区域时整页纵排；长词允许换行并增高。不能仅按字符数切换，也不截掉会影响选词的文本。
- 无匹配参考 **320×66pt**：保留原始码与“无候选”，不显示假页码、不弹警报、不重复按键教程。
- 首项用系统强调色12%轻背景、加粗和序号共同提示空格目标；它不代表面板获得键盘焦点。其余项无需框或各自来源行。
- 颜色沿用 v2 的动态系统语义色，默认跟随系统；必要次级信息对比不足时提升为 labelColor。亮、暗、高对比稿使用原生 AppKit 文本与颜色。无自制玻璃折射或常驻动画。

## 交互保持

数字选择、空格首项、Enter原码、退格修改、Esc取消、既有翻页键保持。隐藏快捷键文案不取消这些能力。不增加箭头选词、候选工具按钮、自动上屏或新配置。鼠标与AX选择不得夺走宿主焦点；IT-24新签名候选复验仍待完成。
