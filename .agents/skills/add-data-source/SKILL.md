# 引入数据源

**任何数据进入本仓库前都必须登记许可。** 见 `docs/数据来源与许可.md`、`AGENTS.md` 铁律 4。

## 步骤

1. **核对许可**：打开上游仓库的 `LICENSE` **逐字核对**，不接受"根目录没写许可"的默认推断。确认与 GPL-3.0 兼容。
2. **登记**：在 `docs/数据来源与许可.md` §1 表格新增一行（ID/用途/来源/上游作者/声明许可/风险/状态）。
3. **记录机器可读元数据**：在 `data/sources.toml` 追加 `[[source]]`，含 `url`、`upstream`、`license`、`risk`、`sha256`、`used_for`、`added_at`。
4. **保存源数据**：
   - 小文件放 `data/sources/`；
   - 大文件记录**下载脚本**（`data/sources/fetch-*.sh`）而非直接提交。
5. **优先自建**：若能用"公开规范 + 我们自己的生成器"产出（如五笔词组码），优先自建，不直接复制第三方派生物。
6. **标注风险**：若为"第三方重新授权"或上游不明 → 标 ⚠️，并寻找替代，**不得作为不可替代来源**。
7. **更新生成脚本**：`tools/` 下的生成逻辑要能复现该数据。
8. **自检**：
   - [ ] `docs/数据来源与许可.md` 已登记；
   - [ ] `data/sources.toml` 已登记且 SHA-256 正确；
   - [ ] 许可与 GPL-3 兼容；
   - [ ] 生成脚本可复现；
   - [ ] `make verify` 通过。

## 禁止

- 引入许可不明或与 GPL-3 冲突的数据；
- 直接复制闭源商业输入法（极点五笔、微软五笔等）的词典作为不可替代来源；
- 提交无来源、无许可记录的大体积二进制数据。
