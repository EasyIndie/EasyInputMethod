# 新增 / 修改配置项

配置有严格约束（见 `docs/配置架构.md`）。**必须**按以下步骤，否则会破坏"真值唯一"。

## 前提

先读 `docs/配置架构.md` 的 §1（四条铁律）与 §8（Schema）。若不满足，先停下来说明冲突。

## 步骤

1. **确认归属**：这是**配置（持久偏好）**还是**会话状态（临时）**？
   - 会话状态**不进配置**（见 `docs/配置架构.md` §5）。
2. **在 Schema 中定义一次**：编辑 `crates/ime-config/src/schema.rs`，新增一条 `OptionSpec`：
   - `key`（如 `wubi.auto_commit`）、`value_type`、`default`、`doc_zh`（中文一句话说明）、`scope`（哪些组件需实时生效）。
   - **默认值只写在这里**，不得在别处重复。
3. **接入消费方**：在需要该选项的组件里，从当前快照读取并**订阅变更**（即时生效）。
   - 不得缓存副本（铁律 R2）。
4. **更新文件模板与文档**：
   - 若该选项属于 v1 最小集，更新 `docs/配置架构.md` §6 示例；
   - 保持 `config.toml` 注释由 Schema 生成，不要手工分叉。
5. **测试**：
   - 单测：默认值、取值范围校验、非法值被拒；
   - 集成测：`ime_config_set` 后消费方立即生效（无需重启）。
6. **自检**：
   - [ ] 没有第二个地方保存该配置；
   - [ ] 没有硬编码默认值；
   - [ ] 没有写入 `UserDefaults`/注册表；
   - [ ] `make verify` 全绿。

## 禁止

- 新增"用户可见但无实际用途"的选项；
- 为省事把选项塞进环境变量或命令行；
- 在设置界面硬编码选项（必须由 `ime_config_schema()` 渲染）。
